# 错误纠正与偏差分诊（正本）

## 1. 用户说"不准"时先分诊

| 类型 | 表现 | 处理 |
|---|---|---|
| 数据问题 | 出生信息、读盘提取、时区或钟表时间性质有误 | 核对输入；先 `archive_chart.py` 归档，再用 `build_chart.py` 重排（新 chart_id），见 `shared/versioning.md` §3 |
| 规则应用问题 | 读错表、口径用错、漏了条件 | 按正确规则重判受影响的结论，记变更日志（类别：读数错误 / 规则应用错误） |
| 解释形态问题 | 盘面方向对，但落到现实的形态不对（例如"变动"被写成"离职"） | 回到三轴分离，重写形态；结构结论不变 |
| 时间问题 | 多条与时间相关的结论同时偏，尤其上升或分盘敏感的部分 | 先看时间来源与边界审计；来源不可靠或盘在换座点附近时才建议 rectifier |

不要一律转向"出生时间可能不准"。时间来源可靠时，命中率低优先怀疑规则在这张盘上的适配。

## 2. 可以修改结论的情况

措辞校订阶段锁定结论。只有下面三类允许改结论：读数错误、规则应用错误、新输入推翻旧前提。反馈复核阶段按用户反馈修正，类别记「反馈复核」，且必须在初始结论冻结之后（`shared/permissions.md` §3）。

## 3. 怎么记

每次修改写入 analysis_record（`shared/scripts/analysis_record.py change`）：

原结论 → 新证据 → 修改原因 → 新结论（附类别）

报告里被改过的结论，在技术附录或分析记录里能找到这条链。无法解决的差异写「未解决」，说明缺什么证据，不强行圆。

## 4. 不做的事

- 不追加新预测去弥补命中率。
- 不承诺"做完完整分析会更准"。
- 不把用户反馈改写成自己的独立推断。
- 不因用户情绪或期望调整结论档位。
