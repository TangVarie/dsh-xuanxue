## 执行主线

1. 跑 `python calculator/scripts/check_chart.py --dir <工作目录>`，按能力范围工作；涉及时机先跑 `python shared/scripts/check_freshness.py --dir <工作目录>`。
2. 初始推导只用计算数据：不读 user_context，不读 verification_record；引用 core 只读 p2a~p4 与 core_summary（`shared/permissions.md`）。`python shared/scripts/analysis_record.py init --dir <工作目录> --module love`。
3. 第一步原盘情感代码（D1 5/7 宫、Venus、DK、D9）→ 第二步多维时机（Vimsottari + Chara、婚姻三阶段 L7 → UL/Sun → L11）→ 第三步流年定性与建议，分别写 love_step1 / 2 / 3。
4. 分盘先按 `shared/divisional.md` 过启用表与边界审计，线A / 线B 分标。
5. 时间窗按 `shared/time_window.md`：MD 背景 / AD 阶段 / PD 月级；MD×AD 含混合、平淡时分层陈述；过运日期只引换座表。
6. 支持与制约证据如实列出，某一侧没有就写"未发现"，不凑条数。
7. 结论写入 analysis_record 并 `freeze`；需要按反馈复核时冻结后再读 verification_record（mode 变 calibrated）。
8. 建议与行动卡按 `shared/grounding_basic.md`；装了 oracle-grounding 时叠加，文风仍是"知心好友"。
