# 独立场景试用与复核记录（v5.1 第四阶段）

每轮由一个没参与修改的子任务执行：只按 skill 文档走，在单独的工作目录里真实运行脚本，报告"按文档走不通 / 文档互相矛盾 / 输出与文档不符"的地方。出生数据全部虚构。

## 第 1 轮：场景试用

**发现并已修复**（摘要）：
- 改出生时间后无法按文档执行（旧记录与新盘冲突、旧盘文件被覆盖）→ 新增 `shared/scripts/archive_chart.py`，calculator / versioning / rectifier / error_correction 统一为"先归档再重排"；`analysis_record.py init` 拒绝覆盖并给出下一步。
- 合盘子目录无法建分析记录、无法做时效检查 → `init --chart A=… --chart B=…` 登记双方盘；`check_freshness.py` 支持合盘子目录。
- 能力范围只在仅日期模式打印、且不看有效精度 → 新增 `calculator/scripts/capability.py`，`check_chart.py` 与 structured_data.md 用同一张表（精度矩阵 × 边界审计含 D1 × Dasha 层级 × 出生时间误差带来的日期平移）。
- "不知道"只排除出分母会抬高匹配率 → 待核超过 1/3 暂不定级。
- 旧引擎 Dasha 交界差 1 天让整条时机链判失败 → 旧版导入数据按 ±1 天容差处理并注明交界日不下结论。
- 旧版导入保留了旧 ✅ 校验块和"读盘方式：直接计算" → 导入时替换。
- report_builder 的 `--mode` 能把报告写成比分析记录更"盲"的模式 → 拒绝。
- reader 轨道 / 条件 A / 时间风险用 Lagna 度数而不是边界审计；两处时间可信度会算出不同结果 → 统一按 D1 边界审计，规则可由数据复算。
- 直接点名专题、合盘时被插入验前事并重复追问 → 不再插入。
- 合盘：UL/DK 非法值静默丢弃、当前运期用排盘时冻结的标记、dosha 减免未算、宿相关项静默缺失、文档与脚本对仅日期一方的度数分级说法相反 → 全部改正并对齐文档。
- 若干副本矛盾（soul D60 分支、Sahams"手算"与"不心算"、导出前必须重排 vs 只刷过运、季度划分来源、低反馈声明里的"高置信度"）→ 改正。
- 文档承诺 `transit.py` 能重取过运但它没有命令行 → 补上 `--chart … --write`、`--ingress-from`、`--hit`。

## 第 2 轮：修复后的最终复核

复核者重跑回归（27/27 通过），并逐项核对上一轮修复。新发现并已修复：
- 月级窗口「不启用」时 `dasha_query.py --date` 连 MD/AD 也不给，而多处文档靠它定位当前运期 → 不启用时输出 MD/AD 行（退出码 2）。
- 双 Lagna 对比的"移到换座点之后 1 分钟"在换座点位于报时之前时会排出同一个上升 → 改为"取与当前上升不同的一侧"并写清算法；分盘可信度声明里写出换座分钟。
- 合盘某一方盘变了以后重建记录走进死胡同 → `archive_chart.py` 支持合盘子目录；init 比较全部登记的盘。
- 双 Lagna 对比文件不归档；D1 未审计的旧数据在新轨道规则下无定义；合盘时效不查规则版本与运期；分析记录不记引擎版本 → 补齐。
- "Moon 在误差内跨宿就整表只作候选"前提错误（时间轴在宿界两侧连续）→ 改为按两侧主星年数较大者算平移；MD 也按平移降级。
- 文档漂移（暂不定级条件、无效等级、时间可信度正本、formatter 写死的轨道）→ 改正。
