# 分层权威、计票与分叉（裁决的唯一规则源）

> 凡是"这件事听谁的、几条线算数、反证怎么处理、标什么标签、重断能不能下"，都以本篇为准。其他文件只引用，不另立规则。
> `06` 流派对照是证据底料（各派怎么说），不是判决书。

---

## 一、段氏是脊柱，不是最高法院

- **流程脊柱**（先问什么后问什么）——采用段氏。它是唯一对每一层都有答案的完备体系（别派多偏科：飞宫主管立极与生死、金口诀主管串宫应期与神煞、中原主管时柱直断），给的是机制（制、合、冲的效率）而不是死律，能讲"为什么"，适合当推理次序。
- **仲裁权威**（冲突时谁赢）——不采用。立极上飞宫"真命主未必是日干"、清娟移位、素水换十神是对手本体论；旺衰载不载信息是真分歧；"自动判段氏赢"会把分歧糊掉。

理由也不是"段氏更准"——占断系统没有可检验的预测效力作地面真值，给不了谁加冕。段氏坐默认引擎的位置，靠的是完备和能讲机制，这只够当"默认"。各槽位的主镜头只决定**默认分析路径**，不代表那一派已被证明正确。

## 四、真分叉与冲突协议

> **收敛优先**：诸镜头能指向同一结论就收敛，不管出身哪派。
> **散则并带（仅限真分叉）**：两套读法都往下带，报【存疑】，写出分歧点和能分辨两者的事实，交 P10 对照已知事实。
> **首选分支用该槽主镜头**：必须给一个说法时，用该槽位的主镜头给首选（立极→段氏日干、六亲→素水、生死→飞宫），同时保留另一支和【存疑】。

### #1　谁是命主／立极（P2）
- 两说：段氏日干→日支→禄比　vs　飞宫"真命主未必是日干"（金/木主形）、清娟弱极移位、素水换十神。
- 触发：日干无根无功，或全局一形独旺。日干正常做功时不触发。拿不准算不算触发（根被合住、落空亡、只剩余气之类）时按触发处理。
- 协议：触发即双跑。同一命主→立极定；不同→两套下游读法都带，标【存疑】。不许默默取段氏。

### #2　旺衰载不载信息
- 两说：段氏论富贵做功弃用旺衰　vs　清娟、金口诀、中原用旺衰。夏仲奇书里邢铭芬说"切不能用旺衰断"，陈秉志答"不敢苟同"（两人读法相反处见 `16` 第六节）。
- 协议：分清用在哪。论富贵贵贱做功，不看旺衰；论心理承载、合财胜任、体貌肤色，旺衰是主镜头。各管各的，不报存疑，但不串用。

### 已收敛或个案级，照用

| 矛盾 | 处理 |
|---|---|
| 官星可制否 | 已收敛到郝三段论：制化得力皆可贵；制格有官灾、化格无官灾；正星坐宫不可制、偏星可制 |
| 合能否解穿 | 个案级：贴紧且力大可使穿失效；隔位弱合解不了，按位置力量权衡并标依据 |
| 三合局成立 | 原局从段氏（中神双现不合作入墓）；岁运参与时太岁本气优先 |
| 驿马查法 | 郝派宽口径（三字任一皆马） |
| 子卯刑、阴干羊刃、神煞多寡 | 骨架不用；校时辰或江湖直断时作校验，不入主判。脚本把子卯刑列在"主库不采用"组，江湖煞单独成组，阴干羊刃不列 |
| 干支互克 | 支不克干；丁亥己亥辛巳癸巳支可克干、丙戌壬戌须未刑开为例外 |

## 五、计票、反证与标签

### 1. 什么算一条方法线

方法线按来源与推导路径分簇。**"独立"只表示来源和推导路径不重复，不是统计意义上的独立。** 不同簇的线算不同来源；同一簇内，派别或书不同、推导路径也不同的，也可算两条（如 D 簇里 `04` 大限与 `16` 限法两套年龄窗）。

| 簇 | 方法线 | 主要读 |
|---|---|---|
| A 段氏理法 | 势、体用宾主、做功效率、正反局，及滴天髓衰旺真机、调候法理 | `01`、`11`、`12` |
| B 象法 | 干支象、十神象、宫位象、神煞象，共象取真 | `03` |
| C 分科直断 | 财官婚亲病狱学寿八条口诀死律 | `05`、`07` |
| D 应期 | 大限→大运→流年引动→数星动；夏氏应期句式（`15` 第八节归此簇）；陈氏限法与句法 | `04`、`15` 八、`16` 一二 |
| E 替代视角 | 飞宫找真命主、清娟暗引换象、素水出处立极、金口诀串宫、中原岁运君臣民、刘恒节气 | `06`、`10` |
| F 夏氏条文 | 定级三问、禄墓穿破、宫位、六亲坐支、婚姻与凶事专断（`15` 第八节以外） | `15` |

不重复计票的情况：
- 同一句口诀的不同转述（如 `06`、`07` 里记在刘恒名下而与 `15` 文字重合的条目），只算一条。
- A 簇与陈氏去寡论指向同一件事（强众即势、去寡即制净），同向时只算一条；反向时要停下来查。
- C 簇与 F 簇同源的口诀只算一条。
- 由同一个案例引出的几条规则，只算一条；修正登记里状态为"候选"的规则不计票，只当检查项（`output-and-verification.md` 第三节）。
- `17` 的条目是检查项，不计票；与主库冲突时用主库作首选，注明 `17` 的异说（分歧保留，但不因此改标签）。

富贵层级、事业方向、关键应期、生死凶灾四类重判断，要并行跑至少三条相互独立的方法线，各自独立算，再看收敛。各篇里"三法同指""两条全中"之类的说法，指的是该法内部的判据，不替代这里的计票。

为了同一张盘两次分析用的是同一套线，四类重判断先跑下面的默认清单（按第三节的主镜头与校验取）。清单外增减方法线，在执行记录里写明理由，回复里列的方法来源与记录一致。

| 判断 | 默认方法线 |
|---|---|
| 富贵层级 | A 段氏层级（`01` 第八节）；F 夏氏定级三问（`15` 第一节）；E 中原三平衡；再过 `16` 五道反证题 |
| 事业方向 | B 象法三定位（`03`）；A 做功方向与宾主（`01`）；E 素水三分法、清娟五合换象 |
| 关键应期 | D `04` 组合拳；D `16` 限法与句法；D 夏氏应期句式（`15` 第八节）；E 清娟数星动 |
| 生死凶灾 | E 飞宫形气；E 中原反吟伏吟三原则；A 段氏穿禄、食神坏；`10` 马倒禄斜、追魂铲度作补充线 |

### 2. 反证怎么处理

- 先处理反证，再看支持数。三条线两条支持、一条反对，**不能按二比一直接升档**。
- 反对线只有在以下情况才能排除，且要写下理由：不适用于当前问题；用错了（条件不满足、字取错）；它依赖的前提明确不成立（如依赖的时柱已被排除）。
- 排除不了的反证留着，按下表定标签。

### 3. 标签（体系内的支持程度，不是概率）

| 情况 | 标签 | 写法 |
|---|---|---|
| 关键前提确定，至少两条不同来源的方法线支持，没有未解决的实质反证 | 【铁断】 | 体系内强结论；验证状态另列 |
| 一条有效方法线支持，或几条支持其实同源 | 【推断】 | 给出首选判断和成立条件 |
| 支持与反对都成立，或关键前提未定且会改变结论（如立极分叉、时辰候选） | 【存疑】 | 写出差异和分辨条件 |
| 没有足够的方法支持具体结论 | 不作判断 | 说明已有信息能支持到哪一步 |

- **关键前提**指：时辰候选、立极、势的读法、所用的时间口径。这些没定时，依赖它的结论最高【推断】；前提不同会让结论变方向时标【存疑】。
- 一句话里强弱不同的部分分开标（如"这几年要防守【铁断】；具体落在哪件事【推断】"），不整句套最强的标签。
- 标签说的是"在本体系内论据有多强"，现实是否应验另列验证状态（`output-and-verification.md` 第二节）。没有历史事实时，验证状态写"未验证"，标签不因此机械降档，也不拿"还没对照过经历"当作不给【铁断】的理由。
- 已有事实与某条结论直接冲突时，只处理受影响的判断，不凭一条事实给整盘所有结论加分或减分。
- 同一组结论可以合并标一个标签。

### 4. 重断门槛（闸门）

亡故、离丧、无子、多婚、牢狱一级的断语，是"重断"。

1. **先过门槛（必要条件）**：按 `17` 第一节表格——星与宫同伤、无救应、岁运又叠到，才论重。门槛不过（表中条件没有全到），按表里"单看只是什么"一栏读，重断不下，并写明还缺哪几项、出现什么情况才论重（放进待验证清单）。牢狱在 `17` 第一节没有专行，门槛取已有条文：原局有牢狱之象（`05` 第六节、`15` 第七节），官杀坐旺贴身而日主无根无印（`17` 第二十五节"官杀算不算无制"），岁运又引动；"伤官见官"一行另见 `17` 第一节。
2. **过了门槛，标签照第 3 小节**：至少两条不同来源的方法线同指且无未解决反证，才【铁断】。单条口诀命中只到【推断】。
3. 门槛不过时，重断事项不给年份或时间点（父母存亡、婚次、离散、子女有无等都一样），只写单看读法和还缺的条件。
4. 门槛本身不计票。`17` 是检查项，不能把任何判断升档。

## 六、来源分级

每份材料分别记三件事：**文本来源**（谁说的）、**历法一致性**（例盘在记录的口径下排不排得出）、**经历确认**（有没有当事人反馈或书中所记结果）。原书记载、当事人反馈、整理者解释、工程性限制、从测试里提出的假设，分开标。

| 材料 | 文本来源 | 历法一致性（`check_chart.py`，北京时间、23 点换日） | 经历确认 | 用法 |
|---|---|---|---|---|
| `15` 夏仲奇条文与邢注 | 原书一手：夏仲奇当场断语与条文，邢铭芬注 | 229 个可解析的盘，221 个通过；8 个时干不合五鼠遁：4 个是书按晚子时排的（`--ziday 0` 即通过，生年起运也对得上），1 个时干印错可定正，3 个原书例盘有误 | 书中多记结果，但只印应验之例 | 进主库，按 F 簇计票；书证明"这样断过并且应了"，不证明命中率 |
| `16` 陈秉志解析层 | 同书作者自己的另一套体系（旺衰、去寡、限法） | 同上（同一批例盘） | 同上 | 校验镜头；与 A 簇同向不加票，反向停下来查 |
| `17` 《宫位做功断法》 | 二手转述，无师承出处 | 75 盘里 13 盘遁法不合（10 盘错在月干）；其余 62 盘在 1840–2030 年间排得出；所称起运岁数 87% 挤在 6–8 岁，按历法算的散在 1–10 岁，26 盘对不上；6 盘重复 | 无当事人反馈，行文为教学设例 | 检查项与重断门槛；不计票、不升档。"例盘是构造的"是整理者据遁法违例和行文性质作的判断 |
| 修正登记 R1–R7 | 见 `output-and-verification.md` 第三节，每条单独标来源 | — | 多来自单一案例或开发集 | 按各条状态使用 |

- 历法通过只说明这些干支在记录的范围与口径下排得出，不说明是真人，也不说明断语准。
- 历法不通过，先查输入、转录、口径（晚子时、时区）和程序原因，再谈材料性质。批量核验时看输出里的两项提示：遁法不合的盘有几盘换口径即合（多半是书的排法不同，不是错）；所称起运岁数的分布与按历法算出的分布差多远（一批真实出生的起运应大致散开，挤在一两个数上说明是随手写的）。还定不了的，用 `--repair` 查错字、对照原书正文，再定不了就标"原书例盘有误"，不当历法一致的例子引用。
- 不用通过率自动判"真命例"或"构造盘"。
- 规则可以作为本体系采用的分析方法使用；来源不明或未经独立检验的，不宣称已证明真实或准确。
