# 17 分科补充检查项 —— 宾主流向与重断门槛

> 来源：胜天半子《盲派八字宫位做功断法》。二手：是对段氏盲派宾主、宫位、做功的转述，没有师承出处。
> 可靠度：75 个例盘里 13 盘月干或时干不合遁法（真实排盘不会出现）；其余 62 盘在 1840–2030 年间排得出；写了起运岁数的 65 盘里有 26 盘与排得出的日期对不上（`scripts/check_chart.py`，北京时间、23 点换日）。13 盘遁法不合里 10 盘错在月干（五虎遁），错字修复只救回 1 盘；书中写的起运岁数有 87% 落在 6–8 岁，按历法算出的起运散在 1–10 岁，6–8 岁只占约三成；另有 6 盘重复出现。加上全书无当事人反馈、行文为教学设例，整理者据此判断例盘是构造的。所以它只能示范机制，不能证明任何规则断得准。（旧版写"23 盘历法上不存在"，是旧脚本按每天中午取样的错误结果，已更正。）
> 地位：本篇条目一律是**检查项**，提醒"这里还该看一眼什么"。它不能把一条判断升成【铁断】；与主库（01–07、09–12、15）冲突时默认主库，冲突列在篇末清单。
> 用法：分科断事时翻到对应节逐条过；下离、丧、亡、无子、多婚、牢狱一级的断语前先过第一节（牢狱另见第二十五节）；篇末冲突清单里标"异说"的，按主库读作首选，同时注明本篇异说，分歧保留。

## 一、重断门槛

这本书贯穿各章的立场：冲、穿、星多现、伤官见官这类单一信号，不直接断离、丧、亡、无子、多婚；要星与宫同时受伤、无救应、岁运又先坏，才论重，否则只是变动。主库和 15 篇的口诀多是单条直断，本节是给它们加一道"先别急着下重断"的闸。怎么用（门槛是必要条件，过了门槛再计票）以 `authority-and-forks.md` 第五节之四为准。

| 事项 | 单看只是什么 | 叠到什么才论重 |
|---|---|---|
| 父母凶事 | 岁运冲父母星或其宫一次：换工作、搬家、资金变动；只动宫＝居所工作环境变 | 原局该星已无根、受制、入墓或重冲穿，岁运又同时损星与宫 |
| 六亲星入墓 | 关系冷淡、不善表达、心事不显；印有根入主位可开之库反主善持家 | 不凭入墓一项断寿限，轻重按上一行 |
| 丑戌未三刑全 | 家产、单位、隐伏之事复杂，亲族因产起意见 | 书未给升重条件；用主库"父母早逝"之断先过第一行 |
| 两母、父母再婚 | 双印或正偏印混杂＝女性长辈共同照料；财多印多只是星多；只宫冲而星有情＝两地分居 | 星混杂＋父母宫冲破＋原配之星先坏＋另一星随后入宫，且新星在大运得根；只现于流年＝一时接触 |
| 手足数目 | 比劫多：可以是朋友、同业（只在日时者尤是） | 先辨真假（落年月或藏年月支不受破坏为实），再参生育年代 |
| 离婚 | 夫妻宫逢冲：未婚应恋爱订婚搬迁，已婚应两地、配偶换工作；逢穿＝信任受损、不吵而隔 | 星宫同伤且无救；大运先伤配偶星＋流年冲破或合闭夫妻宫＋无食伤、官杀、财印居中解救 |
| 多婚 | 财两处、官杀混杂：一实一虚，虚者是工作压力或短暂异性信息 | 两星各自得根，同时进主位争合日主或夫妻宫。再婚另须前星被冲去、入墓或失根，后运新星得根并合、生日支 |
| 外情 | 夫妻宫逢合：合来有用财官＝配偶带来资源；暗合＝私下合作、不公开收入；咸池＝人缘、客源、才艺曝光 | 三因并见：夫妻宫原有冲穿＋配偶星被外位之字争合＋岁运引来新异性星并接通日主或夫妻宫 |
| 配偶伤病 | 只伤星：男应破财，女应丈夫工作变动；星宫一伤一全＝局部事 | 星宫同伤＋星失根＋岁运反复伏吟冲穿 |
| 无子、生育难 | 时柱空亡、冲穿：养育不省心、子女离家；印制食伤得当＝照料；食伤入墓＝来得慢 | 书只给解除条件：空亡逢填实、冲逢合解、库逢冲开可落实；食伤被印制尽又无财转化才论受限 |
| 伤病 | 原局一个刑冲穿：压力劳累；病名不由单穿指定 | 三层：原局病象→大运接通（检查治疗）→流年再冲动日支、时支、月令或病位（手术、突发）；日主无根、官杀重重、岁运临绝最重 |
| 伤官见官 | 口舌、岗位变化；中间有财反成业绩职位，女命不主婚变 | 官杀有根＋印受伤＋财牵连都到位才进正式程序；官杀冲入日时并破财库、印、日主根才牵连家业 |
| 离祖、出国 | 驿马逢冲、日时冲年月、时柱受冲：搬迁、派驻、子女远行 | 原局之功必须靠主位去取宾位财官才能完成；大运先引动冲神，流年再冲开月支或合动驿马 |
| 财库逢冲 | 支出扩大、变卖；本人无经营置业行为只应家用 | 财旺库闭、主位能承接才论发；财弱、主位无根而被强冲＝卖家产 |
| 破财 | 财源、财星、主位功神、财库只动一处＝局部支出 | 四处同动；财被比劫夺走无凭据，或生七杀反攻身 |
| 反吟、并临 | 异地、转向、十年主题集中 | 吉凶从原局做功关系出，不凭反吟并临本身 |
| 早婚、贫贱 | 配偶星在年月＝异性信息出现早；主位不做功未必贫贱 | 早婚须早运接通星并动宫（早运比劫夺财则恋早婚迟）；贫贱书未给条件 |

## 二、宾主流向

- **所得归谁**：年月与日时之间生、合、冲的方向 → 宾位财官被主位合住、制住、收入库＝能得；主位财官被宾位合走冲走＝为他人作嫁；主生宾无回流＝付出多所得少，宾生主＝外部资源自来。
- **同一十神按宾主反读**：比劫、食伤、财所在柱 → 比劫在主位制宾位财＝凭己力取财，在宾位争主位财＝别人分利；食伤在主位生宾位财＝主动找市场，反之＝靠客户渠道。
- **宫对宫的冲合**：日时支与年月支 → 日支冲月支＝家庭与职业单位难兼顾；时支冲月支＝中晚年转业或因子女改安排；日时相合＝家庭与晚景、子女绑在一起；年支合入日支＝远方资源入家。
- **冲的主动与被动**：谁在主位、谁有力 → 主位旺神冲宾位弱神＝主动打破外部格局；宾位旺神冲入日时＝被环境逼着变。
- **干合的表里与争合**：相合两干的坐支 → 干合支冲＝面和心不和，干不合支合＝利益暗连；合神无根＝停在名义。一干被两干同合＝资源被争、事情反复；夹在财与日主之间的比劫是"隔"，求财必经分配。
- **隔断**：年到日之间的中间字 → 宾位之印被财隔＝长辈、学历转不成助力；年上官印被月柱隔＝祖上体面、本人所得有限。
- **月令是否为我用**：月令之神与日时有无作用 → 旺而不参与做功、不接主位＝只是环境势力强。
- **定主线**：全局围绕哪个十神做功 → 透财而全局在制杀，主线在权；官印远而无根、日时食伤生财有力，实走技术经营。
- **功神路径**：功神与所取之物隔几个字 → 贴制最直接；须一生一化才接通的，链上任一字受损整条停（财被比劫截住＝有本事变不成身份）。
- **化是否化到身**：官杀→印→日主 → 印远离日主或被财合坏＝表面官印相生，实为压力临身。
- **制化并存**：食神与印的位置 → 印贴食而夺食＝坏原功神；印、食分居日主两侧不相战＝两路并用，岁运助哪边做事偏哪边。
- **功神互坏**：功神旁有无克合它的字 → 不算无功，是先有机会后生阻碍，反复几次才成。
- **所得归处**：做功之后财官落哪柱 → 进日时＝归己；停年月＝替外界做事；主位食伤生宾位财、财再生年月官杀而不回生＝成绩归单位。时柱之物也要日主或日支合住、或入可控之库才算己有〔存疑〕；被年月合走＝结果外流。
- **冲库三问**：库在主在宾、谁来冲、冲后之物流向 → 主位冲开宾位财库且日主能得＝得财；自家之库被宾位强冲＝破财；库在宾位而主位无开库之字＝看得到拿不到。
- **原局无功靠运**：大运是否补上功神 → 财在宾位，运来主位可控的比劫食伤＝突然开财路；杀无制，运来有根的食或印＝压力转事业；功随运走，换运归平常。
- **星宫分读、好处落宫**：六亲星与其宫；得用之字所在柱 → 星好宫伤＝人有能力而缘薄，宫好星弱＝缘在助力有限。得用之字在年月而不接日时＝条件好却接不住。

## 三、祖业家境

- **出身好是否落到本人**：年月财官印库与日时的衔接 → 年月财有根有库＝家有实产；被主位合入、制取、收入库才落到本人。
- **家底虚实**：年月财的根、库与比劫 → 财多无库或被比劫争＝有收入少积蓄；财少而坐库有根＝有实产。
- **起家还是耗家**：年月比劫、食伤与财 → 比劫制住年月财＝靠经营劳动得财，只争合财＝多人分一份；食伤生财而财入库＝靠手艺起家，无财承接＝劳碌难聚。
- **名望与财富分读**：年干（名声）、年支（祖业实况） → 年上官坐印各有根＝祖辈有职事声望，虚浮＝只是被人提起；官印清财弱＝有名无厚产。
- **祖业哪一代动**：年支被谁冲、库的开闭 → 被月支冲＝父母一代已动；被日时冲＝本人这代离祖、分产；库能开且为主位收取＝得家产，库闭又被宾位合住＝本人无份；年月比劫争合财＝亲族争产；年支被月日反复穿＝分到财物而亲情受损。
- **家道流向与早晚**：年月与日时生的方向＋早运 → 年月连续生入日时＝有传承；日时反生年月无回流＝长期为家付出。早运开年月财库＝幼年家业长，早运先坏年月＝早历家道变化。
- **离祖还是守业**：日时对年月的冲、印比之合 → 冲后得财官＝离祖有利，冲后主位受伤＝被迫外出；年月印比成势合住日主又无冲动之字＝留乡守业。
- **能否承接**：接的路线＋主位根气 → 年上财印经月柱生入日时，或年支财库被日支合入，才算继承；祖业旺而主位无根＝守不住；先离后承＝早运冲年月、中年运把年柱财印合入主位。

## 四、父

父星取法用主库（05 四）。

- **父宫分工**：年柱、月柱 → 年柱偏父亲的家族根基与早年，月柱偏命主成长期父亲的职业与对家的影响。
- **父星落柱**：在哪柱、透还是藏 → 在年月＝早年受父影响深；在日时＝父事入主位，成年后由命主承担。
- **星宫同位与异位**：父星是否在年月、父宫坐什么 → 在年月有根不受冲穿＝谋生路明确；星落别宫而父宫坐比劫＝父离祖在外或家业被亲友分；父宫坐官印＝靠单位、职位、技术立身。
- **父亲的路数**：父星所受作用 → 得食伤生＝会经营；生官而官有根＝立足单位管理；入库不开＝保守重积累；被年柱比劫合住＝为家族兄弟耗财；合入月柱＝掌家中经济。
- **谁帮谁、远近亲疏**：父星与日主日支的生合冲穿 → 父星生官、官生印、印生日主＝父帮命主；日时食伤生父星＝命主为父出力；被日主合＝亲近共事；与日支冲＝观念不同、分居；父宫遭穿＝长期隔阂。比劫在主位制宾位父星＝命主日后接手父亲资源。经济、情感、距离分开断。
- **非凶事的应期**：父星原局所受作用被哪步运放大 → 受比劫夺而行比劫运＝父破财；父星入库逢冲库＝工作资产居所有变；日支伏吟之年＝父事由命主亲办。

## 五、母

- **母亲本人与家庭环境分看**：印星与母宫（书以月柱偏母） → 印有气而宫被冲＝母有能力但家不稳；宫安静而印受伤＝家里平稳、母自身压力重。
- **母力落不落到命主**：印到日主的通路 → 年月连续生入日时＝落实；印被合闭、入墓＝命主所得少；印与日主之间隔财＝被工作钱财牵走。
- **操劳还是享福**：印得生还是被泄耗 → 得官杀有情相生＝靠工作、丈夫得安稳；比劫成势大量泄印＝为子女操劳；印有根入主位＝晚年得子女照应。
- **财坏印的轻重**：财印根气、其间有无官杀 → 财有食伤生而印无根＝母受经济或父亲事务牵制；都有根且有官杀居中＝边工作边顾家。
- **婚后距离与晚年归属**：夫妻宫对印的冲穿；时柱之印被谁合 → 印被夫妻宫冲穿＝婚后观念不合，冲中有合＝远而常往来；印落时柱被日主合住＝晚年随命主，被年月合走＝仍牵挂老家。

## 六、父母关系

- **和不和**：财与印之间有无官杀居中 → 财生官、官生印＝父主外母主内；财直接克印才成问题；居中之官杀受伤＝原可协调的人事失效。
- **谁说了算**：财印力量对比 → 财旺有根克无根之印＝父强母受压；印成势财无根＝母意见重；两星相当反复交战＝争执最显。
- **合的质量**：合神是否得用、有无争合 → 有根无争合＝专一；父星被两印争合或母星被两财牵＝受长辈、工作干扰。财被比劫合走多是把钱和时间给了兄弟朋友，不作外情。
- **谁先应事**：两星根气、救应与各自宫位 → 同年两星同动，弱而无救者先应；大运先制某星、流年再冲其宫，该方先发。

## 七、兄弟姐妹

- **离家、少往来**：比劫被合去哪、是否入墓、月柱冲合 → 被合入别宫＝寄养、过继、早离家；入墓不开＝少露面；月柱逢冲＝各奔一方。
- **手足本事**：比劫有无做功 → 有根并能制财、合官或生食伤＝有实际本事；旺而只与日主争财＝性强而能力未落实。
- **谁发展好**：功在主位还是宾位 → 比劫在宾位取得财官而主位未接通＝手足先成；日主坐下有功并把年月财官合入主位＝命主居上；谁控制功神谁话语权大。
- **助还是累**：比劫做功的成果流向 → 替日主制财、抗杀、护印且所得入主位＝助；合财后财被合到年月＝手足取走资源；比劫夺印＝父母偏向其他子女。
- **行比劫运应什么**：比劫是功神还是夺财 → 功神＝得手足同业之助；夺财＝借贷、分利、替手足担费用。

## 八、性情

- **四层分工**：日主、月令、日支、做功 → 日主定本性，月令定环境，日支定内心落点，做功方式定遇事手段；年月＝早年与在外表现，日时＝私下与年长后。
- **处世手段**：以何种作用、哪组十神做功 → 以合取＝借关系整合；以冲制＝快而直接；以穿制＝察细、从薄弱处下手；以刑＝耐反复、易纠结。伤官制官杀＝敢挑战权威；印化官杀＝先找规则依据；比劫制财＝要亲自控制过程。
- **亲力亲为还是借力**：功由主位还是宾位之字做出 → 主位直接制宾位财官＝事必躬亲；宾位先做功再送入主位＝善借平台。
- **胆量类型**：日主根、杀的制化 → 日主强根而七杀有制＝胆大；无根而杀贴身无化＝外撑内紧；伤官旺而官杀无根只是嘴上胆大。

## 九、形貌

本节取法与主库 03 八不同，整节〔存疑〕。

- **形还是气质**：该五行是否得令、有根、贴身 → 三者具备形体特征才显；虚浮无根只成气质。
- **初见与熟后的反差**：天干所透十神与日支十神 → 不同即有反差。
- **胖瘦与特征**：五行流向；日主之根所受冲刑穿 → 食伤生财流通＝有肉不滞，土重无泄＝厚，金木交战＝骨多肉少；根被冲＝疤、旧伤或不对称，岁运重复引动才显。

## 十、学业

- **学业、文凭、成绩分看**：印官、印食、有无中断之字 → 文凭看官生印、印生身；成绩看印食配合；能否读下去看是否被财、比劫或冲穿打断。有印无官＝爱读书不重文凭；有官杀无印化＝怕考试。
- **三段接通**：印→日主有根→食伤或官 → 印生身而无食伤＝吸收多输出少；伤官旺印无力＝聪明而不按要求失分。
- **印落何宫**：印所在柱 → 在年＝得长辈影响；在月＝学校环境稳；在日时＝工作后考证进修；被财紧贴克＝家庭现实压力早介入。
- **转学、重读、停学**：月柱受冲、伏吟，印是否仍接日主 → 受冲＝换校换住处，印仍接日主＝转学非停学；伏吟＝重读复考。停学四因：财旺坏印、比劫夺印、食伤过旺冲官、官杀重而无印化。
- **二次求学**：印库开闭、后运 → 早年印受制而中晚运得根；印入库后运冲开；早年财坏印先工作，后行官印运回校。
- **考试环节**：流年发动哪个十神 → 官杀动应报名竞争，食伤动应答题面试，印到位应成绩证书录取；冲开印库＝录取、档案调动；印库被合闭＝手续拖延。

## 十一、才艺技能

- **才华显不显、早不早**：食伤在年月还是日时、干还是支、根与墓 → 透年月＝早被看见；在日时＝后天形成；在干＝说写展示，藏支＝操作构思；入墓＝待岁运开库才入行。
- **天赋变专业**：印与食伤 → 印生身、身生食伤＝先吸收后发挥；印太重压死食伤＝有理论无作品，食伤太重冲去印＝有经验不肯受训认证。
- **专不专、入行先后**：功神是否一条线 → 印→身→食→财一线＝知识技术收入一体；食伤两透各自争合＝分散；印在年月、食伤在日时＝先受训后输出，反之先入行后补资格。
- **成名与赚钱分看**：食伤是否到宾位、财是否回主位 → 食伤透年月或与官杀印有情作用＝成名；只在日时做功＝传播有限；财在宾位而取回＝能谋生；食伤旺不见财＝作品多收入不稳。只动食伤之年先有口碑，财现、财库开之年才落实收入。
- **才华受阻**：枭与食的力量 → 伤官过旺而偏印适度制＝成专业标准；偏印成势把唯一食神制尽才是受阻。
- **转行**：原局是否有两条做功路线 → 大运关旧路线、开新路线时改业；层次看新功神能否接入主位。

## 十二、职业与事业起落

- **工作手段**：功神用哪种作用去制 → 合制＝协调整合；冲制＝快而多变（施工、执法、开拓）；穿制＝盯关键环节（审计、检测、医技）；刑制＝在复杂流程里反复处理（调查、研发）。
- **骨干还是一员、动手还是文职**：做功之字的宫位与干支 → 功在年月靠平台，在日时靠个人技术；宾位自行做功而不接主位＝本人只是其中一员；做功在地支且冲刑多＝亲自操作现场，印官在天干流通＝文件制度。
- **功神真不真**：功神的根、对象与结果去向 → 有根、得生、有明确对象、结果能进日时，四条齐备才算根基；主位有功而年月无可取之财官＝平台有限。
- **稳定还是停滞**：冲合后功神还在不在 → 冲而调动功神＝反有发展；功神被合住＝表面安稳实则停滞。
- **工作为何反复**：月柱受何作用 → 受冲穿＝换单位、领导、地点；伏吟＝同类事重复；被合＝机会慢牵扯多。
- **贵人与小人**：有用的印、官的宫位 → 落年月＝单位行业关系，落日时＝身边人；只在宾位不接日主＝认识能人借不上力。小人不凭比劫一字：比劫截财争官、伤官冲官、枭夺食才是。
- **事件落在哪层**：岁运发动的十神＋宫位 → 官杀动＝职位考核；印动＝单位合同证照；财动＝业绩收入；月柱动偏单位，日时动偏本人。

## 十三、官权

- **权从哪来**：官杀被哪条路线处理 → 杀印相生＝组织任命；食神制杀＝别人处理不了的业务权；伤官合杀＝靠手段协调人事；财生官而官合身＝以业绩资源换职位。
- **实权几项**：主位能制取什么 → 能制比劫＝用人权，能取财开财库＝资金权，能制官杀掌食伤＝决策处置权。只有官印＝偏行政文书；只有食伤制杀＝业务权强、级别未必高。
- **权是否落到本人**：官与日时的连接 → 官合入日主或官库被日时打开＝权近身；功神在时柱而控年月财官＝后得实权；官印都在年月不接日时＝有头衔、按程序办事。
- **虚职**：官印虚实、争合、墓库 → 官被两头争合＝权责分散；印旺官弱＝有资格无岗位；官旺印弱＝临时负责缺任命；官入墓不开＝有职无权。
- **升职真假与落点**：大运是否承接＋发动的宫位 → 只见流年官星而大运不接＝责任增、考核；月柱动＝部门调整，日柱动＝落到本人；官印同动＝正式任命，财官同动＝因业绩资源。

## 十四、独营与合伙

- **受雇还是自营**：财与日时的关系、比劫去向 → 财多但全在宾位流转＝只是行业资金大；独营须主位能控制财或财源，且不怕比劫分夺；财无库又被比劫分走＝营业额大利润薄。
- **经营链条缺哪环**：食伤→财→入主位→库 → 见财无食伤＝无稳定项目；财不归主位＝热闹所得少；入主位无库＝被成本人情耗掉。
- **独营还是合伙**：主位取财是否依赖比劫 → 日时之字能独自合住制住宾位财＝宜独营；比劫助日主共同制财且所得有库可收＝可合伙；比劫争合同一财＝为利润控制权起矛盾；合而不入主位＝口头或短期。
- **开业、关停**：财源、财星、月柱是否同动 → 三者同动才开业；只见财无食伤＝只是投钱；关停＝食伤受制、财入墓、月柱被合闭；月柱伤＝店面行业变，日时伤＝本人或内部资金原因退出。

## 十五、财

### 贫富
- **钱从哪来、变成什么**：生财食伤的宫位；财去生谁、被谁合 → 食伤在年月生财＝来自市场客户，在日时＝个人技术；年月财被日时合回＝外财入家。财生官杀＝投到事业税费；生入日时官印＝转成房产身份。
- **岁运财事拆四步**：谁到位 → 食伤到＝财源动；财到＝成交；主位功神到＝本人能取；库到＝转成积蓄。只见财而功神伤＝收入越大支出越大。

### 工薪与经营
- **工薪还是经营**：财经哪条路线进主位 → 财从官印路线进＝工资奖金；食伤生财且主位能合制收财入库＝经营；食生财后财再生官＝收入挂在职位考核上。
- **横财能不能取**：承财条件＋大运 → 须偏财有根、食伤能生、比劫能取、日时有库；偏财虚透＝只是消息承诺；大运官杀攻身而偏财生杀＝见财实增债务。

### 聚守
- **取得不等于守住**：财进主位的方式及下一步 → 日主合财＝凭本人能力取得；日支合财＝经家庭、配偶、门店取得。有根有库或转成房产事业才守得住；到手就去生宾位官杀或被年月比劫合走＝仍外流。
- **是不是真财库、归谁**：库中所藏、宫位、谁控制 → 库中须藏命主的财星；在日时＝自家收藏，在年月须主位打开或合入才归己；被比劫控制＝共有；受官杀控制＝受贷款合同约束。
- **房产、现金、晚景**：财与主位印；时柱 → 财进主位印＝收入转房产；财坏唯一印＝卖住所求财；印多财少＝有房现金紧。时柱比劫坐财＝晚年仍有人分财。

### 破财负债
- **比劫克财是取是夺**〔存疑〕：财与比劫各在主宾何位 → 财在年月被日时比劫制＝取财；财已入日时而比劫从宾位来合克＝分钱、借款不还、客户被抢。
- **被套、被谁坑**〔存疑〕：合财之字属主属宾；财被宾位哪类字带走 → 合财之字在主位且合后仍能做功＝落实，否则本金被套。被比劫合走＝熟人；被官杀引走＝合同罚责债务；印受伤＝手续凭据出问题。
- **替人担责**：财生官杀后官杀与日主 → 官杀又合入或冲入日主＝担保、代签、代持；有印化杀＝可经制度解决。
- **先出后得还是重损**：流出之财的去向 → 生有用官印＝先出后得；有印化、有库收、有财源续生＝损失有边界。

## 十六、男命婚姻

- **妻星不坐妻宫算不算有妻**：财星与日支有无合、生、墓库 → 年月财被日支合入＝从社会、工作圈得妻；时柱财与日支相连＝婚缘偏后；星宫完全不接＝相识多、定婚难。
- **星宫生克方向**：妻星与日支 → 星生宫＝妻对家投入多；宫生星＝婚后资源向妻方倾斜；宫制住宾位财＝能把外部婚缘落实。
- **妻宫逢合是合进还是合走**：合日支之字 → 是宾位财＝把妻合进家；是比劫＝旁人介入、亲友牵制。
- **妻子性情与能力**：妻星坐支十神、根源 → 坐印重保障，坐食伤有技术审美，坐官杀担责压力大，坐比劫独立有主见；得食伤生又进主位＝能谋生且助命主。
- **妻方家境能否为我所用**：妻星落宫与有无合入日时 → 财在年月得令有库＝妻家基础稳；合入日时＝得妻方资源；被别字合走＝有而不为我用。
- **落实的分层**：大运是否先接通妻星、流年是否再动妻宫 → 财透合日主、妻宫被财合动、大运接星＋流年动宫＝落实；只来一个财年＝认识、议婚。

## 十七、女命婚姻

与男命同构处不重列。

- **夫宫坐什么**：日支十神 → 坐官杀＝夫星到位；坐财＝婚后为夫事业家计付出；坐印＝带照顾依赖；坐食伤＝主见强，好坏看是否直接伤夫星。
- **丈夫有没有位**：官杀的根源与进主位的方式 → 有财生有根、再被主位印化入＝丈夫有平台身份；旺而在宾位攻身无印化＝只是压力约束多；食伤制的是宾位七杀＝夫妻共同对付外部困难。
- **配偶助力化成什么**：官杀—印—日主这条链 → 官杀生印、印生身＝丈夫的事业人脉转为我用；直接攻身无印＝带来的是压力；食伤—财—官相接＝命主能力反助夫。
- **合夫宫的是谁**：岁运合日支之字 → 就是原夫星＝夫妻重新靠近；原夫星受伤而他字合宫＝外缘介入的可能增大。
- **认识、变动、成婚之分**：星与宫谁动 → 星现宫不动＝认识；宫动星不真＝生活变化；星、宫、主位同接才成婚。

## 十八、夫妻主次与相处

- **婚前婚后侧重**〔存疑〕：星与宫的先后 → 婚前星重于宫；婚后看日支之字怎样做功。
- **谁做主**：日支与宾位财官的制合方向 → 日支之字制住宾位财官＝命主有决定权；外部财官合入日支并被日主承接＝配偶话语权重；男命财坐日支得食伤生＝妻管钱；女命日支食伤有力制官杀＝妻在家内有主见。
- **相处模式**：日支十神 → 印＝重长辈意见；比劫＝近似伙伴、财务宜分；食伤＝有财相接会商量，直接伤官杀则挑剔；官杀＝家规多。
- **聚少离多**：星宫是否分居宾主、有无合生 → 星在年月、宫在日支而无合生＝配偶常在外；星被合到年月＝长期忙外，被日时合回＝常出差仍归家。宫与月支冲＝因工作父母，与时支冲＝因子女、事业结果；星宫贴身相战者分开反减冲突。
- **矛盾形态**：天干冲克，还是宫逢刑穿破合 → 天干冲克＝说得出口的争吵；宫逢刑＝旧事重提；逢穿＝不吵而隔；逢破＝小事消耗。
- **冷淡与分居的长短**：配偶星的根与去向 → 星有根暂入墓＝阶段性疏远；星弱而岁运再合去克尽＝长期失联；下步运把星合回主位＝阶段性。
- **牵连从哪来**：冲夫妻宫之柱；配偶星去向 → 年月来冲＝源自双方父母、单位；时柱来冲＝源自子女住房；配偶星生官杀攻身＝配偶债务压力转到命主。

## 十九、情缘外遇

- **咸池落不落实**：咸池落宫 → 在宾位不入主位＝别人关注而已；合入日支且本身是配偶星＝落实为婚缘。
- **外部异性靠近**：宾位异性星与主位 → 男命宾位财合日主或入妻宫、女命宾位官杀合身或入夫宫；已婚而原配星宫未伤＝伙伴、客户、应酬。
- **多情还是交叉**：主位取几位 → 主位只取一位、其余停在宾位＝终有归属；主位同时合取两处＝反复。
- **配偶一方有外情的取象**：配偶星被谁合＋夫妻宫向哪去 → 男命妻星被宾位比劫争合且妻宫与外位暗合；女命夫星被食伤牵制且夫宫向年月发生关系。
- **情缘起止**：星的出入与宫的冲合 → 起＝配偶星透出、出库，或宾位异性星被合入主位；止＝合局被冲开、星入墓无引、星被合到宾位；冲开旧合后有新字相接＝调整而非分手。

## 二十、子女与生育

子女星用主库取法（男官杀、女食伤）。标〔食伤〕的条目，书是专就食伤立论的。

- **子女信息实不实**：子女星与时柱有无合、生、入墓收纳 → 有才算接通；星旺宫伤＝养育不省心；星从年月生到时柱＝晚年见子女成就。
- **来得早晚**〔食伤〕：食伤的状态与早运 → 年月得令且早运生扶时柱＝早；藏日时待透＝先立业后育子；被印合闭，行财运制印时信息增强；藏库逢冲而根不坏＝添丁，根已弱再猛冲＝计划反复。
- **管教结果**〔食伤〕：时柱印与食伤 → 印直接制食伤＝管束多发挥受限；食伤另有财转化＝管得严而有成。
- **生育后家里怎么变**：日支与时支 → 相生相合＝衔接顺；相冲＝居住工作分工变动；相穿＝家人配合出问题。
- **操劳有无回报**：日主—子女星—财官这条链断在哪 → 生到时柱气势即断＝长期投入难见效；时柱有财官相生＝配偶与现实资源共担。
- **能否享子女福**：时柱成果是否回流日柱 → 时柱生扶日柱＝愿照顾；时柱财官经印流入日主＝子女所得改善家里；子女星在宾位做功而不接日时＝事业好但远居；时柱财官被年月合走＝所得归其自身或配偶家。
- **子女离家**：时柱与年月的冲合 → 时柱去合年月财官＝进外部平台；时柱有功、冲后取到财官＝越动越好，无功受冲坏＝只是不稳。
- **看子女的婚业（换主位）**：把时柱立为子女的主位 → 时柱与年月财官合＝婚业由外部带来；被日支合住＝受父母家庭影响；财官落时柱而无功不断富贵。流年动时柱：逢合＝定关系、签约，逢冲＝换工作、婚后另居。

## 二十一、住宅

- **十神分工**：印、财、官杀、食伤 → 印＝房屋、契约；财＝购房资金；官杀＝产权、贷款压力；食伤＝装修使用。印多不等于房多，看能否被主位取得。
- **住处哪里不安**：日支所受作用 → 受刑穿＝室内不合用、反复修补；被时支冲＝后期因子女、置业改动住所。
- **祖宅去留**：年柱印与月柱、日主 → 年印有根并生到日主＝承接祖宅；被月柱财制＝出售分割；年印被合到宾位而日时之印入主＝祖宅归他亲、自己另买。
- **新宅与迁居次数**：时柱财印与日支；日时之冲 → 时柱有财印并合入日支＝后来另置；日时只冲无承接＝搬得多，冲后有合有库收＝终能安定。
- **名下有多少、钱从哪来**：印或土库能否进日时 → 不数印星；库须由主位开取，在年月被别人合住＝祖产或共有；库冲开后财印入主＝购房，财散到宾位＝出售。食伤生财＝靠经营收入；官印相生＝靠单位、贷款；比劫制财而财入库＝共同出资。
- **买、卖、迁的应期**：大运给条件，流年动日时 → 财透并生合日时＝资金到位；印入主位＝签约交付；只动其一＝筹款或看房。日时印被合向年月＝转给他人；财冲开印库＝以房换钱。年月来冲日时＝外部推动、距离远；日时内部相冲＝家庭原因。

## 二十二、迁移出行

- **主动还是被推**：年月与日时谁冲谁 → 年月冲入日时＝被环境推着走；日时冲制年月＝主动向外；动而取到财官＝有得，只伤日主根气＝奔波无果。
- **月支的去留**：月支所受冲合 → 被日时支冲开＝守不住原生活圈；合住主位＝留本地；合向年柱＝被外部单位亲友带走。
- **驿马动是得是劳**：马是否功神，合冲后能否完成原局之功 → 马得财官或为功神＝越动越有机会；受制又伤主位＝多劳反复；马为所用而被合＝延误，为忌被合＝反少奔波。
- **成果归谁**：年月官杀财与主位 → 年月官杀有印化入日主＝靠外地平台；日时食伤制年月官杀＝靠技能取位置；财官被年月别字合走＝成果归单位或合伙人。
- **有无归处**：时柱；冲后有无合库 → 时柱能收财官＝所得沉淀；财入时库＝在外赚回乡置业；时柱被年月合走＝安家异地；冲后有合或入库＝多变后落脚，只冲不合＝长期奔波。
- **卡在哪、先动哪**：压在月柱上的十神；流年引动哪柱 → 月支被合闭＝卡在手续、单位、家庭；官杀压月柱＝受审批合同制约。动年柱＝远方机会出现，动月柱＝单位变，动日支＝住房婚姻同变，动时柱＝新落脚处。

## 二十三、人际合伙

- **人缘能不能用**：宾主之间有无情，不看比劫多少 → 外面财官能进日时＝关系可为己用；比劫满盘争财＝人多帮少。
- **朋友是助力还是分利**：比劫所在宾主位 → 在主位制宾位财、抗官杀＝朋友成为自己的手段；在宾位争主位之财＝因朋友损利；官杀制比劫＝能在制度下共事。
- **合伙人可靠否**：合财之比劫的虚实、财库在主在宾 → 比劫合财而财有归处＝目标一致；把财合到宾位＝对方掌资源；虚浮比劫合财＝只说不做；财由主位之库收藏＝账清。印护住财官＝有合同支持；七杀无制进入日时＝受对方债务牵连。
- **上级是否真帮**：官杀虚实及与印、伤官的关系 → 官杀虚透＝实助有限；印从官杀生到日主＝愿提拔；伤官制官正是原局之功＝敢处理问题而得实权，官为护日主之字而伤官来破＝因言语影响职位。
- **下属与客户**：食伤、比劫、时柱；财的柱与合库 → 食伤有财承接＝执行有结果；时柱比劫争财＝团队内争功。财合入日时＝客户能变收入；财被比劫合走＝客户转投同行。

## 二十四、伤病

病位与病名取象用主库（05 五、02 八）。本节只补轻重与救应。

- **冲日支应在哪方面**：被冲之字是日主的什么 → 是根＝身体承受力受损；是印＝休息恢复被打乱；是财＝因经济、配偶、工作而劳累。
- **刑、穿是增病还是去病**：刑后结果；被穿的是所用还是所忌 → 刑开墓库、引出功神＝可应手术、矫正等主动改变；穿到所用之字＝不剧烈但拖延，穿到忌神＝有时反解郁滞。
- **手术还是突发**：金、官杀、食伤、印与岁运 → 金取器械，食伤取切割排出，印取医疗恢复；岁运冲入病位而同时有印或官杀制化＝主动检查、术后改善；只见冲刑无救＝突发与反复。
- **及时还是拖延**：应事之年的印与财 → 印透有根＝及时处理；财来耗印＝因工作经济顾虑拖延。
- **意外轻重**：冲到的是忌是用 → 冲到忌神而日主得救＝有惊无险；冲到所用之字无救＝影响深。

## 二十五、是非官非

- **官杀算不算无制**：有根否、有印化否、有食伤制否 → 虚透＝名义上的批评；坐旺贴身而日主无根无印＝重。
- **纠纷从哪来**：官杀所在宾主位及同来之十神 → 从年月压入日时＝来自单位、平台、政府；伏在日时＝在家庭、合作；与财同来＝因钱债；印被财坏＝凭证不足。
- **伤官见官应何事**：官是所求还是所忌；伤、官各在何柱 → 官为所取之位而伤来破＝失平台、得罪上级；官为忌而伤有力制＝突破限制。官在年月＝对象是单位领导，在日时＝牵连配偶、合作人；天干紧贴＝公开，地支暗战＝私下投诉。
- **伤官见官的走向**：伤、官之间有无财 → 伤生财而财入主位＝未必有祸；财再生官＝反得职位；越过财直接克官，官有根伤无根＝口舌冒犯；伤旺官弱＝辞职或自营。
- **合同站不站得住**：财（标的）、官杀（责任）、印（凭据） → 三者流通＝有规则可循；财旺印伤＝重利轻手续；日时之财被年月比劫合走而官杀又压身＝内部争账转诉讼。
- **诉讼谁主动、证据如何**：主宾谁发动；印的状态 → 主位发动制宾位＝命主追讨维权；宾位官杀冲入主位＝被追责索赔；印能护主＝证据有利，印被合坏或墓闭＝关键资料缺失。
- **起止与收束**：流年引动的是伤、官还是财 → 只引伤官＝命主主动申诉离职；只引官杀＝外部问责；伏吟＝旧事再起；合住矛盾之字＝暂缓或和解。印＝证据程序，食神＝协商方案〔存疑〕，财＝赔偿调解；有根能收束，虚浮则拖延。

## 二十六、岁运

- **大运以何种方式入局**：运与原局做功结构 → 扶起原局已有之字；补入原局所缺之字〔存疑〕；破坏原有结构。
- **流年冲合某支应何事**：被动之支的宫位＋所藏十神 → 宫位定人事范围，十神定事情性质，作用定发生方式。
- **藏干透出后的结果**：透出之字的状态 → 被合＝事因合作关系而来；受制＝有事能处理；无根＝声势大结果小。
- **同年吉凶并见定主次**：流年各处作用与大运主线 → 顺着大运做功的为主事，另碰到的宫位为辅；财入主位为得、合到宾位为失；末了看所得能否保存。
- **象到与事到**：命主现实身份 → 引动婚宫，未婚应相识订婚，已婚应配偶工作变化；引动官杀，从政应职位，经营者应监管，职员应考核。

## 构造盘示范

以下为书中例盘（整理者判断为构造），只示范机制，不是命例。所选八盘遁法皆合，在 1840–2030 年间都排得出（2026-10-11 用新脚本复核）；遁法不合的未入选；筛选时标出的问题附在盘末。

1. **庚申 丙戌 丙午 己丑（坤）**｜财的来路与归处｜年柱庚申财在宾位，月干丙比肩隔在中间，早年求财有分利；时干己伤官从主位生庚，财归时支丑库；午丑相穿，得结果时伴随家庭牵扯。（起运不符）
2. **庚申 壬午 甲寅 丙寅（乾）**｜制化并存定职业｜年柱庚申杀＝外部规则、设备、风险；月干壬印化杀，时干丙食神从主位制杀，取工程技术、风控一类。丙戌运食神得势、流年再引出财，才转独营。（申与寅之冲、寅午半合书未论；起运不符）
3. **己丑 甲戌 乙未 丁亥（坤）**｜有产可争，不等于富｜年柱己丑为财，戌未皆财地；月干甲劫财合年干己财，又丑戌未三刑全，断亲族因产起意见；时干丁食神生财而亥中甲助劫，所得分流。
4. **甲申 己巳 乙丑 庚辰（坤）**｜父星被年柱比劫合住｜月干己偏财为父星，坐巳得伤官生＝凭技术求财；年干甲劫合己＝为兄弟亲友分担钱财。丙寅运寅冲申、穿巳，父宫动；丑年伏吟日支＝父事由命主亲办。
5. **庚申 壬午 丁卯 甲辰（坤）**｜冲夫宫而夫星得生，不断离｜壬官在月，庚申财生之，丁壬合，夫星进主位。辛酉年酉冲日支卯，但辛生壬，应搬迁调动。（卯辰穿、卯午破书未论）
6. **辛酉 庚寅 戊辰 壬戌（乾）**｜子女外出；换主位看子女｜庚辛食伤透年月，寅中甲杀取子息；辰戌冲＝自家与子女宫相动。丙戌运时柱伏吟＝子女离家成家；以时柱为主位，卯年卯戌合＝子女定婚，辰年冲＝搬迁换岗。
7. **壬申 戊申 丙寅 庚寅（乾）**｜主位之根冲取宾位财杀，走出去才接通财官｜年月两申藏财杀在宾，日时两寅为根在主，两寅冲两申＝不止一次迁移；时干庚把财带入主位。申年年月伏吟＝外部先变，寅年日时伏吟＝本人主动调整。
8. **戊午 甲寅 癸酉 庚申（坤）**｜伤、官各自有根且天干紧贴才成伤官见官，主位印制伤护官｜年干戊官坐午、月干甲伤官坐寅；日时申酉印＝书面依据与程序。寅年伤官伏吟＝己方先起，午年官得根＝规则正式介入，申酉年印强＝易收束。（起运不符）
