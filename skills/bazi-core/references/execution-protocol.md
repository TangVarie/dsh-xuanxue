> 本文件只管"怎么走"：输入契约、四种入口、阶段状态与条件出口、追问复用、执行记录、P0–P10 每一步做什么。

## 一、输入契约：排盘参数卡

每次任务维护一张参数卡。`scripts/paipan.py` 会自动打印，手里只有用户的话时也按这张卡记。

| 项 | 说明 |
|---|---|
| 原始日期、原始时间 | 用户原话照录，和计算用时间分开存 |
| 历法 | 公历 / 农历；农历要说明是否闰月 |
| 出生地、时区、夏令时 | 时区不给按 UTC+8，标"默认"。给 +8 这类固定偏移时，夏令时未说明按否计算，日期落在中国 1986–1991 年夏令时期内列出另一读法；给 Asia/Shanghai 这类时区名时，由时区库判断并扣除夏令时，用户没说明时同样列出另一读法 |
| 是否已校正 | 用户给的是钟表时间，还是已经校正过的平太阳时、真太阳时 |
| 采用的时间口径 | 不修正 / 经度时差修正 / 真太阳时（经度时差＋均时差） |
| 换日口径 | 默认 23 点换日；可改 0 点换日（晚子时） |
| 性别 | 排大运需要；不给不默认男，两种顺逆都列 |
| 四柱来源 | 由时间计算 / 用户直接给 |
| 起运资料 | 由时间计算 / 书上所记 / 未提供 |

规则：
1. 用户明确给出的参数优先；已经确认的不重复问。
2. 只有当参数差异会改变**本次要回答的结论**时，才追问或建立有限候选；不影响结论的缺项照记不问。
3. 默认值必须在参数卡上可见。不静默按男性、北京时间、某种换日口径处理。
4. 原始出生时间与用于计算的时间分开记。用户给的已是校正时间，禁止再按经度校正一次。
5. 经度修正只叫"经度时差修正"；加了均时差（`--eot`）才叫真太阳时。脚本的均时差用近似式，误差约一分钟内，临界时照样列候选。

| 输入情况 | 做法 |
|---|---|
| 公历出生时间与必要参数完整 | `paipan.py --date "YYYY-MM-DD HH:MM" --gender …`，生成完整排盘与参数卡 |
| 农历 | 加 `--lunar`；该年有同号闰月而用户没说时，脚本停下要求 `--leap yes/no`，两种换算都列出 |
| 只有四柱 | 先 `check_chart.py --pillars` 查结构和历法候选；可成立的原局分析继续；起运日期标"未提供" |
| 只有日期没有时间 | `paipan.py --date "YYYY-MM-DD"`：不依赖时柱的部分照做，依赖时柱的结论标"暂缺"；当天交节时年月柱也列候选 |
| 出生时间在边界或有两个候选 | 加 `--uncertainty 分钟数`；脚本列出候选盘，只对受影响的判断分支 |
| 已提供校正时间 | `--basis mean-solar` 或 `true-solar`，记录口径，不再校正 |
| 信息互相矛盾 | 指出冲突字段和受影响范围；其他可完成的部分继续 |

## 二、四种入口

| 入口 | 什么时候 | 内部执行 | 用户看到 |
|---|---|---|---|
| **全盘分析** | 给了盘，要"完整看一遍/批八字/全面分析"，或没说看哪方面 | 所有适用的 P0–P10 | 完整报告（默认标准档），缺失信息有明确说明 |
| **专题分析** | 带着具体问题来（婚姻、今年财运、哪年成事、身体） | P0–P4 内部必做；相关分科；P10；问题涉及时间才展开相应 P9 | 先答所问，再给关键依据与必要核验 |
| **同盘追问** | 同一命盘在本会话已分析过，接着问 | 复用仍有效的参数和结构记录，只补跑受影响部分 | 直接回答新问题，不重复整份报告 |
| **历法／文献校验** | 核对文献例盘、抄写错字、一批盘的历法一致性 | 只做资料整理、`check_chart.py`、来源状态登记 | 检查结果与疑点；不做人生分析 |

**追问复用的前提**：对象相同；出生参数与分析口径相同；技能版本和相关规则没变。任一条变了，重算受影响的部分；拿不到可靠的前文记录，就按需要的范围重建，不凭印象接着说。

## 三、阶段状态与条件出口

每个阶段结束时登记一个状态：

| 状态 | 用在什么时候 | 接下来 |
|---|---|---|
| 已完成 | 本次所需的输入和计算都齐了 | 进下一阶段 |
| 部分完成 | 能处理一部分，缺的信息不全面阻塞 | 继续已支持的部分，标出哪些判断依赖缺项 |
| 不适用 | 用户的问题不需要这一项 | 说明或内部登记原因 |
| 候选并行 | 有限几个候选排除不了，而且会改变相关结论 | 保存共同结论，差异部分分支 |
| 阻塞 | 缺项使本次核心问题无法有意义地计算 | 明说缺哪一项、为什么影响核心问题 |

**不算全局阻塞的**：缺历史事实（标"未验证"照做）；缺 `oracle-grounding`（用 `output-and-verification.md` 的内置表达协议）；没指定目标年份（给近期窗口或问一句，不停分析）。
**局部阻塞的**：缺起运资料，阻塞精确的流年定位，不阻塞原局分析。时辰不确定，不依赖时柱且在候选间一致的判断照常做，依赖时柱的分支保留。
**真阻塞的例子**：只给了一个年份没有月日；四柱遁法不合且无法判断哪个字抄错。

全盘报告九段里的条件段按适用性展开（见 `output-and-verification.md` 第一节），不为凑齐段落编内容。

## 四、执行记录（内部，轻量）

内部维护一份记录：本次问题与时间范围、参数卡、候选盘、各阶段状态、结构摘要（势/主/功/层级/正反局）、主要结论、依据与反证、验证状态。

每条**重要结论**（会写进"本次主要结论"、会被追问复用、或带应期的）记这些字段：

`结论ID｜对象与时间｜依赖的前提｜方法来源｜支持线｜反对线｜标签｜验证状态`

修饰语不必建档，整份记录也不必展示给用户。用户要看推导时按详细档展示。P5–P9 先形成待核验结论，P10 处理事实冲突、适用条件和标签后再定稿；中途改过的，留下改前改后，不覆盖原判断。

## 五、P0–P10

每个相位的"镜头"行指向 `authority-and-forks.md` 第三节的分层权威表；镜头只决定**默认分析路径**，不代表那一派已被证明正确。

### P0　排盘与校验

- **做什么**：按第一节的参数卡，把命盘钉成可检查的计算结果。
- **怎么做**：
  - 给时间：`python3 scripts/paipan.py --date "YYYY-MM-DD HH:MM" --gender male|female [--lon 经度] [--eot] [--tz] [--uncertainty 分钟]`。
  - 只有四柱：先 `python3 scripts/check_chart.py --pillars "…" [--gender] [--born 年]` 查遁法与历法候选，再 `paipan.py --pillars "…"` 出藏干、十神、神煞查表、关系扫描。
  - 关系扫描分"主库采用"和"列出但主库不采用"两组，口径按 `references/02`；夹拱（如戌子夹亥）和扩展暗合脚本不扫，按 `02` 手动补。
  - 时辰候选：脚本列出的候选盘，用 `references/09` 第 0 步的方法（中原时柱直断歌、刘军问答、素水排行诀、夏氏时支诀）对**已发生**的事缩小范围。缩不下来就带着候选走：共同结论照写，受影响的判断分支。
- **出口**：本次输入模式应有的排盘信息——完整生辰给完整排盘表；只有四柱给原局表与历法候选；只有日期给三柱与起运区间。缺什么写在参数卡和状态里。
- **自检**：地支关系两组都看过了吗？默认值都可见吗？候选盘是不是只在受影响的判断上分支？

### P1　定势＋调候底色

- **做什么**：找出谁结党（势），定全局温度湿燥（决定富贵上限与健康底色）。
- **镜头**：主＝段氏分党＋穷通宝鉴（`11`）｜校验＝中原三平衡气象、刘恒十干四季。旺衰的用法纪律见 `authority-and-forks.md` 真分叉 #2：定势、定富贵层级不用旺衰取用；旺衰只在论心理承载、合财胜任、体貌肤色时当主镜头（清娟月令 50%、时支 45%；中原三平衡），别串用。
- **怎么做**：按段氏分党——木火、金水、水木、火燥土、金湿土、水湿土（`01` 第四节）。党内有穿刑不算一党；巳火随局变性。记全局气象（寒燥湿润、阴阳比例）。查 `11` 调候表，日干在本月最缺什么。查 `11` 调候表时看喜用在不在位。查 `12`：是否一行成势，成势则按"衰旺真机·五行颠倒"判该顺泄还是该克（旺极宜泄不宜克、衰极宜帮不宜克，逆之即反局）。
- **读**：`01`、`11`、`12`。
- **出口**：什么党、谁是党魁、寒燥湿润、调候药味在不在位。
- **自检**：党内穿刑查掉了吗？泄路（如水势需木泄）通不通？

### P2　定主·立太极（真分叉 #1）

- **镜头**：主＝段氏日干法（默认）｜对手＝飞宫主形、清娟移位、素水换十神。协议见 `authority-and-forks.md` 第四节 #1。
- **怎么做**：
  1. 默认走段氏：日干有合（财/官）以合为日主之意；无合看有无生（食伤贴身）；无合无生看日支；日支也闲看禄比。日干正常做功就不触发分叉，别没事找事。
  2. 触发条件：日干无根无功，或全局一形独旺。不触发就直接用默认。拿不准算不算触发（如根被合住、落空亡、只剩余气）时，按触发处理，双跑。
  3. 触发则双跑：飞宫主形法（金/木为形，`06`），必要时加清娟弱极移位（`01` 第七节）、素水换十神（`06`）。
- **出口**：两法同一命主→立极定；不同→两套下游读法都带着走（"若以日干为主则…／若以主形为主则…"），立极标【存疑】，写出分歧点和能分辨两者的已发生事实；必须给首选时用本槽主镜头（段氏日干）暂取，仍挂【存疑】。
- **自检**：触发了却没双跑？双跑分歧却只写了一套？

### P3　找功

- **镜头**：主＝段氏做功／制法效率。
- **怎么做**：列全部做功点（合冲穿刑克墓制、化、生泄、合、墓），分主功神、辅助功神、废神；正向还是反向做功；制得净不净；效率（合制＞冲库＞冲＞穿＞克；围克特高，`01` 制法明析）。
- **读**：`01`（做功、制法效率）、`02`（合冲穿刑破墓绝的精确规则与换象）、`15` 第二节（夏氏的禄、墓、穿破、三刑、合闭用法：禄即自己、半禄、无财以禄当财；星坐墓为第一个、宫入墓为第二个；穿要先分清穿的是什么；卯戌合闭）。
- **出口**：做功全表（每个做功点：类型、效率、性质、角色）。
- **自检**：每个干支都问过"它在干什么"吗？墓库做功看了吗（库做功＞明字做功）？月令做功看了吗（月令做功最大）？

### P4　富贵层级＋正反局＋虚实

- **镜头**：层级、正反、虚实 主＝段氏；财官归属（谁的钱、几成、何方式）主＝素水出处论（吃皇粮/自营/打工）＋清娟合化效率，校验＝段氏宾主到位——别拿段氏做功一把抓"归属"，那是素水、清娟的强项。
- **怎么做**：
  - 层级：有势有功制净＝大富贵；制不净看运补；有功无势/有势无功＝中常；两党对峙、废神满盘、做功反被制＝贫贱（`01` 第八节）。
  - 富还是贵：制去财与财原神＝富；制去官与官原神＝贵；官杀制不尽当财；食伤泄秀＝学问；化用＝稳贵。
  - 正反局：日柱做功方向与全局势一致为正局，相反为反局主凶；反局五类（日支对抗、日干日支相反、冲合交叉、大运反局、流年反局）见 `01` 第六节。
  - 虚实：逐柱判天干虚实（有根有生为实、无根无生为虚），定财官印食伤的虚实含义与应期属性（`01` 第五节）。
  - 夏氏定级三问（`15` 第一节）：①被制的是明字还是库（制库高一档，库制库最高）；②被制的官、财落在哪一柱（月上最大，年上次之，日上再次，时上最小；月上之财是国家众人之财）；③火候对不对（忌神得月令只宜弱制，不得月令要制彻底；制浅主有才不遇，制过损寿）。另查是否反制格（五凶神落主位有用，大于正格）、是否带变局的祸根（从格、专旺格里那个与大势相反的字）。
  - 五道反证题（`16` 第三节排除条款）：判了"有势有功制净"后逐条问——被制的字是不是其实最要紧；大运是不是一路在扶被制的一方；是不是专旺；看着弱的字是不是当令有根有护；有没有通关之字把制神化去。任一条答"是"，层级降一档并写明哪一条。
- **读**：`01` 第五·六·八节、`15` 第一节、`16` 第三节、`12`。
- **出口**：层级、富贵倾向、正局或反局（张力点在哪）、关键字虚实。层级属四类重判断，按 `authority-and-forks.md` 第五节的默认方法线清单跑。
- **自检**：层级做了量级校验吗（库做功、月令做功、主位优于宾位）？反局张力点找出来了吗？

> P0–P4 是地基：全盘和专题都在内部做完，专题报告可以只摘要展示。下面 P5–P9 按入口选取，选中的做透。

### P5　职业（象法三定位）

- **镜头**：主＝段氏象法（`03`）｜校验＝清娟天干五合换象、素水"吃皇粮/自营/打工"三分法。
- **怎么做**：干支象、十神象、宫位象交叉取共象，再用合象、化象、墓象、制象、带象细化；配 `07` 行业速查。清娟天干五合化物取象、素水"吃皇粮/自己干/打工"三分法并用，三者都要用。
- **读**：`03`、`07`；`17` 第十二至十四节（工作手段、权从哪来、独营还是合伙的检查项）。
- **出口**：职业大类、性质（体制/自营/打工）、取象依据。

### P6　六亲

- **镜头**：主＝素水星宫感应（宫＞星，六亲星须与对应宫发生生克合冲穿才作数）｜校验＝郝原身入宫、先天基数、夏氏坐支法与墓序法。
- **怎么做**：星宫感应定位→原身入宫补定→先天基数再补。逐亲查坐基（长生禄旺／死墓绝）、有无刑穿合坏、大限卡段。父母存亡、兄弟数与排行、子女有无及头胎性别（冲穿反断注意）。
  - **同胞数**：默认路径用夏氏时支诀（`15` 第四节末）。原文只说"弟兄几个"；本库按"数同性同胞、含自己"读，这个读法是整理者从开发集反推的，见 `output-and-verification.md` 修正登记 R7，属候选。比劫计数与排行诀补异性同胞和排行；两路冲突时并列写出，不静默取一边。
  - 夏氏补法（`15` 第三、四节）：父母星看年月上所坐之支——坐死病墓绝早克，坐长生旺地则"旺怕合"，流年来合之年应；年为远方与腿脚、月为娘家老家与胸、时为门户与脸；头胎男女的十神对照与"冲穿换相"；合住子孙宫不生、枭夺食之运不生。
- **读**：`05` 第四节、`09` 第 6 步、`15` 第三·四节；`17` 第三至七节（祖业、父、母、父母关系、手足的检查项）。
- **出口**：各六亲落在哪个字/宫、坐基好坏、存亡与数目判断。

### P7　婚姻

- **镜头**：主＝段氏配偶宫·星＋好坏式｜校验＝清娟暗引、郝直断、夏氏婚姻条文。"官星可制否"已收敛，见 `authority-and-forks.md` 第四节。
- **怎么做**：配偶宫（日支）为主、配偶星为辅（男财女官；无财看食伤为妻，无官以印或财当夫）。套好婚四式、坏婚六式、独身四式。多婚数＝坏宫之字数或星数。婚期：原局有合应冲年、有冲应合年、无冲合应合年，加星宫同动；离婚应期＝坏星透干、穿宫、天地合绊之年。
  - 夏氏补法（`15` 第五节）：与配偶宫有关系的字就是配偶星；宫穿星，死一个离一个；星坐墓为第一任、宫入墓为第二任；财官入墓晚婚不婚，"合而不冲"库不开；配偶星在年时且与宫有合主远方，在月主本乡；冲宫之年离、合宫之年再婚。
  - 婚次、离、丧属重断，先过重断门槛（`authority-and-forks.md` 第五节）。
- **读**：`05` 第三节、`04`、`15` 第五节；`17` 第十六至十九节。
- **出口**：婚姻好坏式、婚次、婚期与离异的时间窗口。

### P8　身体与凶灾官非

- **镜头**：生死凶灾大关 主＝飞宫形气（水火两气俱灭＋金木形根被伤）｜校验＝中原反吟伏吟三原则、段氏气象。病位 主＝段氏穿害病位｜校验＝中原干支死律。
- **怎么做**：全局气象（过寒过燥）→ 连体、根、禄是否受制 → 穿害对应病位（丑午癌糖、子未妇科、申亥颈腰、寅巳手术等，见 `02` 第八节）→ 凶死复核用飞宫、中原三原则。修正登记 R3"大运支被日支冲＝该运常驻弱点"属候选，只当检查项。
  - 牢狱与凶事（`05` 第六节＋`15` 第七节）：夏氏牢狱七条（印受伤、财坏印带刑穿、伤官佩印被冲、比劫与官杀对抗、伤食入墓或被枭夺、伤食穿官杀、禄被穿）、不走正道三条、羊刃无制逢合冲穿、年时伏吟反吟与门户逢冲主出走。原局有此象才查应期；没有就明说没有。
- **读**：`05` 第五·六节、`15` 第三·七节；`17` 第二十四·二十五节（轻重与救应）。
- **出口**：体质底色、易损部位、高危运年（凶死之断只点防范年份）、有无牢狱官非之象。

### P9　大运逐运＋流年应期

- **镜头**：无单一主镜头，全矩阵平权——段氏禄原身/遁藏透干、清娟数星动、金口诀串宫压运、中原岁运君臣民、飞宫生死校、夏氏应期句式（`15` 第八节）、陈氏限法与句法（`16` 第一·二节）。各自独立算，看收敛；怎么计票见 `authority-and-forks.md` 第五节。
- **怎么做**：
  - 大运：逐运判正局加力还是反局；功神当值还是被绊；干五年支五年分看（干用支体）。反局之运预警牢狱、下台、破败；交脱诀讲明（限应凶而后有吉运，未到吉运必先应凶，最险）。
  - 年龄窗两套：`04` 大限（年 1–18、月 18–35、日 35–55、时 55 后）与陈氏限法（每柱十六年、每字八年，`16` 第一节）。两套都罩住的年龄段可作两条线，只一套罩住的只算一条。
  - 流年组合拳（`04` 第九节）：大限卡年龄段→大运定基调→流年找引动（禄、原身、遁藏透干、填实、合冲穿到位）→数星动逐一拆事件（清娟式：一年引动几组就断几件事）→多线索同指一年才下重断。
  - 修正登记里与应期有关的 R4、R5、R6 按各自状态使用（`output-and-verification.md` 第三节）。
  - **缺起运资料**时：原局与大运方向照做，流年定位标"部分完成"。
- **读**：`04`、`01` 第六节、`15` 第八节、`16` 第一·二节。
- **出口**：大运总轴（每运一句基调）、当前运细批、近年逐年——从当年起连续五年，每年都写一句，没有明显引动的年份写"无明显引动"，不跳年。时间精度跟着依据走：能支持到月就给月，只能支持到年或时间窗就写到那一级，不编月份。

### P10　核验、定稿与表达

- **怎么做**（规则都在 `output-and-verification.md`）：
  1. **对照已知事实**：用户给了经历→逐条标一致、偏差、未覆盖，并按第二节登记验证状态。推导前就看到的事实只能叫"已知事实拟合"，不叫盲测。事实与某条结论直接冲突，只处理受影响的判断；偏差按第三节的错因选项归因，可以是"当前规则无法解释"；回复里怎么说按第三节第 1 小节。
  2. **定标签**：按 `authority-and-forks.md` 第五节计票，处理反证后定【铁断/推断/存疑】或不作判断；验证状态另列。
  3. **建模**：结构向量卡（势／体用／主功神／层级／正反局）；三条贯穿线（贯穿一生的主题）；详细档另给引擎权重与置信分层（哪几层强、哪几层弱）。
  4. **可检验的预测点**：写成具体可观测事件＋依据支持到的时间窗＋什么结果算不中，并列预设复测点（哪一年的什么事检验哪条机制）。
  5. **化解与建议**：清娟调候法的生活化通关（方位、颜色、认亲、择业择城），按内置表达协议（`output-and-verification.md` 第五节）；`oracle-grounding` 在场时可作增强层。
  6. **开口次序**（`09` 第 11 步）是可选的传统话术，不是强制流程；默认先答所问。凶事给出路、吉事留余地、危命只点防范年份不说死。
- **出口**：核验段（含验证状态）、建模段、本次主要结论、可检验预测点、建议、待验证清单。
