## 二、使用情境（模型行为抽测）

做法：让独立的模型实例只读本包、按 SKILL.md 处理 `tests/scenarios.yaml` 的输入，输出它会发给用户的回复，再按每条的 must / must_not 人工判定。同一模型族自测，结论只说明"这套文字能把模型引到预期做法"，不等于其他模型或线上环境同样成立。
