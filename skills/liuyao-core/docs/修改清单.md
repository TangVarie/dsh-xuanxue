## v5.2 → v6.0（规则版本 r6.0，2026-10-12）

按七部分迭代方案逐项列出改了什么、落在哪。冲突逐条的处理见 `docs/冲突清单.md`（C01–C50）。

## 一、规则统一

- **文件职责固定**（SKILL 第七节有表）：SKILL 只管范围、模式、必要输入、读取路由；`00` 管推演与纠错、降级、冲突；`11` 管默认规则；`20` 管触发与反证；新增 `22` 输出协议、`23` 落地协议、`24` 规范示例。
- **默认规则只定义一处**：`11` 第二节改为默认规则总表 R01–R26，吸收原 SKILL 第六节、原 `20` 第三五节、原 SKILL v5.2"断语标源"四条；开镜总则原来写了三遍，现只在 `11` 第三节保留一份。
- **新写定的默认**：R06 静爻受生（"不动之爻不得生"降为邵/林派说法）、R07 月冲值日之爻、R08 三合成局、R10 土的寄生、R12 合墓解墓（未决）、R21 象法只作描述、R24 起卦方式、R25 做局与再占、R26 静爻值临日月能否通关（未决）。
- **过时指令同步**："双镜一致→置信度高"删去；"中高"删去；各专题里把单派规则写成铁律的地方改标派别。
- **历史材料**：`10`、`06`、`07`、`08`、`15` 里的人格、真心、第三者、死期、选股类说法保留，标"原作者观点"，引用方式统一由 `22` 九.5 规定。
- **卦例**：`13` 每例加【适用】标记——默认样本 / 技法示范 / 退出默认模仿 / 含越界断语。例11（单盘断"有妇之夫"）、例16（梅花体用）、例19（进行时翻吉凶）、例20 退出默认模仿。
- **来源说法**："平均八成准""七成""80% 癌症"等集中登记在 `11` 六，标"未经本包数据验证"。
- **明显错误**：`14` 示范 B 六二"○动"改"×动"；铜钱字背补两种相反约定的提示；`02 书``01 邵伟中`等原始资料编号与 references 文件号撞号的地方改写；指向 `_digests/` `_newmat/` 等不存在路径的引用全部改为"未随包分发"；`03` `09` `10` 里失效的旧条目号改指 R 编号。

## 二、四种模式与输入

- 完整解卦 / 单点追问 / 对照与复盘 / 资料解释，判定与各走哪几步见 `00` 〇。
- 输入改为"只追问会实质改变判断的信息"：`00` 0.2 一张表列出各项何时必须问、何时不问；性别只在婚恋等取用依赖时问；前卦有记录就引、没有不追问；原话已说清关心哪一面就不再拆候选用神。
- **修订通道**（`00` 十）：用户纠正问题、补关键事实、发现排盘错误时可重定主用神与主判；附"改了什么→必须重算什么"的依赖表；原登记保留、修订追加。

## 三、输出

- 默认五段：简明卦盘 → 主判（含置信度）→ 依据与反证（含"双镜一行"）→ 应期及条件 → 对应建议（`22` 二）。
- 逐爻推演、编号判词、核对项、应期四列表、记录表移到"详解展开"，只在用户要求、重大分歧、复盘时出（`22` 三）。
- 备选只留会改结论的；应期上限不作填满目标；建议只在涉及决定时给，纯解释不给行动卡。
- 置信度固定三级，定义为"依据清晰度与规则稳定性"，五项检查加降档项清单；Jev 概率、双镜一致性、现实发生可能分开写（`22` 七）。
- 断语边界集中在 `22` 九：不断心、第三者门槛、健康不写病名死期、不选股、旧资料引用规则。

## 四、排盘与换算程序

- `scripts/paipan.py`：爻值 / 符号 / 卦名动爻 / 本变卦名 / 铜钱（须指定字背约定）→ 本卦变卦、卦宫世应、纳甲、六亲、伏神、旬空、六神、甲类机械触发清单；`--verify` 对截图读出的字段出差异清单，读不清的字段保持未确认；`--date` 遇边界时各候选分别算出并列出差异。只依赖标准库。
- `scripts/ganzhi.py`：公历→四柱干支。月建按节、年按立春、日按换日约定；节气交接前后 60 分钟内、只给日期且当天交节、23～24 点未指定换日约定时标"未确认"并给候选；支持时区；装了 sxtwl 时自动交叉核对。只支持 1900–2100 年。
- 自动化只处理确定性数据，不评吉凶。

## 五、共享依赖与 Jev

- `23` 包内最小落地协议：两阶段隔离、三段链翻译、建议锚回依据与排除项、行动卡按需；外部 oracle-grounding 作增强，冲突时以本包为准。
- `scripts/jev_judge.py` 重写：只收"来意摘要"，含卦名、爻象、干支等卦盘信息一律拒收；返回结构逐题校验（缺题、题型、选项、概率范围与总和、答案与概率一致性）；所有失败统一为 `status` + `error_code`，任何异常都被捕获；`usable` 只在 `ok` 时为真；总耗时上限（默认 25 秒，含重试与等待）。
- 题库升 jq-v0.2，补 `wenfa_type`（问法类型）；金标准升 jg-v0.3，字段改"来意摘要"，补问法类型期望与 3 条新例。
