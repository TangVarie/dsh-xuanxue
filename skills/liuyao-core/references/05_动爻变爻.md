# 05 · 动爻 · 变爻 · 反吟伏吟

> "卦不妄成，爻不妄动，天机尽泄于动、变之间"（曲炜）。动爻揭示发生了什么，变爻揭示起因/结果。动变是断卦的"中心点"。

## 一、动爻的作用
- **唯有动爻能释放能量、行使生克**（暗动等同发动，但力稍逊）。"不动之爻不得生"是邵/林派规定，本包默认见 `11` R06。
- **动爻只生动爻，但可克不动之爻**（邵）。
- **衰爻发动照样能克旺静爻**（张鼎）；**回头克力量最大**，超过原卦中之克力。
- **作用范围/优先级（张德）**："动变最优先"（动爻最先作用本位变爻）；动爻越位作用它爻时——动爻优先、近者优先、合冲优先。
- **虚化（张德）**：明动会使其它爻被动"虚化"（牵一发动全身）。虚化之爻功能≈静爻；若非持世/临应且虚化临月日，可不看。

## 二、动爻与变爻的关系（难点，邵/曲/张德对照）
- **变爻＝第二层次（曲炜）**：变爻能生克主卦动/静爻，主卦爻无权生克变爻；变爻生克权由日月定。
  - **作用范围**：变爻与本位动爻有生克合冲时**只作用本位爻**；无此关系时**才**作用其它旁爻（例：未动化申，金泄未无生克关系→申可越位冲克主卦寅木）。
- **动爻也能生克变爻（张德辟谬）**：诸书因独尊用神才规定"动爻不能生克变爻"，遇反例又用"化变"补救、自相矛盾。张德引《增删卜易》"忌化用"（父化子、官化兄、兄化财、财化父、子化官）为证——**动爻能克变出之爻，只是力量比变爻回头生克动爻弱**。
  - → **取向**（`11` R22）：承认双向作用，但**回头（变→动）力 > 顺向（动→变）力**；断卦以曲炜"变爻为上层次"为骨，遇明显"动克变"现象（六亲化出特例）按张德补。
- **六亲化出特例（邵伟中）**："兄化财不劫变出之财；父化子不克子；官化兄不克兄；财化父不克父；子孙化鬼不克官鬼。"

## 三、化进神 / 化退神
- **进神**（同五行前进，增力）：寅化卯、巳化午、申化酉、亥化子、丑化辰、辰化未、未化戌、戌化丑。
- **退神**（后退，减力）：卯化寅、午化巳、酉化申、子化亥、辰化丑、未化辰、戌化未、丑化戌。
- **喜忌**：喜神化进吉、化退凶；忌神化退吉、化进凶。
- **应期口诀**："**化进神逢值逢合，化退神忌值忌冲**"（值指变爻、合指动爻，以利用神为前提）。
- **旺相化退不立刻退尽（曲/张德）**：旺相之爻化退，"占近事得时而不退"，要过段时间才慢慢退（旺月不退、休囚月才退）；土爻休囚化辰＝化进增力（土不论入墓）。张德专门辟"动而化退不论旺相马上退尽"之谬（→[11]）。

## 四、化空 / 化墓 / 化绝 / 回头生克（动爻与变爻的复合状态）
- **动化空**：变爻旬空则动爻随之旬空、无生克权（待变爻出空/冲空，→[07]）。邵："动化空，不为空"——指动本身抗空，但化出之空爻须出空才用。
- **动化墓**：以"临墓"论；用神化墓待**冲墓**之日应（→[06]）。默认只论化出本五行之墓（木化未、火化戌、金化丑、水化辰）；墓书"即使非自墓"（如卯化辰）作可选说法（`11` R28）。
- **动化绝**：为"化休"（衰弱意）。
- **回头生**："用神本有三分优势，得回头生变七分。"
- **回头克**：须看变爻有无生克权（无则不能克、不应灾）；世爻化回头克不一定有灾（曲炜：测短期/长期不同论）。张德"动化回头克"判法：原象动爻旺→进行时冲去变爻应吉（短期变爻逢冲动爻胜、长期动爻胜），须区分助旺/生旺。
- **化破/化空连坐之争**：张德否定"化破化空"（"谁破谁空是自己的事，勿搞连坐；动不为真破散"）；传统（野鹤/丁）有"自空化空必成凶咎"。→ 取向：以"变爻是否真有生克权"为准，不机械连坐（`11` R18）。

## 五、反吟（主反复动荡，凶于伏吟）
- **爻变反吟**：动爻化出与本爻相冲克（卯化酉、丑化未、巳化亥、辰化戌……回头冲克）。连冲带克减力大（卯化酉），只冲不克减力小（酉化卯）。
- **卦象反吟**：方位对冲之卦互变（离坎、乾巽、艮坤、兑震）。曲炜：爻变反吟只坤、巽两卦。
  - 核对：按 `14` 的纳支穷举，动爻与本位变爻相冲只有巳化亥、亥化巳、卯化酉、酉化卯四种，都出在坤↔巽互变，与曲炜说法一致。上一条举的丑化未、辰化戌是泛指"化出相冲之支"的例子，纳甲装卦里不会出现（坤↔巽互变时初、四爻不动），盘上见不到不必去找。
- **断法**：反吟主事体反复不顺；**但用神旺相不被冲克照样成事**；用神/世爻反吟且受伤＝大凶。上卦反吟外不利、下卦反吟内不利。喜神反吟应凶、忌神反吟应吉。
- **张德**：六爻**不论"卦象反吟"**（属梅花经卦逻辑），只论地支爻变反吟（巽坤互变）。
- **默认**（`11` R19）：只论地支层面的爻变反吟；方位意义的卦象反吟不作吉凶依据，只可作取象。依据：张德明言不论卦象反吟；曲炜论反吟也落在地支爻变。

## 六、伏吟（呻吟不安、原地打转，不为大凶）
- **爻变伏吟**：动而变爻与动爻同支（仅乾变震、震变乾）。
- **断法**：所求不尽人意、反复不顺、如病人呻吟有忧虑；以增力论（忌神伏吟应凶、喜神伏吟应吉）。
- **解**："**吟待冲**"——待冲破伏吟原象（尤其日冲当时解开，但须冲方彻底）。卦变伏吟同时六冲，勿断毫无进展。

## 七、独发 / 独静 / 多爻动
- **独发/独静**：卦中只一个动爻（或只一个静爻）时，该动爻/变爻所值日月常为应期（"神兆基于动"）。
- **独静**（邵）：主要矛盾常集中于独静爻，但要看众多动爻循环生克最后落在何处（例：木生火→火生土→土生金，循环至独静之金=财→大发）。
- **反对"只看独发独静"（李顺祥）**：无论独发独静都须**紧扣用神**——用神不是那爻时，独发/独静只代表应期，不能喧宾夺主。
- **多爻乱动（曲炜）**：不可机械"阳世顺行阴世逆行"；看动爻最终生到/克到何爻，必形成连动相生，查链条有无断节，定最终受益爻（利原用为吉、利忌仇为凶）。

## 八、卦变（变卦）与时态
- **主卦＝现在/起始，互卦＝中间，变卦＝结局/进行时**（曲炜）。
- **阳动主过去之事、阴动主将来之事**（邵/曲/丁多用）。张德辟其"无普适性"——过去之事须是仍影响现状的急事要事，卦才反映（→[11]）。
- **大象生克**：分卦变回头克、伏吟、反吟、六冲、六合；以六爻生克为主、卦象生克为辅。
