# 16 · 盲派六爻要义（杨军《盲派六爻真经》）

> 来源：杨军《盲派六爻真经》（师承民间盲师张明），第二批资料中的扫描书。**本文件依 OCR 第 1–61 页（全部理法：基础+生克制化+用神原忌仇喜+空亡墓绝+应期+断卦总纲/步骤/语言+解灾）整理**；62–136 页（名人卦例/天灾人祸预测法/附录哲学）为卦例专题，可续 OCR 补。OCR 有少量识别误差，已据文意校正。
> **定位**：盲派是本包收录的完整门派之一，默认不用，只在求测者断卦前指明"盲派/做功"时整套切换（`11` R20）。整理时曾有"盲派与本库最契合"的看法，那是整理者观点，不是当前默认。盲派**保留用神**（不同于玄空子/张德的"废用神"），但对**月/日分工**有根本性的重新规定，与本包默认的"月日同功同权"（R03）直接对立——这是采用盲派时必须先立的地基。

## 一、盲派的总纲与立场
- **本派主张（十二字）**："**取用神、轻六神、废格局、留组合、重作用、顺爻意。**"（注意：**保留取用神**，这点与玄空子/张德不同。）
- **盲派 vs 传统的根本区别**：继承传统的原始生克冲合，但**不用年月时分析吉凶、不用格局、不用断语**；"越真实越简单"。
- **断卦图式（核心心法）**：`日辰 →（动爻 ↔ 变爻）→ 用神`。先取用神（问事目标对应之六亲），以动变爻对用神的生克冲合定**先后成败**，最后以**日辰**对卦中作用定**吉凶**。"先把本卦看，后以变卦定吉凶，日辰最后定乾坤。"
- **装卦守传统**：卦/六亲/六神/地支/用神与传统一样，**明确反对"震卦纳支错"等改纳支说**（与 `02 墓库书` 的"乾卦改纳甲"相反，盲派守正统纳甲）。

## 二、月 / 日 / 年 / 时 的分工（盲派最大的地基，强冲突点）
传统持"月日同功同权"；盲派**把月、日的职权彻底分开**：
- **月建 = 旺衰之提纲（只论旺相休囚死）**："月建是一个固定的能源库，**月建决定所有卦爻的旺衰**；爻旺受克也不会衰，爻衰受生也不会旺——卦里只有得时的旺相五行才旺，其它再多也是衰。"（"春天发芽秋天落"）→ **月只定旺衰、不直接定吉凶**。
- **日辰 = 六爻之主宰（专司生克冲合、长生墓绝、定吉凶）**："日辰主宰全爻生死存亡……在与动变爻、静爻相比之下占 **80% 的力量**。" 爻冲日来合而不解、爻合日来冲而不破。
- **年（太岁）/ 时辰 = 有职无权**："爻冲年来合而不解、爻合年来冲而不破；**年/时不管旺衰、不管生克冲合**。"（仅在细断时作"现象范畴/分野"取象，如年祖辈·月长辈·日同辈·时晚辈；年省·月县·日乡·时村。）
- **原时 vs 流时**：**原时的月建定旺衰、日辰定吉凶**；**流时（流月流日）不能定旺衰吉凶，只定应期**——据此否定"十二日变一次"的恶性循环（"吉凶只在当时决，祸福无劳日后知"，与张德"原象不易性"同向）。
- **旺衰 ≠ 强弱**：旺衰＝得令为旺、失令为衰（月定）；强弱＝力量大小，得日辰/变/动/暗动生助为强、被其克为弱。

> ⚠️ **接入须知**：盲派的"月管旺衰、日管吉凶、年时无权"与本库主流（`03` 同功同权 + 四层次）**互斥**。要走盲派就整套走，不可与主流混用同一卦（→[11]）。

## 三、爻的权力等级与作用顺序
- **六爻权力等级论**（社会等级隐喻）：**日辰(天子) > 变爻(诸侯) > 动爻/暗动(官员) > 静爻(百姓)**。上可作用下、下不能作用上。日辰先作用变爻、再动爻、再静爻。
  - 形似曲炜"四层次"，但盲派把**变爻明确列为第二高于动爻**，且配"日辰 80% 力量"的盲派旺衰观。
- **有无生克冲合"功能"清单**：动爻、暗动、变爻、日辰、**开伏**有功能；年月时、**闭伏**、静爻、**虚化**（静爻所化之变爻）无功能。
- **作用顺序口诀**："**本先变后吉凶观，日辰最后吉凶参**"——①本卦六爻先互相作用 → ②变爻作用本卦在后 → ③日辰最后作用变卦与本卦定吉凶。
- **冲合先于生克、动先于静**："冲合力量强于生克，故冲合在先；动爻遇动爻/静爻时直接作用动爻（枪打出头鸟），只有静爻时才作用静爻。"
- **耗泄驳谬（盲派独特）**：六爻里**没有耗泄之说**，只有生克冲合。"金对火只有火克金，不要扯耗；变爻水对动爻金无作用，不要扯泄。"——否定"泄气/耗气"参与作用（否则"到处都是吉凶"）。

## 四、变爻作用规则（盲派折中，重要）
传统"变爻只作用原动爻" vs 李洪成"变爻可作用所有爻"——盲派给出四条：
1. 变爻与原动爻**有回头作用关系** → **只作用原动爻**，无权作用其它爻；
2. 变爻与原动爻**无回头作用关系** → **有权作用其它爻**（动/静/开伏；无权作用闭伏）；
3. 变爻与原动爻**有"合中回生/克"** → 只作用原动爻；
4. 变爻与原动爻**无"合中回生/克"** → 作用原动爻力量多、作用其它爻力量少。

## 五、冲（盲派定义，与传统有别）
- **暗动（盲派）**："**日辰冲静爻无论旺衰皆为暗动**"，只分**旺暗动 / 衰暗动**（衰暗动"待旺而用"）。→ 与传统"旺静逢冲＝暗动、休囚静逢冲＝日破"**不同**（盲派静爻逢日冲都叫暗动）。引《断易天机》"六爻安静……若日辰相冲名曰暗动"为据（无旺衰二字）。
  - 暗动取象＝阴私潜伏、福来祸至而不觉；**应期在合**（合暗动之爻或合日辰）。各类占断（婚/官/讼/失物/营谋/出行/家宅/病）吉爻暗动＝暗中有帮、凶爻暗动＝暗中有害。
- **冲散 / 冲脱 / "搬家"**：
  - 日辰冲**动爻/变爻**（无论旺衰）＝**冲散**（也叫日破，报废不中用，殃及相连的动/变爻）；
  - 日辰冲**空爻**（动静无论旺衰）＝**冲脱**；冲变空之爻＝冲脱；冲伏空爻＝冲脱（不中用）。
  - 日辰冲伏爻：**带克则不出、不带克则出**。
  - **日辰冲散/冲脱动变爻，盲师叫"搬家"**（含义＝转迁、移动）。
- **爻与爻冲**：卦中动/变爻冲动/静爻无论旺衰均为冲散，冲中带克比不带克凶；静爻冲静爻＝"有冲之意、无冲之力"。
- **六冲口诀**：子午冲身不安·丑未烦恼仇恨·寅申损财车伤·卯酉伤肢车祸阴私·辰戌纠纷官司·巳亥生气妇女争权。

## 六、合（盲派分类与规则）
- **六合分类口诀（盲派招牌）**：**子丑恩合**（不情愿，服毒喝药之凶）·**亥寅义合**（一条心）·**卯戌利合**（表面和，见钱忘友）·**辰酉容合**（共同喜，你让我我让你）·**巳申势合**（巴结当官）·**午未勾合**（不正当）。
- 近合/远合：子丑午未相邻＝近合短合；卯戌辰酉＝远合久合；寅亥＝中合。
- **生合 / 克合**："合占第一性，最终是合的结局；克合即'合中克'（合七克三），不是先合后克。"
- **爻与爻合 vs 日辰与爻合**：
  - 动合静爻＝**合起**（得人帮忙成事）；
  - **日合静爻＝合起**（不产生生克冲合功能，但成事；不管带生带克——"坊间认为合起为暗动，非也"）；
  - **日合动爻＝合绊**（绊住暂不能动，但会成事）。
- **合冲与生克同时＝合冲先于生克**；且"巳克申（绑住打）遇戌土不能转化（已合申方向不可改），而午克申遇戌土可转克为生"——合的方向不可改。
- 取向：占婚/合伙/出行/合同/风水**喜合**；占出狱/疾病/脱货/官司/离婚**忌合**（反之忌冲/喜冲）。

## 七、三合（盲派成局 / 破局）
- **成局条件**（任一）：①三合爻俱全且都动；②两动＋一暗动；③两动＋日辰；④两动＋一个原动爻之变爻。具备后即使有爻空/破/墓/日克也无碍，**待出空墓时成局发挥**。
- **不能成局**：其它动爻所化之变不参局；**月建不参与三合**；静爻、伏爻不参局；两动爻不能单独成局。
- **破局**：三合中有爻被日冲散/冲脱、或被它动变冲、或某爻化克无转化。
- **半合**："盲派里根本没有半合局——半合只用来取象、不主吉凶。"

## 八、三刑 / 六害 / 六破
- **三刑口诀**：寅巳申刑（忘恩负义、蛇毒心）·丑戌未势（多对敌、暗设阻隔）·子卯礼刑（无涵养、官司）·辰午酉亥自刑（烦恼自害病官）。"少一不凶有矛盾，成刑俱动不安静。" 须辩旺衰（旺如乘车得马、休囚如被禁）、刑我刑他、有无它爻制。**盲派一直运用刑害**（"刑中合、合中刑＝合作中有对抗"），反对增删/正宗废刑害。
- **六害**：害从合来（冲破合叫害）——子未·丑午·寅巳·卯辰·申亥·酉戌。归生克范畴，断吉凶以生克论、只在辩义取象时用。
- **六破**：子酉·丑辰·寅亥·卯午·巳申·未戌，各有歌诀；亦归生克范畴。

## 九、进退神（盲派口诀）
- 进神：亥化子·寅化卯·巳化午·申化酉·丑化辰·辰化未·未化戌（向前发展）；退神反之。
- **"旺相化退，占近事不退；休囚化进，占近事不进。"** 应期"逢值逢合"应事。
- 辩证：占凶事化退＝雪中送炭、化进＝忧中生喜；占吉事化退＝喜中生忧、化进＝锦上添花。用神原神喜化进、忌神仇神宜化退。

## 十、伏吟 / 反吟（盲派）
- **伏吟**＝两地支重合（原地踏步、进退不得），不主吉凶、可被化解；分**卦伏吟**（乾兑互化/震巽互化/艮坤互化，取象）与**爻伏吟**（子化子…，断吉凶）。"久病呻吟、欲迁不能。"
- **反吟**＝六组地支互相对冲（反复无常），不主吉凶、可化解；分**卦反吟**（乾巽/震兑/坎离互化，取象）与**爻反吟**（子化午…，断吉凶；**回头克者大凶，只冲不克者反复无大凶**）。测行人/失物/破案，反吟主"去而复回/失而复得"。

## 十一、飞伏 / 开伏闭伏（盲派）
- 先天卦原地支为**伏神**、后得卦地支为**飞神**。"飞神＝表面现象，伏神＝内在世界；伏神透出之时必产生结果，**无引拔永远无用**。"
- **拔**＝日辰/动/变爻**冲克飞爻**使伏出；**引**＝日辰/动/变爻**生合伏神**使出；**自出**＝飞神旬空/休囚入墓时伏易出。
- **开伏 / 闭伏**：开伏＝能出伏（有生克冲合功能、可被动变作用）；闭伏＝不能出伏（无功能、不受作用）。
- 占捕逃：飞爻＝捉拿人、伏爻＝逃亡者；**飞克伏能捕获、伏克飞抓不到、相生相合难寻**。

## 十二、生克的盲派细则
- **连生**：木→火→火→土→土→金，连续相生力越来越大、源源不断（生者为事件源头，即使被伤也无大碍）。
- **群生 / 群克**：多个同五行地支（本卦动或变卦）共生/共克一爻＝力最大、势不可当（群克用神则必死，群生用神则福愈厚）。
- **碎金赋**（动爻生克条件，盲派引用）："子动生财不宜父摆；兄动克财子动能解（贪生忘克）；财动生鬼切忌兄摇；父动生兄忌财相克；鬼动克兄父动能解……"——三原则：①甲生克乙不能有克甲者；②甲克乙、甲有生助则力增；③贪生忘克（邻位相生、隔位相克，力用于邻生则无力克隔位）。
- **盲师一掌诀**："横定六合竖六害，相冲六对斜中来，跳过三宫三合成，金木水火四绝行。"

## 十三、与现有库的关系与接入建议
- **高度契合处**（可直接增强）：盲派的"日辰主宰/80%力量"与库内邵伟中"日建为主宰"一致、可互证；"原时定吉凶流时定应期"与张德"原象不易"一致；权力等级与曲炜四层次可对照；伏神拔/引/自出、开伏闭伏、连生群生群克、碎金赋、六合恩义利容势勾分类——均为可直接吸收的**取象/作用细则**。
- **强冲突处（须整套走盲派、勿与主流混用）**：①**月专论旺衰、日专定吉凶、年时无权**（vs 同功同权）；②**暗动＝日冲静爻无论旺衰**（vs 旺者暗动衰者日破）；③**日辰冲动/变爻＝冲散日破**（盲派把"日破"归到动变被冲，而非传统的休囚静爻被冲）。
- **引擎调用**：见 `11` R20——只在求测者断卦前指明"用盲派断"时，整套切换到盲派规则（月定旺衰→日定吉凶→用神图式→权力等级→冲散冲脱搬家→伏神开闭），输出标注"盲派"。想长期默认用盲派，先改 `11` 默认并升规则版本。

## 十四、用神·原忌仇喜（盲派）与取用
- 用神=预测对象（某事取某六亲）；**元神=生用神者；忌神=克用神者；仇神=生忌克元者（非"耗用神"）；喜神=克忌神者（非"泄用神"）**——盲派"无耗泄"贯穿到此。
- **吉用神 vs 凶用神（关键）**：占吉事(升官发财成婚)→元吉·忌凶·仇凶·喜吉；占凶事(官司病灾离婚)→元凶·忌吉·仇吉·喜凶。**喜忌随"所占是吉事还是凶事"翻转。**
- **立场取用（换位）**：六亲按"卦主站在某事物内的立场"命名——占我，站孩子立场取父母、站父母立场取子孙、站妻立场取官鬼…"用神随立场变"（与曲炜/张德角度取用同向）。
- **用神多现不取一舍一**：反对增删"病药用神观"(舍闲取持世/舍不空取旬空那套)；主张用神多现各有其用、同一事可多用神。
- **取用五类**：①自占自身(世)②自占事物(世+事之六亲)③代占测人(按亲属/身份取)④代占测人之事(取事之六亲，用神重则以事为主)⑤代摇卦(世=发起意念之人，非摇卦者)。

## 十五、空亡（盲派）
- 空亡诀："空亡有假亦有真，静空休囚生也假，空化空爻呈真空，旺空动空不为亡，受生时吉克应凶，虚假脱疏空亡准。"按日干支查。
- **空 vs 亡**："空待时有用、事必成；亡彻底无用、事不成。"旺空=表面繁华实质炎凉(财空钱不厚、官空有职无权)。
- 九种空择要：静空休囚=亡(动爻生也不成)；空化空=真空(不作用不受作用)；静空旺相=空(出空/实空时受生应吉、受克应凶)；动空(旺者出空应、衰者旺相出空应；日冲为脱=事已发生完)；合空=表里不一；冲空=改目标；伤空(空动逢克)=应吉(我空脱身)；自空=应凶、出空后应事。

## 十六、墓绝（盲派观，重要冲突点）
- **土无长生、无绝**：盲派认为寄生十二宫源自数理、与生克无关；六爻以**日支**为衡。四绝诀(午亥水绝/寅酉金绝/子巳火绝/卯申木绝)取象用。
- **墓库不主吉凶**：有动墓/日墓/化墓/飞墓，**无月墓年墓**；**无"旺为库衰为墓"之说，更不以"随鬼入墓"论凶**——一切因问事组合而论。入墓=失自由/结束/隐藏，入墓期失作用权，出墓(冲墓)应事。金见丑日入墓盲派以"生"论，墓只用来提取信息。
  - ⚠️ 与 `06`(墓库书/主流)的"入墓凶·旺库衰墓·随鬼入墓"**直接对立**——走盲派镜时用此盲派墓观，勿与 `06` 混用。

## 十七、应期与解灾（盲派）
- 应期=找主线病根、对症下药（同病处寻药）。单位：终生应年/年内应月/月内应日/日内应时。
- **盲师应期口诀**："太岁并临一年中，节气发时在当月，四立不出一季度，旬空动时本旬内，君主用时在朝暮，气一难逃十五天，候发必是一礼拜。"
- 快慢：冲旺克现动为快、合衰生静伏为慢；爻位定月/日/时。过去未来：旺动现在、相未来、休囚死动已过去；初爻过去·三四现在·五六未来；主卦现在·变卦未来。
- **解灾论**：趋吉避凶=错开时间/改换空间/以物质能量抵挡（不能改天体之凶本身）；**识灾可解不可解，有解才解、无解不强解**；盲派归于因果、重积善。
