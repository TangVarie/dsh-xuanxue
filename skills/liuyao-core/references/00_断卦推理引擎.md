# 00 · 断卦推理引擎（推演流程 · 纠错 · 降级 · 冲突处理）

> 本文件是推演的中枢：一卦到手后按什么顺序、用哪些技法、从哪些角度交叉，最后落到一句带置信度的判断；以及出错了怎么改、缺东西怎么降级、规则打架怎么办。
> 引用约定：→[0X] 指 `references/0X` 技法细则；R01…R29 指 `11` 第二节默认规则；输出格式见 `22`；判词翻成现实话见 `23`；技法触发条件见 `20`。
>
> 两条主线：
> 1. **多镜并跑**：同一张盘先用主流纳甲法跑一遍，再用张德世应镜跑一遍，两版各自记下，求同存异；其他镜只按 `11` 三的事前条件开。
> 2. **两阶段**：先推出域中立的卦理判词（第 0～8 步），再翻成当事人能核对的现实话（第 7 步取象 + `23`）。

## 〇、模式入口

| 模式 | 怎么认 | 走哪几步 | 不做什么 |
|---|---|---|---|
| 完整解卦 | 给了卦（铜钱结果、卦名动爻、截图）并说了要问的事 | 第 0～9 步全走，按 `22` 二成文 | — |
| 单点追问 | 本会话已有登记过的卦，用户就其中一点追问（某爻、应期、某个判断、某条依据） | 沿用已确认的卦盘与登记，只重跑相关判断链（问应期→第 9 步及它依赖的第 3、6 步状态；问某爻→该爻的第 3～6 步）；按 `22` 四成文 | 不重新取用、不重复卦盘、不重出整套报告；答案改了主判才走第十节 |
| 对照与复盘 | 拿来别人的解读；报告事后结果；指出本方的错误 | 第十四节；纠错走第十节 | 不重断未受影响的部分 |
| 资料解释 | 问规则、术语、门派差异、某本书怎么说 | 不进推演；按 `22` 六 | 不强行起卦 |

一条消息里混了两种（例："这卦三爻动什么意思？顺便问下暗动是什么"）：资料部分直接答，卦的部分按单点追问处理。说不准是哪种时，按对用户最省事的读法走，并在开头一句说明读法。

## 第 0 步 · 输入核验与来意登记

### 0.1 三类输入
- **卦形**：六爻自下而上的阴阳与动静（铜钱结果、六个爻象、卦名＋动爻、本卦＋变卦、排盘截图都可还原）。
- **时间**：起卦的年、月、日、时干支，至少要月建与日辰。
- **来意**：谁测、测什么、问法类型、动机、时限。

### 0.2 只追问会实质改变判断的信息
| 信息 | 什么时候必须问 | 什么时候不问 |
|---|---|---|
| 卦形 | 截图看不清动爻；卦名与爻象对不上；只报"几个字几个背"而铜钱约定不明（`14` 〇） | 六爻阴阳、动静已能还原 |
| 时间 | 日期本身矛盾（公历与给的干支对不上、星期对不上）；起卦时刻落在节气交接或 23～24 点、且两套干支会改变主判（第十一节）；脚本提示"时区未指明"（没说起卦地，而节气交接离得近，换个时区月建就不同） | 给了干支；或给了公历且脚本换算无边界问题、无时区提示 |
| 测什么、问法类型 | 不清楚，且不同问法取用或喜忌不同 | 原话已说清 |
| 谁的事 | 分不出是本人、代测还是双方之间 | 原话已说清 |
| 动机 | 想成 / 怕生变 / 已发生，会翻转喜忌且原话看不出 | 问法类型已经带出动机 |
| 性别 | 婚恋卦等取用依赖男财女官时 | 其余情况 |
| 年龄 | 寿数、学业阶段、常理仲裁要用时 | 一般不问 |
| 时限 | 事情本身有现实截止期而没说 | 没说就按事体常理定应期单位，并写明 |

- 原话已说清关心的是哪一面，就按原话取用，不再自己拆出候选用神去追问或降档（例："能不能按我提的价格谈下来"就是取妻财，不必再问"价格和续租哪个要紧"）。
- 需要问的合并成一次，最多三项，每项带一句为什么问（例："这关系到用妻财还是用应爻"）。
- 用户不在场或不答，按最合理的读法推进，开头写明读法，相关结论降一档。
- 起卦方式非铜钱的，照收，记入记录（R24）。
- **时区**：公历时间默认当作北京时间。用户说了所在地、时差，或话里明显不在东八区，按起卦地的钟表时间给脚本加 `--tz`；没说就不问，除非脚本给出"时区未指明"的提示——那时合并进这一次追问里问一句起卦地，问不到就按北京时间与另一种月建（提示里那个节气的前后两个月，用 `--month` 指定）各跑一遍，按第十一节处理。

### 0.3 问法类型（取用与喜忌随之不同）
1. **能否成**：看用神旺衰、世应生合。
2. **走向好坏**（成了之后是变好还是重演）：看变卦、六冲六合、父母爻、原象不易。
3. **该不该**（要拍板）：按 `23` 给分层结论与条件；必给对应建议。
4. **只问时间**：只做病处寻药（→[09] 三①），不展开成败分析。

"要不要复合"这类话可以指 1、2、3 任一种，结论可能相反（能成但重演），默认问一句；问不到就按第十三节分层各给一句。

### 0.4 一事一断
一卦只断一件事，可从多角度断这一件事（R15）。来意混了几件无关的事，请求测者拆开、一事一卦；宽主题（流年、终身）可多角度，但围绕主题。没有真实动机不占（"不动不占"）；本 skill 不替用户摇卦。

### 0.5 前卦
- 本会话、用户提供的记录或记忆里已有同一件事的前卦：直接引用它的主判一句，写本卦与之同向还是反向。
- 没有可用记录：**不追问**，登记里写"前卦：无可用记录"。
- 两卦主判不一致，必须写原因：来意变了 / 有新信息 / 前判有误（写出收回哪一句）。不许各断各的。
- 第三卦起提示"筮不过三"，只答前两卦没答的角度，不重开吉凶。

### 0.6 来意预判（可选 · Jev）
- 先写**来意摘要**：只含谁测、测什么、关心哪一面、动机、时限，不含卦名、爻象、干支等任何卦盘信息；再运行 `python scripts/jev_judge.py case.json`（字段见 `20` 二）。
- 只有 `status: ok`（`usable: true`）的结果能用；`skipped`、`error`、`mock` 一律当作没有预判，按 `20` 二人工判断来意，不追问密钥。
- `ambiguous_items` 里的题：先追问；主用神追问不到，就把前两名各断一遍，结论一致才坐实。
- Jev 只做预判，取用由第 2 步定。装卦后补跑的 Jev 只能当复核。

### 0.7 事前登记（看盘之前定下）
问法类型、主用神（含备选）、应期单位、所用门派（默认 r6.1；或求测者事前指明的盲派等）。
- 看盘后想换用神：只能写成备选，置信度降一档（`22` 七）。
- 例外只有第十节修订通道（用户侧带来的新信息或排盘错误）。

## 第 1 步 · 装卦核验与建坐标

### 1.1 装卦
- 用 `python scripts/paipan.py` 装卦（输入爻值、卦名动爻或本变卦名，加月建日辰或公历时间），输出纳甲、六亲、世应、六神、旬空、变卦、伏神与甲类机械触发清单。也可按 `14` 手装，再用脚本核一遍。
- **截图**：模型先把截图里能看清的字段读出来，写成 JSON 交给 `paipan.py --verify`，得到差异清单。字段格式见 `14` 十一（`paipan.py --verify-template` 打印空模板）；爻自初至上写 6 项。看不清的字段写 `null`（未确认），**不自动补齐**。
  - 差异出在爻象、动爻、日期：属输入问题，向用户确认那一处。
  - 差异出在纳支、六亲、世应、六神、旬空：多半是排盘软件约定不同（如子时换日、乾卦改纳甲），以本包规则为准（R17），并在简明卦盘后注一句差异。
- 公历只给日期的：`python scripts/ganzhi.py` 换算，或 `paipan.py --date`。严禁凭记忆心算干支。起卦地不在东八区的加 `--tz`（0.2）。

### 1.2 不等确认，直接推进
盘面完整、无未确认字段时，简明卦盘直接写进输出（`22` 二.1），接着往下断，不先停下来等用户确认。只有未确认字段会影响主判时才停。

### 1.3 盘面高亮（先圈出病灶）
- 月建、日辰并 / 冲 / 合到的爻；旬空之爻；持世、临应之爻；发动、暗动之爻与变爻；
- 特殊卦象：六冲 / 六合 / 三合局 / 反吟 / 伏吟 / 冲变冲 / 合变合 / 冲变合 / 合变冲（→[01] 九）。
- `paipan.py` 的触发清单只给"触发了什么"，不给结论；旺衰、取舍仍按下面各步判。清单只算各爻与日月、动爻与本位变爻、主卦六爻彼此之间的关系；变爻越位作用它爻、暗动之爻再去冲合等它不算（`20` 一表后"脚本算到哪里"），这些要自己过。

### 1.4 四建分用
测多久的事就用多久的建：测终身用岁月日；测流年用岁月（应期落到月）；测月内用月日（应期落到日）；测当日用日时（应期落到时辰）。

> 盘面高亮做完，主要矛盾通常已浮现——多数卦的答案在"持世 / 用神 × 日月 × 唯一或最强的动爻"三者的关系里。

## 第 2 步 · 取用 · 双镜（→[02]，R01、R02、R16）

**主流镜**：
1. 按事取六亲为用神（财看妻财、官事看官鬼、文书学业看父母、子嗣医药晴天看子孙、手足竞争劫财看兄弟），以六亲取用，不以五行属相取用。
2. 同时取对应点（曲炜）：先想现实中办成这件事要经过哪些环节、牵涉哪些人事物，再在卦里一一找对应；世＝求测人本身，应＝对方/环境/目的地，各六亲＝各环节。
3. 配齐原神（根）、忌神（病）、仇神。"用神是表面，原神才是根本。"
4. 用神两现先判各司其职；不上卦取伏神，伏神出现只靠值、临、冲伏、冲飞四法。

**张德镜**（并跑）：不先锁用神，抓世应重心——持世之爻＝我在此事上所持的态度/方法；临应之爻＝我面对的对方/环境；动变＝最明显的动态信息。把"克"还原成现实动词：克＝找上门、追求、控制、得到（占财财爻克世必得；官鬼克世＝麻烦找上门）。

两镜**各自得出一句主判**，分别记录（`22` 二.3 双镜一行）。同向在置信度理由里记一笔，不升级；冲突进第 8 步仲裁。

## 第 3 步 · 定旺衰（→[03]，R03、R04、R07、R27）

逐个判世、用、原、忌与关键动变爻：
1. **月建 + 日辰同功同权**：日月对某爻一生一克（或一旺一破）时，抛开日月，看卦中旺衰。张德细化为月令 70% / 日辰 30%，综合仍同功同权；并立"原象不易"：原象旺爻遇衰月不会一落千丈，原象衰爻遇旺月不会一步登天——用来否决"等个旺月就翻盘"。
2. **旺相休囚死 + 长生十二宫**：定基础能量；墓、绝、长生在月日上一起看（→[06]）。土的长生墓绝不作吉凶依据（R10）。
3. **暗动 / 日破 / 临界**：旺相静爻被日冲＝暗动；休囚静爻被日冲＝日破；日月一生一克的静爻为临界态，看卦中动爻是帮它还是耗它。土爻逢土月冲默认以月破论，不因"月令同五行"当成旺相（R27）；月冲值日之爻两派同判有力（R07）。
4. **爻的四个层次**：日月 > 变爻 > 动爻/暗动 > 静爻/伏爻；上层次能生克下层次，下层次无权生克上层次；爻值临日月即升为第一层次——应期的钥匙。
5. **特殊状态镜**（只按事前条件）：从象/一气专旺按 `03` 九机械条件（R04）；五运六气只在疾病或涉健康的盘（R03）。只作对照、不径直替换。

## 第 4 步 · 推生克冲合刑害（→[04]，R06、R08、R09）

1. **次序**：「先生后克，先动后静，无生则克，无克则生」（邵伟中/林潮）。静爻能否受生按 R06：默认动爻、日月可生静爻；静爻得不到生时，先找生者自身受制的理由；只能靠"不动之爻不得生"解释时标派别、降档。
2. **合冲优先**（曲炜）：同层次先论合冲，再刑，再害，最后普通生克；下层次的刑冲合害让位于上层次。
3. **冲四态**：冲起（旺静逢日冲＝暗动）、冲破（休囚逢冲）、冲实（旬空旺逢冲）、冲散（日月参与的合冲不散）。论冲须至少一方发动。
4. **合化 vs 合绊**：合化后五行与本性相同者仍能生克，不同者被绊；日月本身五行不变；合住忌神为吉、合住喜神为凶。
5. **三合局**：按 R08 判成局，依赖争议条件时标源。
6. **通关 / 贪生忘克**：须有生克权之爻发动来通关；被合、入墓、月破者不能通关。
7. **刑害**：有生克权就以生克论；四土警示只按 R09 条件，六害不入应期依据栏。

## 第 5 步 · 看动变（→[05]，R18、R19、R22）

作用路线（先本位变爻、再越位它爻）、化进退（旺相化退不立刻退尽）、化空 / 化墓 / 化绝、回头生克（须变爻有生克权）、六亲化出特例、爻变反吟伏吟（只论地支层面）、独发独静（紧扣用神）。

## 第 6 步 · 四钥匙交叉验证（"墓空为先"，→[06]、[07]、[05]，R10～R13、R28、R29）

| 钥匙 | 核心问题 | 翻盘点 |
|---|---|---|
| 墓库 | 关键爻入墓还是入库？是谁的库？ | 旺爻入库＝保护待用，逢出库应吉；衰爻入墓＝死墓，出不出都凶；忌神入墓反吉 |
| 旬空 | 真空还是假空？ | 真空到底无用；假空出空、冲实即用；旺空逢冲＝冲实，衰空逢冲＝又空又破 |
| 伏神 | 用神伏在哪、能否出？ | 值、临、冲伏、冲飞才出；飞生伏吉，伏生飞泄 |
| 反吟伏吟 | 有无爻变反吟伏吟？ | 主反复、呻吟；用神旺相不受伤照样成事 |

每把钥匙都问"锁住了谁？何时解锁？"——答案直接喂给第 9 步。
**两象定一象**：两处不同信息指向同一结论才坐实，孤证不立。

## 第 7 步 · 取象落地（→[08]、[10]，R14、R21；翻译规则见 `23`）

1. **六亲取象**：随事转义（父母＝文书/房/车/长辈/保护我之物；"载我之车撞了人，车反成官鬼"）。
2. **六神定性质**，不定吉凶（R14）。
3. **爻位定位**（初足、二腿股宅灶、三腰腹门床、四胸腹大门、五心口路人、六头顶远处）。
4. **五行取象为辅**，别拿五行硬凑方位数字。
5. `17` A 类取象法、`15` 月日组合用语可在这里作描述，不回改第 3～6 步（R21）。
6. 先写域中立判词，再按 `23` 三段链翻译；翻译与现实硬冲突，回第 2、7 步复查。

## 第 8 步 · 定吉凶 · 仲裁 · 置信度

1. **定吉凶看原象**（起卦那一刻的盘），不看进行时（R05）。"内因有克终是祸，外因有克不一定是祸"：日月克世用只说明现在运气差；真正的隐患是卦中休囚的动爻克世用（等它旺起来时应）。
2. **仲裁**（双镜冲突，或开了少数派镜）：
   - 先回到现实常理与来意动机，哪一版更贴合当事人处境；
   - 两象定一象：哪一版有第二处卦象佐证；
   - 张德"占远应近、舍轻报重、舍人报己、舍喜报忧"：信息互搏时，坏事、急事、与己最切身的事优先显现；
   - 仍定不下：输出"主判 + 备选 + 触发条件"，置信度降一档，不硬选。
3. **标源**：结论只在一派规则下成立的（R06、R08、R10、R12 等），断语括注派别，降一档，给另一派下的备选。
4. **置信度**：按 `22` 七评三级；Jev 概率、双镜一致性、现实发生可能分开写。
5. **主判一句话**：吉凶 + 取象（什么事、谁、哪方面）+ 置信度。

## 第 9 步 · 定应期（→[09]；写法见 `22` 八）

总诀：**动待合，静待冲；衰待旺，旺待墓；冲待合，合待冲；空待出，墓待破；伏待引，吟待冲。**
- 把世、用（原神动则含原神）的每一处病都找出来，全部治好那一刻才是应期。
- 进行时"先遇先应"：往后排月或日，先遇到能解病的字就断在那里。
- 单位由现实事体定；有时限的事，理论应期落在时限外＝事办不成。
- 速度："克比生快、动比静快、旺比衰快"。
- 合墓只作备选（R12）。

收尾：按 `22` 成文；记录字段按 `22` 十（标准输出不显示记录表）。

## 十、纠错与修订通道

**触发**（只认用户侧带来的新信息或硬错误）：
1. 用户纠正问题：问的其实是另一件事、另一个角度、另一种问法；
2. 用户补充关键事实：会改变取用或喜忌的现实信息（例："其实合同已经签了"——动机从"想成"变"怕生变"）；
3. 发现排盘错误：爻象、动爻、日期、干支、装卦字段；
4. 自查发现硬错：冲合方向、墓库主客、层次误用。

**不算触发**：看完盘觉得另一个用神更顺；看到结果后想换解释（那是复盘里的"事后解释"）；用户不满意结论但没有新信息。

**步骤**：
1. 写明触发类型和用户原话。
2. 重新登记受影响项（问法、主用神、干支、卦形）。
3. 按下表只重算受影响的部分：

| 改了什么 | 必须重算 |
|---|---|
| 爻象 / 动爻 | 全部：卦名、宫、世应、纳支、六亲、伏神、变卦、触发清单、第 2～9 步 |
| 日干支 | 旬空、六神、日辰对各爻的生克冲合（暗动、日破、日合、日墓）、旺衰中日辰一项、应期日级排序 |
| 月建 | 旺相休囚死、月破、月合、月墓、旺衰、应期月级排序 |
| 年、时 | 流年取象、时辰级应期（年时一般不改吉凶） |
| 时区 / 起卦地 | 按新时区重跑 `ganzhi.py`：节气交接附近月建会变（立春附近年也变），变了就按"月建"一行重算；日辰随起卦地钟表日期，一般不变 |
| 问法类型 / 主用神 | 第 2 步以后全部判断、喜忌、建议 |
| 性别 | 婚恋卦取用（男财女官），第 2 步以后 |
| 时限 | 应期单位与时限判断 |

4. 输出"修订说明"：原主判 → 新主判；触发原因；受影响结论清单；未受影响的结论原样保留并说明。
5. 记录里原登记保留，修订作为新条目追加（`22` 十），不覆盖。

## 十一、降级规则（缺东西时还能做什么）

| 情况 | 仍能做 | 暂不能成立 / 怎么标 |
|---|---|---|
| 没有日期，或公历换算失败 | 卦形检查：卦名、宫、世应、纳支、六亲、伏神、变卦、六冲六合、爻变反吟伏吟、化进退、回头生克的五行关系、独发独静、用神两现 | 旺衰、月破日破、暗动、旬空、六神、入日月墓、应期——都不能断。只给"卦形层面的倾向"，置信度最高为低，并请用户补日期 |
| 起卦时刻在节气交接前后或 23～24 点，脚本标"未确认" | 两套干支各跑受影响的项 | 结论一致照常；不一致写双分支、降一档，请用户确认起卦时刻或换日约定 |
| 脚本提示"时区未指明"、而用户不在场或没答起卦地 | 按北京时间与另一种月建各跑受影响的项 | 结论一致照常；不一致写双分支、降一档（按"节气边界两套干支结论不一致"计） |
| 截图有看不清的字段 | 其余字段照常 | 受影响判断标"待确认"；影响主判就先问 |
| Jev 不可用、超时或返回异常 | 按 `20` 二人工判断来意 | 详解里写"来意预判：未启用 / 失败（原因）" |
| 没装 oracle-grounding | 按 `23` 完成落地翻译 | 不提示安装 |
| 缺 PyYAML | `paipan.py`、`ganzhi.py`、`record.py` 不受影响 | Jev 返回 skipped |
| 用户不在场、问题不答 | 按最合理读法推进 | 开头写明读法，相关结论降一档 |

## 十二、冲突处理

1. **双镜冲突** → 第 8 步仲裁；仲裁不下给主判＋备选＋触发条件，降一档。
2. **门派规则冲突** → 按 `11` 二默认；结论只在一派下成立的标源降档。
3. **资料内部冲突**（R12 合墓、R26 静爻值日通关、R27 土月冲土爻、R29 静爻逢动爻为墓）→ 按 `11` 的未决条目处理，作备选并给双分支。
4. **前卦冲突** → 第 0.5 节。
5. **判词与现实硬冲突** → 回第 2、7 步复查，结果写进修订说明（`23` 一.3）。
6. **"卦凶换个时空再占"**（`19`）→ 只在现实情况实质变化后作新卦，按 0.5 登记前卦；同一情况下反复摇不算新卦（R25）。
7. **用户坚持另一种解读** → 走第十四节对照流程，逐条认 / 不认 / 部分认；没有新信息不改主判。

## 十三、婚恋卦专项

1. **问法分流**：能否成 / 走向好坏 / 该不该 / 只问时间，按 0.3 定了再取用。"要不要复合"默认问一句是问能否还是问走向。
2. **两用神边界**：世应看双方处境与立场；男财女官看感情对象与感情本身；父母看条件、承诺、安排；男测时官鬼默认先取压力、麻烦、处境，再取他人。成文每提到对方，标是哪一爻；应的原神与财的原神分两条线写，不互相代换。
3. **第三者象**：过 `22` 九.2 门槛才能进主判，否则默认取"别的事、压力、处境"。
4. **动机不定**：改不改得了、真不真心、能不能自立，卦上只给"这条线稳不稳、何时有力"，写成爻位状态与衰待旺的时点（`22` 九.1）。
5. **复合类卦分层**：至少分感情层（财官爻旺衰与出现）、结构层（世位、父母爻、六冲六合、变卦）、时间层（应期），三层各给一句，不合并成一句吉凶。其他婚恋卦同样按层写主判（`22` 二.2）。
6. **世应线与财官线方向相反时**：资料有"未婚以世应为主"（`10` 二）与本节第 2 条的分工两种读法，不取一舍一。主判按两层各写一句（世应层：双方立场与往来；财官层：感情本身有无根、何时有力），置信度按"两条用神线方向相反"降一档（`22` 七），备选写清哪条线先应验就按哪条读。

## 十四、对照他人解读与事后复盘

- **对照**：逐条引对方原文；先列对方说对的；分歧分规则错误 / 门派差异 / 取舍差异三类；对方指出的错逐条认 / 不认 / 部分认，硬错优先认；只重发被推翻的条目（`22` 五.1）。
- **事后复盘**：先调出事前登记（记录文件、记忆或本会话可见内容；找不到就说找不到，不凭印象补）；按事前定义的可观察结果与时间窗口判定；各镜分别判；事后解释单列不回填（`22` 五.2、十）。
- 复盘里发现规则层面的系统性问题，记下来作为改 `11` 默认的证据，不在单卦里临时改规则。
