# 10 · 专题断法（各类占断要点）

> 各事项的取用、吉凶标志、取象、应期要点。每条尽量标门派。用时仍走引擎 `00` 全流程，本文件是"专题加速器"，不替代推演。
> 本文件收录的是各派原话。其中涉及当事人心思、人格、第三者、死期寿数、选股的说法，保留为原作者观点；断卦时按 `22` 九处理：只转写成爻位状态，第三者象过门槛，不写病名死期，不选股。

## 一、求财
- **取用**：妻财为用、子孙为原神（财源）、兄弟为忌（劫财）、父母为仇。世为求财能力。
- **得财标志**：财福两旺不逢克；财持世/生世/合世/克世＝"财来找我"易得（克世须世旺能担）；子孙旺生财＝财源绵绵；**兄子同动财源更厚**；官化财生世＝公家/官方求财利；财多太旺须**入墓库收**（入库日到手）；财空墓逢冲日得、出空可得。
- **不利**：卦无子孙财爻＝莫费神；**父兄同动＝水中捞月一场空**；兄弟持世/旺动＝破财（"兄弟持世莫求财"，但兄入墓/财临日月冲兄/兄逢空破时仍可得，须世财两停）；财化兄被劫、财化鬼有耗、化父劳累、六合变六冲无财；测财遇兄临岁君动＝必有一年破财之灾。
- **官鬼持世求财**（曲/张鼎）：财动生世可得、世动财静可求；但兄也动则破财、财官相合则得不到。鬼旺只在下卦内三爻可得（张鼎）；空手求财（靠技艺/名气）看官爻。
- **进货/股票**：财最衰时进货/最低买（须卦中财扶得起）、财最旺时抛（注意最旺时是否逢空破墓绝）。（原作者说法；当前版本可断"这笔交易成不成、何时有变"作参考，不推荐标的、不给仓位，`22` 九.4）
- **长短期（曲炜）**：长期求财须财与世相生相合（如开店与客户搞好关系）；短期求财财世两旺有任何联系即可得（一次性交易兄弟持世也得财）。
- **得财数**：取财爻纳甲数/地支数/卦数，旺加倍、衰如数、死绝减半，结合规模定单位。
- **张德视角**：兄弟克财＝豪夺（赌博/意外/股票等非常手段）、官鬼泄财＝巧取；"兄弟持世破财伤妻"是谬论（→[11]）。
- **彩票（袁）**：偏财为喜逢生、在五六爻临太岁＝中大奖（袁氏体系内说法，少数派，不单独摘用）。

## 二、婚姻 / 感情
- **取用**：未婚以**世应**为主（世我、应对方），男兼看妻财、女兼看官鬼；已婚以世+男财女官为用。（两条线方向相反时怎么写主判，见 `00` 十三.6）
- **成否**：世应相生相合比和＝可成；相冲相克＝难成（除非通关化解）。世生应＝我爱慕对方、应生世＝对方爱慕、相合＝彼此爱慕。男测世宜阳、女测世宜阴（阴阳得位）；发动方＝主动方。
- **未婚持世信息**（原作者观点，属断心类断语）：兄持世＝逢场作戏不想结婚；子孙持世＝爱自由不想结婚；财持世(男)/官持世(女)＝想娶/想嫁（内卦已发生关系）；父母持世＝事业心强、想成家。→ 当前版本只写持世六亲与用神的生克状态，不写求测者或对方的心思（`22` 九.1、九.5）。
- **忌象**：男忌兄持世、女忌子孙持世（未婚不成、已婚生死别离）；两财两官＝外遇/再婚之兆；六合变六冲＝不能长久（"六冲卦测婚不出三年必分"——张鼎，来源说法，不写"必"）；得《姤》卦男女测婚终不顺。→ "外遇/再婚之兆"属第三者类取象，过 `22` 九.2 门槛才进主判；用神两现先按 R16 判各司其职。
- **外遇定向**（原作者观点）：男——财临玄武(妻暧昧)、官临勾陈(妻有旧情人)、财与官/兄日月相合或财下伏官＝妻有外遇；女反之。"谁临玄武谁暗昧、谁临勾陈谁勾连。"财发动合官＝妻主动勾引、官发动合财＝别人勾引妻（发动者为主动方）。→ 当前版本：这些只是第三者门槛里的"候选卦象"之一，须两处独立卦象、来意不否定、断前先问、写成备选并配读偏条款（`22` 九.2、`00` 十三）。
- **对方是否已婚**：官伏财下/财伏官下/一官两财/一财两官/月日现财官——分清过去未来。
- **看相貌/家庭**：以应/财官+六神+地支字形看相貌；以世/应所在卦旺衰看双方家庭；年龄差以世与用神所临卦（乾老男·坤老妇·兑少女·艮少年）+纳甲序数差（曲炜例：兑配乾断对象大13岁验）。
- **张德视角**：官鬼=控制权/话语权、妻财=付出感情，**非机械等于丈夫/妻子**；《黄金策》"应财世鬼夫唱妇随、应鬼世财夫权妻夺"。
- **女测子孙持世非必克夫**：子孙休囚空破墓绝/受克合/有财通关则不克夫甚至助夫。

## 三、事业 / 官运 / 调动
- **取用**：官鬼为用（职位/官方）、父母为印（单位/调令/文书）、子孙为忌（克官丢官）、世为己。
- **吉象**：官鬼旺而不破不坏、官旺生世/持世；调动需"官+父母+世"三者齐全、身旺、官(领导)父(调令)同旺、用神动才可调。
- **凶象**：官鬼受**日建化坏/动化回头克**（虽旺也丢官）；子孙持世/动克官＝与官无缘/易丢官（但求公检法类官职、子孙持世反有利——曲炜）；官与世冲＝领导不同意。
- **官的性质**：看官子午卯酉为正职、寅申巳亥为副职；木官科技、火官教育、土官建设、金官司法、水官巡察。
- **曲炜**：子孙持世非必无官（子孙休囚、官旺仍可当官）；官鬼持世非必有官（休囚空墓则无）。退休/下岗取官爻，官受克逢合遇冲化退化空入墓为离岗期。
- **张德**：世持官鬼克临应兄弟＝以手段掌控克阻力，但**须临应兄弟有气不空不破**（否则对方示弱诱敌，世越轻举妄动越倒霉，"打在棉花团上"）。

## 四、疾病 / 生死（各派分歧最大；当前版本不写病名、死期，`22` 九.3）
- **取用（丁派四分法）**：① 测父母病：父母为用、财为病、官为医生；② 自测：世为用、克世为病、生世为医；③ 测他人病：官鬼为病、子孙为医药；④ 以官鬼为用者：用原越旺病越重（与①②③相反！）。
- **曲炜（反对死看官鬼）**：把**主卦当一个人体**看，**最旺五行及被其克之五行＝病症所在**；官鬼为忌闲仇神时只代表**病位**（官在五爻＝胸、六爻＝头）、不代表病症；官为原神/世被克才表病症。动爻及日月冲之爻位也是病位。
- **病灾 vs 伤灾**：世/用旺而受克多伤灾、衰而受克多病灾；鬼化鬼/鬼化兄/兄化鬼/兄化兄、用神太旺（太刚易折）、临白虎受克——多伤灾。
- **实病 vs 虚病**：用原受克、阴阳失衡＝实病；用不受克、世用临腾蛇玄武、医院查不出＝虚病（早期精神病/怪异信息场/低灵干扰）。病因看用神所临六神/腾蛇所临爻五行/官鬼忌神五行/伏神/动变五行六亲。
- **寿数**（原作者断法）：世旺/临日月/得生扶/化生化旺＝长寿；占寿原神不宜动（动则寿有限，死于原神墓绝/被冲克之年）、忌神不宜动（死于忌神逢合/值年）。**用神入进行时墓**常为死期判据。→ 当前版本不输出死期、寿数（`22` 九.3）；占寿类问题只答病势轻重倾向与需重视的时段，并提示就医。
- **刘虹言更正**：古分久病近病（久病逢冲死、近病逢合不吉），改"轻病重病"（重病逢冲为吉/逢合不吉）；突发昏迷须加"问寿"思维。
- **部位**：鬼爻卦宫定部位（乾头·兑咽喉牙·离眼目心·震手足·巽肠道瘫·坎血肾·艮背指·坤腹）；五行定病经（金肺·木肝·水肾·火心·土脾）；爻位定部位（→[01] 七）。
- **四土俱全俱动**（张鼎/墓书加权信号）：原书说测病多主癌症/死期，须与其他病象互证（→[04]）。→ 当前版本只作"病象需重视"的加权警示，不写病名与死期（`11` R09、`22` 九.3）。

## 五、官司 / 诉讼
- **取用**：世为己、应为对方、官鬼为法官、父母为诉状、间爻为证人、子孙为解救（旺动＝有人调和）。
- **胜负**：不论谁克谁，**看世应力量谁大谁胜**；世克应＝我欺人、应克世＝他欺我。太岁临官＝官司升级；财爻主理（持世我有理）；父母空/无＝证据不足打不起来；对方告我＝父母临应动。
- **牢狱标志**：世/鬼/用入墓、三刑、勾陈克世、白虎临兄动、勾陈临世/忌发动克世。官鬼越旺官司越大；**官鬼受克反吉**。
- **起因三方面**：某六亲临朱雀动 / 某六亲动变官鬼 / 官鬼临某六神动。
- **六冲卦官司易散。**

## 六、失物 / 盗贼
- **取用**：贵重物以**财**为主，测盗取**官鬼**、抢劫取**兄弟**。
- **可寻象**：财在内卦本宫无伤无劫、财旺静持世/生世/合世、鬼不上卦/空亡/衰绝不动、财化子孙生合世。
- **难寻象**：财空/化空、财在外卦外宫旺动、财动、鬼动/变爻为鬼（别人偷）、财伏难出、财死墓绝胎、财入兄库（被同辈拿走）。
- **方位**：财在何卦定方位（乾西北·坤西南·震东·巽东南·坎北·离南·艮东北·兑西），动则看变爻方位。
- **何人**：兄/鬼在外卦动＝外人/不识者，在内卦动＝家人熟人；旺＝青年、休囚＝老年、临胎养长生＝小孩；配地支五行肤色字形。**知情人看子孙发动**。

## 七、行人 / 寻人 / 出行
- **取用**：代表该人之六亲（或代测以世代之）；五爻为道路、兄弟为阻碍之神、马星为车。
- **问法三分（曲炜，一念之差天壤之别）**：问平安 / 问能否走成 / 问能否回。
- **能否回**：用神逢合＝迟归（绊住）；用神冲世/日建冲用＝人即归（"用神冲世人即回"）；世/用值空＝人不回（真空难回，动空静空＝暂不回）。归魂卦难来/难变（世用逢冲才变）；游魂卦主变（世用被合则变不了）。
- **走成否**：最怕日月动变合住用神（有事绊住）。
- **远近/方向**：用神本宫内卦＝不远、本宫外卦＝本地、外宫外卦＝出本地；卦吉在最有力喜神方、卦凶在最有力忌神方。
- **出行避灾**：忌官鬼持世/克世（火鬼防火、木鬼防木）、鬼临蛇雀＝官非火灾、勾陈克世＝田土牢狱；五爻动克世/世在五爻受克＝道路灾（父母在五爻克世＝车祸）；躲灾向子孙/生世之爻方向（官鬼持世则不能向子孙方）。

## 八、学业 / 求名 / 升学
- **取用**：父母（文星/成绩）+ 官鬼（功名/名次），子孙为忌（不可克世/克父）。艺术类偏重子孙（曲炜）。
- **吉象**：父母旺＝成绩好、世旺不入墓＝临场发挥好（旺相入墓＝没发挥好）；官鬼旬空待**填实之年**考取。
- **凶象**：世休囚＝信心不足竞争力差；父母克世（有兄弟通关也可学会，但花钱多）。

## 九、天气
- **取用**：子孙/妻财＝晴、父母＝阴雨、官鬼＝雷电雾、兄弟＝风云。
- **要点**：父母旺雨大，临水最大、临金稍大、临木一般、临土火小；财父同动＝先雨后晴/时晴时雨；父子同动＝先晴后雨；官化入水库＝雷电收、雨止（定结束时间）。测当日天气子时起卦为好。
- **张德辟谬**：**"木动生风、水动下雨"皆荒谬**（父母巳午火旺动照样下大雨）；狂风台风属风灾用官鬼；"合父鬼冲开有雷则雨"正解＝官鬼去冲"合住父母的那个爻"（非官鬼直接冲父母）（→[11]）。

## 十、家宅 / 风水
- **取用/爻位**：二爻＝宅、父母爻＝具体建筑、五爻＝人。宜人克宅/宅生人/相生比和；忌宅克人、人生宅。宅新旧看父母爻旺衰。
- **爻位（家宅）**：初地基水井·二宅灶·三门床墙·四大门·五道路人位·六栋梁屋顶。
- **吉凶**：宜六亲全上卦+安静+六合（藏风聚气），忌六冲（散气住不长）；忌兄鬼父财发动（兄动不利财女、官动灾祸、父动烦劳、财动耗费），最利子孙发动（平安生财，唯不利当官人）。
- **门路煞**：五爻合二爻为门（定门向）、冲二爻为路；初二爻临官鬼墓＝宅基下有古墓（白虎＝伏尸、空＝已弄出）；三四爻同五行＝穿心煞。
- **张鼎"一门二灶三床"**：阳宅三要；主屋须为制高点（偏房高于正屋＝大凶"阴阳颠倒"）。
- **袁炜明"卦爻颠倒颠+过路阴阳"**：砂=高一寸、水=低一寸，八方砂水按爻位；秘诀"**喜神受制时，砂水正断、吉凶反断**"；调整须"除煞形+送煞神"形神兼备（少数派整套用）。
- **张德提醒**：不平安/不发财未必是风水原因（先入为主），事主实为官运而占则卦意直接反映官运、不必硬扯风水。

## 十一、终身 / 流年（六爻测终身不如四柱——曲/张德共识）
- **流年（邵"月变日不变"法）**：以世爻为主，逐月推旺衰、找灾月吉月（月建只司当月、日辰始终其事）。墓书"断流年秘籍"：①看世爻→②看动爻→③查暗动→④看静爻→⑤据生克爻位六亲六神判应何事→⑥以月为单位推应期→⑦提趋避。先定全年总吉凶再逐月细推。
- **终身（袁七步）**：判世爻旺衰→区分喜忌→格局高低/财官→天干六亲→排大运→断流年→六亲流年。先断以前流年验证思路对否，对了再断未来。
- **大小限（张鼎）**：10年一大限（主卦初爻起每爻10岁、超60从变卦世爻续）、每爻一岁小限（世爻起，阳顺阴逆）。用大小限条件：六静/六冲/终身卦/4岁后来测者。"老怕长生少怕衰，中年最怕死绝胎。"
- ⚠️ **一卦多断之争**：测流年/终身这类宽主题可多角度断；但**单项具体事不可一卦多断**（曲/张德，`11` R15）。

## 十二、测来意（曲炜四切入 / 张德共性法）
- **曲炜四点**：①看世爻（求测者处境心理）；②看动爻变爻（卦的中心，"天机尽泄于动变之间"，动揭示发生何事、变揭示起因结果）；③看应爻（环境/气场）；④看六神（定向事物类别）。结合社会常理（七八十岁老人不太可能问婚财）。
- **经验诀**（原作者观点）："不肯说测何事让你断来意者，多是难言/外遇/贪赃之事——测出才说实话。"→ 不用于判断求测者；本包默认先问清来意，不练测来意。
- **张德**："共性法"主动测来意；"来意不需测，一定要问清"——非练功不必硬测来意。
