# 23 · 落地翻译协议（包内最小版）

> 用途：把推演产出的卦理判词翻成求测者能核对、能照做的现实话。本文件让 liuyao-core 单独安装也能完整工作。
> 共享技能 `oracle-grounding` 若已安装，可作增强（见第六节）；没装就按本文件走，不缺环节。
> 本层只管表达与落地，不改推演结论、不改门派裁决、不改置信度。

---

## 一、两阶段隔离（最高优先）

1. **先推演，后翻译**。第 0～9 步（`00`）先推出域中立的卦理判词：只有爻位、六亲、生克冲合墓空、卦名，没有现实名词、关系词、心理词。
2. **翻译只许翻**：不新增判词里没有的结论，不削弱、不反转判词。判词说"用神入墓待冲"，翻译不能写成"基本没戏"，也不能写成"很快就成"。
3. **硬冲突报回**：翻译时发现判词与求测者现实处境明显对不上（例：判词指向"文书受克"，但求测者说根本没有文书环节），回到第 7 步复查取象、第 2 步复查取用，不在翻译层悄悄圆过去。复查结果写进"修订说明"（`00` 十）。
4. **置信度原样搬运**：翻译写得越具体越显得准，但具体不等于为真。翻译层不升级置信度。

---

## 二、判词翻成现实话：三段链

每个关键判词走三段，缺第三段就是空断，重写：

```
符号关系        →  力学（谁压谁、谁生谁、何时解锁）  →  求测者处境里能核对的表现 1～3 条
官鬼动克世爻       外部的规则/压力正在找上门             这周有没有被催交材料、被约谈、被加条件
```

- **用求测者自己的说法**和他所在行业、场景的叫法写第三段；不熟悉的领域，先问一句他那边怎么称呼，或只写到力学层，不用"赋能、抓手、闭环"这类通用黑话凑。
- **隐结构**（伏神、入墓、旬空）翻成"还没显出来 / 被收住 / 还没落实的那条线"，同时写"等什么才出来"（对应应期的病与药）。
- **矛盾分层，不取平均**：吉凶混杂的信号分到不同层——能不能成 vs 成了之后怎样；现在 vs 应期之后；这件事 vs 这个人的处境。各层各一句，不写"总体有好有坏"。
- **吉象写成条件**：只有卦象本身支持时才写"做 X 则兑现，不做则不兑现"（例：世爻静而得生，资料有"人动则得生"之说，可写成"你主动推进，这条生扶才用得上"，并标派别 R06）。卦上没有这层，不硬造条件。
- **六亲六神只取象**：六神决定"是什么性质的事"，不决定成败（R14）。
- 断语边界照 `22` 九：不断心、第三者门槛、不写病名死期、不选股。

---

## 三、建议怎么对应判断

1. **每条建议锚回一条依据**：写清它解的是哪个盘面张力。例："应爻旬空（对方这条线未落实）→ 先要一个书面确认，再投入下一步。"
2. **讲机制**：一句话说明为什么这样做有用。换个人、换件事照样成立的建议是空话，重写。
3. **至少一条排除项**：给建议就写一条"不要做什么，因为……"（例："不必急着加价，财爻旺相，卡点不在价钱而在文书"）。
4. **时机建议对齐应期**：宜动的时间放在应期候选上，写条件分支（"若到某日对方仍未回复，则……"）。
5. **做局**：择日合局可作时机选项；择人随行、化贵入卦默认不用；用户明确要做局时介绍并标"卜筮正术"（R25）。不导购、不承诺功效。
6. **什么时候不给**：只问结果、只问时间、纯解释规则时不给建议（`22` 二.5）。

---

## 四、冲突怎么处理

- **双镜冲突**：以第 8 步仲裁结果为准写主判＋备选＋触发条件，翻译层不自行调和成一句。
- **判词之间冲突**（同一爻既被生又被克等）：判词层已经按十六字与层次定了次序，翻译照次序写，不改。
- **翻译与现实冲突**：报回推演，见第一节第 3 条。
- **用户要求"说好听点"**：可以调整措辞和顺序，不改倾向和置信度。

---

## 五、行动卡（按需）

- **何时给**：涉及现实决定，且建议多于三条或带时间表时，附在标准输出最后。纯解释追问、单点追问不给。
- **内容**：一句话结论＋时机表（窗口｜依据｜宜｜忌）＋禁区。
- **零新增**：全部压缩自正文，正文没有的东西不进卡；置信度标签原样保留。

```
行动卡
结论：<一句，含置信度>
时机：<窗口>｜<机械依据>｜宜<…>｜忌<…>
禁区：<一条>
```

## 六、与外部 oracle-grounding 的关系

- 已安装时，可借用它的域模型卡、义项池、顾问式六段骨架，让第三段清单更具体。
- 两者冲突时以本包为准：本包另有一事一断、断语边界（`22` 九）、应期机械依据（`22` 八）、建议按需给（`22` 二.5）等专属纪律；oracle-grounding 里"趋避必给、行动卡必给"不覆盖本包的按需规则。
- 没装时不提示用户去装，按本文件完成即可。
