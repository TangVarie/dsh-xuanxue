# 07 · 旬空与伏神

> 四钥匙之二、之三，与"墓"同列"为先"。旬空＝"暂时的无/虚"，伏神＝"用神不上卦、藏在背后"。

## 一、旬空
### 1. 查法
- 按**起卦日干支**查（张德强调：不按年月时查空）。每旬两支无天干配即空。速查见 →[01] 六。

### 2. 真空 vs 假空（最关键）
- **真空**＝休囚逢空：旬空期及出旬出空均**无生克权**、到底无用（即便逢冲出空填实仍为空——张德"原象衰空之爻最终为空"）。
- **假空**＝有气逢空：只本旬空，**出空便有生克权**（出空可成事）。
- 判据口诀（野鹤/邵）："**旺不为空，动不为空，有日建生扶者不为空，动而化空不为空，伏而旺相不为空。**"——指不为**真空（到底空）**，最终冲实/出空/填实即有用。

### 3. 出空 / 冲空 / 填实
- **冲空填实**：旬空**旺相**逢冲＝暗动/冲实（不空、可用）；旬空**休囚**逢冲＝又空又破（必成灾咎）。
- **出空**：出旬、逢值、填实（同字到）即出空全力（曲炜："冲空只发挥一半力量，出空全力"）。
- **自空化空，必成凶咎**（用爻旬空又化空，谋事不成）。
- **应期单位**：测年运按月推出空、测月余按日推、测日内按时辰推（→[09]）。

### 4. 各占类旬空（林潮《断卦技法》"一看空"）
- 测合作以应为用：应空＝对方不实；旺空＝多忧虑无定准；衰空＝无实力/有假/虚诈。（林潮原话。当前版本断语只写爻位状态：应空＝对方这条线暂未落实、旺空待出空可用、衰空到底难落实；"不实、有假、虚诈"属断心词，不写，`22` 九.1）
- 求财：财旺空，出空可得；财衰空＝无财。
- 行人：用旺空，出空人现；用衰死空＝人有险或失。
- 伏空：旺则填实/冲飞得用；衰死空，填实/冲飞则有凶。
- 避逃逢空＝主暂无事（仍须综合旺衰冲填）。
- 测流年世爻真空＝一年事与愿违；非真空仍能成事（未出空前钱不到手/挣不抵花）。

### 5. 袁炜明"旬空反断"（少数派，整套用）
- 旬空之爻**喜忌反断**：喜神空作忌看、忌神空作喜看。
- **不反断的例外**：旬空爻发动时、被日时支冲时、临时支时——不反断（另在不同爻位有更细规定，原书学习班保留）。
- ⚠️ 仅在袁氏体系内成立，**不要单条摘出套别派盘**（`11` R13）。

## 二、伏神
### 1. 何时取伏神
- 用神不上卦（卦中无该六亲）时，于本宫首卦找该六亲＝伏神，伏在对应爻位（飞神）之下。
- **卦中无某六亲也是信息**：无官鬼可揭示离婚/无夫；无财非测婚必无妻（兼看应、伏财）。

### 2. 伏神出现（得用）只有四法（曲炜）
- **值、临、冲伏、冲飞**。**合伏神/合飞神都出不来。**
- 口诀："**伏无提挈终徒尔，飞不冲开亦枉然**""冲飞露伏"。

### 3. 飞伏生克
- **飞生伏**＝飞神泄气、利伏神（吉）；**伏生飞**＝伏神泄气（不利）；飞克伏＝伏神受制（凶）；伏克飞＝伏神有力可出。
- 伏神照论旺衰、月破、日破、入墓（入飞神/月日之墓）。
- 旺相有气之伏神：在出空、冲伏/冲飞时有用；衰死伏被飞克则凶。
- 伏神逢空（曲炜）：有气为假空，出空逢值有用；无气逢值也无用；**冲空、冲飞都解不了伏神的空**。

### 4. 真假六亲（与伏神配套，测亲属/生死大关时用）
- 本宫内卦出现的六亲为"真"（代表肉体/人身），外卦或他宫者为"假"（代表能力/地位/事物之象）。
- **真六亲受克＝人有灾；假六亲受克＝事/物有问题**（如破财，而非妻有难）。
- 黎光《易隐》另有"对宫取伏神"等高层取法（→[11] 备查）。
- 张德**否定**"以世爻地支重定六亲"那一套真假六亲（张德观点）；本库默认仅用上面这一层"本宫真假"，且只在亲属大事时启用。

## 三、自检
- [ ] 空是真空（休囚，到底无用）还是假空（有气，出空可用）？
- [ ] 旺空逢冲＝冲实（不空），别误判成"破"；衰空逢冲＝又空又破。
- [ ] 应期：出空/冲空/填实哪个先到？单位对吗？
- [ ] 用神不上卦：伏在哪？飞伏生克如何？能靠值/临/冲伏/冲飞出来吗（合不解伏）？
- [ ] 袁氏旬空反断只在整套袁氏体系内用，标注来源。
