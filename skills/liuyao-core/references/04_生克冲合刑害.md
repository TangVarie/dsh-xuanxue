# 04 · 生克冲合刑害

> 把静态旺衰变成动态因果。先定**次序**，再逐类处理。核心两条：①「先生后克、先动后静、无生则克、无克则生」（邵/林）；②「合冲优先于普通生克」（曲）。
> 当前默认：静爻能否受生见 `11` R06；三合成局见 R08；刑害见 R09。

## 一、生克的次序（铁律）
- **十六字诀（邵伟中/林潮）**：「**先生后克，先动后静，无生则克，无克则生**（无生则仍然克）」。
  - 操作：日月先生"它能生的动爻"，无可生动爻才克可克之动爻；对动爻处理完，再对静爻行权。卦中爻同理。
- **关键限定（邵伟中/林潮派）**：**动爻只生动爻，但可克不动之爻**；**不动之爻不得生**（爻虽临日月之生，不动只是"相生之象"，须发动或旺时才真得力）。有通关之爻则循环相生有情。
  - ⚠️ 这一条与本包默认的曲炜四层次（上层次可生克下层次）和《增删》（静爻可受生）不同。本包默认按 `11` R06：静爻得不到生时，先找"生者自身受制"（空、破、回头克、被合绊）这个两派共认的理由；只能靠本条解释时，断语标"邵/林派"、降一档、给备选。
- **特殊关系优先（曲炜）**：同层次里 **合、冲 > 刑 > 害 > 普通生克**；下层次的刑冲合害一律让位于上层次爻。
- **隔爻生克（曲炜）**：紧贴作用大；相隔/远隔作用递减（可忽略），但"隔也作用"。

## 二、冲（六冲：子午·丑未·寅申·卯酉·辰戌·巳亥）
**同一个冲，结果取决于被冲爻的旺衰/动静——四态：**
1. **冲起（暗动）**：旺相**静爻**得日辰冲＝暗动，获生克权。
2. **冲破（日破/月破）**：休囚**静爻**得日冲＝日破；月建冲爻＝月破。"逢生不起，逢克更凶。"
3. **冲实**：旬空**旺相**爻逢冲＝冲实（不空、可用，本质是"动不为空"）；旬空**休囚**爻逢冲＝又空又破（必成灾咎）。
4. **冲散**：卦中爻逢冲则散；但**被月建合者日冲不散、被日建合者月冲不散、日月参与的合局冲不散**。
- **连冲带克 vs 只冲不克**（袁/曲）：子冲午、申冲寅、酉冲卯、亥冲巳、丑冲未、辰冲戌＝连冲带克（力大）；午冲子、寅冲申、卯冲酉、巳冲亥＝只冲不克（力小）。"冲"比"克"彻底（含克力+斥力）。
- **成立条件（邵）**：卦中两爻相冲，**须有一方是动爻**才论冲；六爻俱静的六冲卦"只有相冲之象，不以相冲论吉凶"。

## 三、合
### 六合（子丑·寅亥·卯戌·辰酉·巳申·午未）
- **生合 vs 克合**：生合（寅亥、辰酉、午未）易成化；克合（子丑、卯戌、巳申）难成化（藏干内因决定）。
- **合化 vs 合绊（邵伟中细判，重要）**：相合两爻——与合化后五行**相同者仍能生克它爻**；**不同者被绊住**（失生克权）。
  - 例：寅亥合木，寅本是木仍以木性生克；亥合化为木性则不再以水作用（被绊）。卯戌合火，卯戌都改以火加力。
- **被绊**："被抱住的人不能打人，但别人能打他"（曲炜）——被合之爻不能去克它爻，但它爻仍能冲克它。
- **日月与爻相合**：**日月本身五行属性永不变**（如申金日合卦中巳火，巳被绊，日仍以申金行使生克）。
- **成立条件**：六合须**两爻皆动**（或一方为日月/变爻）；静爻一般只论"合象"（信息：内心思维/团结友好），不论"合力"。
- **吉凶**：合住忌神为吉、合住喜神为凶；合吉为吉、合凶为凶（卯戌合化火生土克水→若助了忌神则"合凶"，古例断死）。
- **争合**（同层次两个同字同合日月）：用情不专、合不牢，仍有些生克权（变爻与动爻非同层次，不构成争合）。
- **测事取向**：测喜事喜合忌冲（合则长久、冲则易散）；测忧愁喜冲忌合（冲则忧散、合则缠绵）。测出行逢合＝绊住难走。
- **张德视角**：地支六合**都为合绊、不论合动**，象义＝拉拢/合并/缠绵/挽留/克制/稳定长久；六合卦预示"远、缓、慢、稳、久"，六冲卦预示"近、急、快、乱、短"（→[11]，与传统"须动才合"有别，属其体系）。

### 三合局（申子辰水·寅午戌火·亥卯未木·巳酉丑金）
> 以下为主流/曲炜说法，也是本包默认（`11` R08）。《增删》要发动或日月补齐、静爻不成局；《卜筮正术》借月建补字只用于应期（`19` 五）；盲派月建不参局（`16` 七）。结论依赖"静爻成局"或"日月补字判吉凶"时标源降档。
- **中神（子午卯酉）为要**，另两神成就中神；**须中神旺/动才易合化**，否则合而不化为绊（待中神趋旺）。
- **缺一字**：缺的字在日/月出现仍可合；多一字、两字反加力；**唯独缺一字不能成局**。
- **受月令制约**：月/日与卦爻同时克本气、且合局在日月休囚时，合局不成（例：午月火旺、巳火克酉、酉化墓，则巳酉丑不成局）。
- **化墓/化长生（袁）**：中神动化墓库减力（卯化未、子化辰、午化戌），化长生增力（子化申、卯化亥、午化寅）。

## 四、合冲互解的次序（曲炜，务必牢记）
- 起卦顺序＝主卦 → 变卦 → 月建 → 日建 → 进行时月日。
- **主卦的合冲，变爻可解、日月可解；动变爻与日月的合冲，进行时可解；月建与卦爻的合冲，日建可解；日建与卦爻的合冲，进行时日月可解。**
- 推论："月建与卦爻之冲，日合可解；月建与卦爻之合，日冲可解。" → 由此判断是"冲解合"还是"合解合"，并据此定应期（→[09]）。

## 五、刑
- **多数派（邵/曲/张德）：基本弃用三刑，有生克权就以生克论。**
  - 寅巳申同动：以寅生巳、巳(火)克申论（寅申冲则巳申不合）；子卯刑：按子水生卯木论。
  - 曲炜："有生克权就不论刑"；土刑（丑未戌、辰午酉亥自刑）＝激起土气使土更旺、力量叠加；刑不论动静、不能使爻暗动。
- **重刑派（张鼎/墓书，专题加权信号）**：
  - 子卯＝无礼之刑；寅巳申＝恃势之刑（多犯法、肢伤、凶险）；丑未戌＝无恩之刑（多体病、且易土旺）；辰午酉亥＝自刑（虑事有误）。
  - **丑未戌三刑 / 四土俱动**：力大于寅巳申且**难解**，俱动主死伤、病灾、癌症、刑狱（"十刑九有灾""库逢刑则开"）。
  - **四土全（辰戌丑未）**：①四刑"十件事没一件成"；②"凡看病四土俱现非死不行，四土俱动死期到，80%癌症"（原作者说法，未经本包数据验证，`11` 六；断卦时不输出死期、病名，`22` 九.3）。查全不全：主变卦+日月都算，伏神不算。
- **取向**（`11` R09）：常规不以刑为主力；遇测病/测灾且四土明显俱全俱动，作加权警示，与其他病象互证（守"两象定一象"），不单凭三刑下重断。

## 六、害（六害：子未·丑午·寅巳·卯辰·申亥·酉戌）
- 极少用，多作辅助信息（如"卯辰相害也指伤灾"）；《增删》不用；不进应期依据栏（`11` R09）。
- **谁害谁（曲炜逐组）**：子未害＝未克子；丑午害＝午生丑(丑害午)；寅巳害＝寅生巳(巳害寅)；卯辰害＝卯克辰；申亥害＝申生亥(亥害申)；酉戌害＝戌生酉(酉害戌)。生者三组主"生方受损"、克者三组主"受克方受损"。
- 张德：害＝妨害、拆散、独占（与六合相反）；作用上按一般合冲生克处理。

## 七、通关 / 贪生忘克 / 救应 / 流通（曲炜辨析）
- **通关（贪生忘克）**：连续相生使相克双方不相克（卯生午、午生丑，卯不克丑——午通关）。须**有生克权之爻发动**来通关；通关爻被合/入墓/月破/化回头冲克时**不能通关**，链条断节处必有两动爻相冲克。
- **救应**：既有生又有克同时存在（生者不起通关作用，只"对应"）。
- **流通**：三个及以上不同五行连续相生。
- 三者区别在于"是否化解了相克"。
