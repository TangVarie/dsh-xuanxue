# 18 · 六爻源流 · 汉易卦气（理论背景）

> 来源：一批"汉易"讲课记录（乙未汉易20课、汉易9/14课、十三课、建候积算；QQ 群聊体，已清洗；原始记录未随包分发）。
> **定位（务必先立）**：这是**理论源流 / 思想背景**，回答"今天的六爻为什么长这样"，**不是断卦操作规则**。京房是纳甲六爻的祖师——纳甲、纳支、八宫、世应、游魂归魂、寄生十二宫、爻位，这些**零件全部源自京房卦气**。默认**不调用**；只在你想理解原理、追源流、或做学理探讨时按需读取。其中不少内容**现代六爻已弃用**，本文件如实标注，绝不冒充实战技法。

## 一、卦气说（源头）
- **十二消息卦**：以阴阳爻的逐月消长配十二月（复→临→泰→大壮→夬→乾→姤→遁→否→观→剥→坤），是"月令旺衰、进退神、月相定应期"的思想底色。
- **卦配节气 / 六日七分 / 七十二候**：六十四卦配一年节候（每卦约六日七分）。→ 现代六爻**已弃用**，仅作源流。
- **一月三十日配卦**（乙未汉易）：初一地雷复→三十坤，按月相阴阳消长排卦；配月相吉凶（上弦未成、望成功、下弦消退）。属象数推演，**记录如此、操作性低**。

## 二、纳甲 / 八宫 / 世应 / 游归 的源流
- **月体纳甲**：以月相方位配八卦天干（京房—魏伯阳—虞翻一脉），是"纳甲"之所以如此配的天文背景。
- **八宫卦序 + 世应 + 游魂归魂**：京房把六十四卦编为八宫、按本宫→一世…→五世→游魂→归魂定世位（即 `14` 装卦表的八宫表来历）。
- **寄生十二宫（长生沐浴…墓绝）**：源自星占/历法（讲者提及"长生命名为沐浴""《开元占经》"），演化为今天六爻的长生墓绝判断（`03`/`06`）。

## 三、建候（残缺骨架，标注存疑）
- 大意：每卦从**世爻**起、按节气逐爻"建"一个月，标识该卦各爻所主的月令时段。
- 本批资料（"一路向北"道家六爻版）**未给完整起例**（未明确"从世爻起"的全部规则、未给六十二卦例），且个人化、夹杂跑题。→ **只存骨架、不作操作用**；现代主流六爻基本不用。

## 四、积算（残缺骨架，标注存疑）
- 大意：六十甲子按六爻顺序循环排布以"纪日/纪时"（讲者版："乾起甲子、坤起甲午→六十甲子按爻顺序排满→查位置→配纳音断"）。
- 该版把"纪日"讲成纪"流年"、与京房原典有出入，**未给完整算法**。→ **源流参考，弃用为主**；讲者本人也称"很少用、可以不用但必须会"。

## 五、对现代六爻的"思想借鉴"（可取的）
- **"消息爻只与世爻论关系"**（十三课）：化繁为简的取用思路——盯住关键爻与世的关系，与库内曲炜/玄空子"以世为太极点"相通，可借鉴。
- **十二消息 / 阴阳升降**：理解月令旺衰、进退神、月相定应期"为什么这样"的底层模型。
- **源流自觉**：知道纳甲/世应/长生等都来自京房卦气，断卦时对这些"零件"的分寸感更稳。

## 六、明确已弃用 / 仅作源流（勿当技法用）
- 六日七分、七十二候配卦；建候、积算（纪日/纪时）；纳音=五星之说；"地支不克天干"等个别讲法。
- 这些**不进断卦运算**；如用户专门问源流再引用本文件。
