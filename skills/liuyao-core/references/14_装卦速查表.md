# 14 · 装卦速查表（从摇卦结果排出完整卦盘）

> 用途：用户**摇卦**得到六爻后，用本表装出可断的卦盘（纳甲地支·六亲·世应·六神·旬空·变卦·伏神）。
> 装卦必须零错误——一步错则满盘皆错。r6.0 起：本表是规则来源，`scripts/paipan.py` 按本表把装卦做成可重复计算；手装后用脚本核一遍，截图用 `paipan.py --verify` 出差异清单。脚本与本表不一致时，以本表为准并报告脚本错误（`tests/test_paipan.py` 用本表的八宫表与世应口诀互相校验）。

## 〇、记录摇卦结果
每次摇卦（三枚铜钱）得一爻，自下而上六次：
| 铜钱（本包约定） | 爻 | 符号 | 爻值 | 阴阳 | 动否 |
|---|---|---|---|---|---|
| 两背一字 | 少阳 | `／` | 7 | 阳 | 静 |
| 两字一背 | 少阴 | `／／` | 8 | 阴 | 静 |
| 三字（三正） | 老阳·重 | `○` | 9 | 阳 | **动**（阳极→变阴） |
| 三背 | 老阴·交 | `×` | 6 | 阴 | **动**（阴极→变阳） |

> ⚠️ **铜钱字背有相反约定**：坊间另有以背为阳面的算法（背记 3、字记 2），那样三背为老阳、三字为老阴，与上表正好相反。用户只报"几个字几个背"时，先问他按哪种约定，或请他直接报每爻阴阳与动静；`paipan.py --coins` 要求写明 `--coin-rule 本包|背为阳`。

> 用户也可能直接报"某卦+第几爻动"或六个阴阳。先还原成"初→上"六爻的阴阳 + 哪几爻动。
>
> **同时必须落实"四值干支"并写进盘面**：年(太岁)·**月(月建/月支)**·**日(日干支/日辰)**·时。其中**月支、日干支**是后面定旺衰、查旬空、起六神、定应期的命根，缺一不可。
> ⚠️ **若用户只给公历日期，先换算成干支再装卦，切勿凭记忆心算干支**（心算极易错，错则旬空/六神/月建/应期全错）。用 `scripts/ganzhi.py`（或 `paipan.py --date`）换算：月建按节气交接、年按立春、日按子时换日约定；起卦时刻落在节气交接前后或 23～24 点时，脚本会标"未确认"并给出两种可能（`00` 十一）。换算结果写进简明卦盘。
> **时区**：公历时间默认当作北京时间（+08:00）。用户说了所在地、时差，或明显不在东八区，就按起卦地的钟表时间加 `--tz`（如英国冬令 `--tz +00:00`、夏令 `--tz +01:00`）。脚本在没写 `--tz` 而节气交接离得近时会提示，这时问一句起卦地再算（`00` 0.2）。

## 四、配六亲（以"卦宫五行"为"我"）
逐爻拿"地支五行"与"卦宫五行"比对：
- **生我者＝父母**；**我生者＝子孙**；**克我者＝官鬼**；**我克者＝妻财**；**比和者＝兄弟**。
- 主卦、变卦六亲**都按主卦的卦宫五行**排。

## 六、查旬空（按起卦"日"干支）
- 法一（公式）：地支序(子1…亥12) − 天干序(甲1…癸10)，结果(不足+12)：2→子丑空·4→寅卯·6→辰巳·8→午未·10→申酉·12→戌亥。
- 法二（六甲旬）：甲子旬空戌亥·甲戌旬空申酉·甲申旬空午未·甲午旬空辰巳·甲辰旬空寅卯·甲寅旬空子丑。
- 卦中临到空亡地支的爻即"旬空"（真空假空之别见 `07`）。

## 七、排变卦
- 把动爻(`○`/`×`)的阴阳翻转(阳变阴、阴变阳)，静爻不动 → 得**变卦**。
- 变卦重新定上下卦 → 按第二节给**变出之爻**纳地支（只动爻位置有变爻；通常只关注动爻变出的那一两个变爻地支）。
- **变爻六亲仍按主卦卦宫五行**配。
- 变卦不必重排世应、六神（仍用主卦的）。

## 八、定伏神（仅当某六亲在主卦缺位时）
- 主卦六爻里缺哪个六亲（如无妻财），就到**本宫首卦(纯卦)**同爻位取那个六亲做"伏神"，伏于主卦对应爻(飞神)之下。
- 八宫首卦的地支即第二节"纯卦"装法（内卦纳支+外卦纳支顺接）。
- 飞伏生克、伏神能否出，见 `07`。

## 十一、截图核验（`paipan.py --verify`）的输入格式

排盘截图先由模型读成一个 JSON 文件，再交给 `python scripts/paipan.py --verify chart.json`。空模板用 `python scripts/paipan.py --verify-template` 打印。

```json
{
  "本卦": "泽水困", "变卦": "坎为水",
  "月建": "亥", "日辰": "丁亥", "旬空": "午未",
  "爻": [
    {"阴阳": "阴", "动": false, "地支": "寅", "六亲": "妻财", "六神": "朱雀", "世应": "世", "变支": null},
    {"阴阳": "阳", "动": false, "地支": "辰", "六亲": "父母", "六神": "勾陈", "世应": "",   "变支": null},
    {"阴阳": "阴", "动": false, "地支": "午", "六亲": "官鬼", "六神": "腾蛇", "世应": "",   "变支": null},
    {"阴阳": "阳", "动": true,  "地支": "亥", "六亲": "子孙", "六神": "白虎", "世应": "应", "变支": "申"},
    {"阴阳": "阳", "动": false, "地支": "酉", "六亲": "兄弟", "六神": "玄武", "世应": "",   "变支": null},
    {"阴阳": "阴", "动": false, "地支": "未", "六亲": "父母", "六神": "青龙", "世应": "",   "变支": null}
  ],
  "伏神": null
}
```

| 字段 | 写法 | 读不清时 |
|---|---|---|
| 本卦、变卦 | 卦名，全称或简称都认；静卦或截图上没有变卦写 `null` | `null`。卦名认不出（读错字）时脚本记一条输入类差异、按未确认处理，不中止 |
| 月建 | 地支或干支 | `null` |
| 日辰 | 干支 | `null` |
| 旬空 | 两个地支连写 | `null`（不比对） |
| 爻 | **恰好 6 项，自初爻到上爻**（截图多是自上而下排，写的时候倒过来） | 整爻看不清写 `null` |
| 爻.阴阳 | `"阳"` / `"阴"` | `null` |
| 爻.动 | `true` / `false` | `null`。六爻的阴阳、动静都齐，脚本以爻象定卦形；不齐就靠卦名 |
| 爻.地支、六亲、六神 | 截图上的字 | `null`（记入未确认，不补齐） |
| 爻.世应 | `"世"` / `"应"` / `""` | `null` |
| 爻.变支 | 动爻化出的地支；静爻 `null` | `null` |
| 伏神 | 截图标了才写：`[{"位": 3, "地支": "午", "六亲": "妻财"}]`；截图明确没有伏神写 `[]` | `null`（不比对） |

- 以下划线开头的键（如模板里的 `_说明`）会被忽略。
- 结果三种：`ok`（逐项一致）、`diff`（有差异）、`unconfirmed`（没有差异但有读不清的字段）。差异分两类：**输入类**（爻象、动爻、卦名、日期）要向用户确认那一处；**推算类**（纳支、六亲、世应、六神、旬空、伏神）以本包规则为准，在简明卦盘后注一句（`00` 1.1）。
- 格式写错（爻不是 6 项、某爻写成字符串、动静写成"是/否"）时脚本直接说明哪一项该怎么写，不会装出一个盘来。
