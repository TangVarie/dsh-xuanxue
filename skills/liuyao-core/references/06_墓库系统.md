# 06 · 墓库系统

> 四钥匙之一，且"**墓、空为先**"（优先于普通生克）。本文件以资料02《六爻墓库用法》（墓书）+ 曲炜 + 丁派为主。核心一句话：**旺爻入"库"是保护待用（多吉），衰爻入"墓"是死墓出不来（多凶）。**
> 当前默认：`11` R10（土不论入墓）、R11（墓库二分）、R12（合墓能否解墓未决）、R28（化墓只论本五行之墓）、R29（静爻逢动爻为墓未决）。盲派墓观与本文件对立，只随盲派整套用（`16` 十六）。

## 一、四墓库与长生定位
- **辰戌丑未为四墓库（四墓/四库）**：
  - **辰＝水（土）墓**（壬水墓辰、辛金亦墓辰）
  - **戌＝火墓**（丙火戊土墓戌、乙木亦墓戌）
  - **丑＝金墓**（庚金墓丑、丁火己土亦墓丑）
  - **未＝木墓**（甲木墓未、癸水亦墓未）
- 长生—帝旺—墓—绝（→[03] 长生十二宫）：金生巳旺酉**墓丑**绝寅；木生亥旺卯**墓未**绝申；火生寅旺午**墓戌**绝亥；水生申旺子**墓辰**绝巳。
- 应用三规定：① 以**日辰地支**为对应；② 动爻以**变出之爻**为对应；③ 伏爻以**本位飞爻**为对应。
- **土是否入墓（分歧）**：曲炜"土不论入墓、辰只是水库"；张德"土本身即万物之墓"；墓书/丁"万物皆临墓但非皆入墓"。**默认取"土不入墓"**（`11` R10），避免过断。

## 二、墓 vs 库（旺衰二分，全章脊柱）
> "入墓与入库是两个完全不同的概念！墓是埋物葬物之地，库是储物藏物之所。"
- **休囚之爻逢墓库 ＝ 入墓（死墓）**：如人死入坟，**出与不出均应凶**，无生克权。
- **旺相之爻入墓库 ＝ 入库**：如仓库储物待用，**既限制又保护**（入库期不受它爻克、自己也不克它），**多逢出库而应吉**。
- 一句话："旺相之爻入墓的'出墓'有用；休囚之爻入墓'出墓'也无用。"
- **临库 ≠ 入库**：财临库＝这个库里放的是钱（如银行存折，说"是什么库"）；入库＝说"是谁的库"（戌是午之库）。

## 三、入墓的几种方式
**总纲（层次规定）**：爻无论旺衰，遇"**高层次**"墓都入墓；**爻不入同层次爻之墓，只入高层次之墓**。入墓期暂失生克权（也不受克）。"墓、空为先。"
1. **入日、月墓**：动/变/静爻逢日或月为其墓，都入日月墓。
2. **入动爻墓**：静爻可入卦中动爻之墓（且墓爻须自身有生克权才能"收"）；不入静爻之墓；动爻不入动爻之墓（同层次）。
   - ⚠️ 这一条与第四节"墓爻自身发动则爻不入（库门开着藏不住）"相抵：墓爻既然是动爻，就总是"自身发动"。资料没有给调和规则，本包列为未决（`11` R29）：静爻逢动爻为其墓，不作入墓 / 入库的唯一依据，主判依赖它时给双分支。
3. **入变爻墓**：动爻可入**本位**变爻之墓；只入本位、不入旁爻变出之墓；静爻不入变爻之墓。
**具体动象**：
- **动而化墓**：爻动化出墓爻（即使非自墓），只要墓爻不逢日月合，即化入墓（卯化辰、午化戌、巳化戌）。
  - ⚠️ "即使非自墓"是墓书说法（卯木之墓在未，卯化辰化出的是水库）。本包默认只论化出本五行之墓，与 `05` 四、`20` 一、`paipan.py` 一致；结论依赖"化入非自墓之库"时标"墓书"、给默认下的备选（`11` R28）。
- **日/月见墓爻**：丑日月占，金爻入丑墓＝藏（火克不到金）→ 避凶；待金逢冲出墓。
- **随鬼入墓**：入墓于三传（年月日）或世动化墓；多见于测病/牢狱，多凶。
- **伏而入墓**：伏神伏于墓爻下（如申伏未下＝申入未墓），待逢冲合/值时出。
- **自身坐墓/自墓**：爻坐自己的墓地（由长生十二宫定）。

## 四、出墓 / 解墓 / 填实
- **解墓三法**：① 冲墓；② 合墓；③ 冲入墓之爻。
- **墓的开合**："**墓爻逢冲则开，逢合则闭**。"（戌为火墓，卯戌合则火墓闭、火不入；丑墓被未冲则开。）
- ⚠️ 上两条在"合"上相互矛盾：一说合墓能解墓，一说墓逢合则闭。资料未给调和规则，本包列为未决（`11` R12）：冲墓、冲入墓之爻作主要解墓依据；合墓只作备选应期，依据栏注明两说并存，给双分支。
- **不入墓的情形**：入墓之爻自身发动、或静而逢冲，则不入；墓爻自身发动则爻不入（库门开着藏不住；与第三节第 2 条相抵，见 `11` R29）；两墓爻动而相冲（辰戌、丑未动相冲）墓门开启，爻不入。
- **出墓时机**：入墓之爻**逢值（临日月/逢冲）即出墓**。
  - 化墓之爻：待冲墓爻或冲入墓之爻时出（卯化辰，待酉冲卯或戌冲辰；午化戌，待子冲午）。
  - 合住墓门者层层先后要分清（午化戌有卯合戌，待辰冲戌破卯戌合，午才入戌墓）。
- **填实**：墓爻逢空＝"墓里没东西"，逢冲则实/出空填实，墓里才有东西。
- **特殊规定（墓书）**：① **月冲墓爻"论开不论破"**；② **解日月墓只能冲爻，不能冲/合墓**（日月＝区域气场，冲不到）；但**日/月之墓入卦时，可以冲墓来解**。
- 曲炜否定"爻入日墓过月解、入月墓过月解"——**必待合墓冲墓冲爻才解**（特殊情况例外）。

## 五、四墓俱全与"四墓全则土动"（墓书独有体系）
- **四墓全成立**：① 主卦两墓+日月两墓；② 主卦两墓+动爻变出之墓；③ 日月一墓+主卦两墓（共三），待流年/月行另一墓凑齐；④ 用爻安静被带动化出墓爻凑齐。
- **断法（"四墓全则土动"）**：
  - 日月是墓爻且卦中两墓均动 → **有冲脱之象**（临财破财、临父文书不成）。
  - 卦中墓爻不动、日月是墓爻 → **会土局而土动、无冲脱**（临财生世进财、临孙财运好）。
  - 卦中墓不动、动爻化出墓 → 会土局无冲脱（临原用为吉、临忌为凶）。
  - 只一墓动且日月无墓冲它 → 不论冲脱；有墓冲它 → 论冲脱。
- **总判**："**忌神冲脱为吉，原、用两神冲脱为凶**。" 另：**丑未戌三刑**＝墓爻有伤，主官非、病伤、破财（→[04] 重刑派）。

## 六、各占类的墓断（用神入墓 vs 忌神入墓）
- **总原则**：用神/原神入死墓（休囚）→凶；忌神入死墓→反吉（被关收）；旺相入库待出库应吉。
- **占财**：财临库＝库里是钱；财旺入库，逢冲库/出库时得财、进财；财休囚入墓＝求不到。四墓全临财生世→进财；冲脱临财→破财。**财入兄库＝财到兄弟/朋友处去了**（例：应财子入兄辰库＝钱到对方手）。
- **占病**：用神（病人）入墓＝病重、被收（医院/坟墓象），凶，尤忌随鬼入墓；鬼入墓而用神出墓相对吉。"用神入进行时墓"常为死期判据之一。
- **占人（行人/失踪/找人）**：用神入墓＝人被收/呆某处/被带走；逢冲墓（暗动）则人被带出、行踪不定。
- **占物（失物）**：财/物入兄库＝被同辈拿走且入库；父母（单据/车）入月库＝难寻。
- **占婚恋**：用神入"鬼库"＝对方厚爱拒之/移情/隔阻（例：世兄入日丑〈亦官〉库＝女方拒现男友另有他意）。（原作者取象；"移情""另有他意"属断心与第三者类断语，断卦时只写"用神入库、被收住、待冲开"，第三者象过 `22` 九.2 门槛）
- **占官运/官司**：官入墓、随鬼入墓多凶（牢狱被收）；忌神（克世之兄）入墓反吉。
- **占工作分配**：世入日库"入库则安"＝安定下来，库支配的方位即定居方位（世酉入丑库，丑为东北→定居东北）。
- **占天气**：官鬼亥水化辰土"化入水库"＝雷电收势、雨将止（定现象收束时间）。

## 七、墓的"避凶/保护"吉用（易被忽略）
- 入墓期它爻克不到入墓之爻 → **避凶**（金入丑墓，火动也克不着；身爻旬空+入库避难，虚惊一场）。
- 旺神入库＝蓄势待发；"入库则安之"常作吉断。

## 八、墓库应期
- "**旺待墓、墓待破**"：旺爻应期常落在其入墓之时；入墓之爻的出墓应期在**冲墓之日 / 填实之日**。
- "**主卦中的墓爻不论动静，只论有墓不论入墓；入墓之爻逢值表示出墓。**"

## 九、关键口诀（逐字保留）
- "**爻逢墓库无论旺相休囚只有两种含义：有用无用、入墓入库之别。入库大都逢出库而应吉；入墓则出与不出均是应凶！**"
- "**墓爻逢冲则开，逢合则闭。**""**爻不入同层次爻的墓，只入它的高层次爻之墓。**""**墓、空为先。**"
- "**解墓：一冲墓、二合墓、三冲入墓之爻；入日月墓只可冲爻，不能冲日月解墓。**"
- "**四墓全则土动；忌神冲脱为吉，原、用两神冲脱为凶。**""**月冲墓爻，论墓开，不论破。**"
- "**入墓难克**（有条件）；只有被克之爻才算入墓，旺相之爻遇墓只能称临墓。"（邵/丁/丙）
- "绝处逢生者发，墓中值破者兴。"（《管公运限口诀》）
