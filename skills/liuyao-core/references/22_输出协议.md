# 22 · 输出协议（标准输出 · 简答 · 复盘 · 资料解释 · 记录）

> 本文件定义"怎么写出来"：各模式的输出顺序、详解何时展开、置信度等级、应期写法、断语边界、复盘记录字段。推演怎么做见 `00`，默认规则见 `11`，判词怎么翻成现实话见 `23`。
> 这里的每条规则只在本文件完整定义，其他文件引用节号（如"`22` 七"）。

---

## 一、四种模式各出什么

| 模式 | 默认输出 | 何时展开到详解（第三节） | 不出什么 |
|---|---|---|---|
| 完整解卦 | 第二节标准输出 | 用户要求详解；出现重大分歧；进入复盘 | 不默认出逐爻推演、编号判词、核对项表、记录表 |
| 单点追问 | 第四节简答 | 追问的答案改变了主判 | 不重复卦盘，不重出整套报告 |
| 对照与复盘 | 第五节复盘输出 | 本身就是展开形态 | 不重断未受影响的部分 |
| 资料解释 | 第六节解释输出 | — | 不起卦，不给置信度、应期和建议 |

**重大分歧**指以下任一：双镜冲突且第 8 步仲裁不下；切换门派后主判反转；前卦主判反向且原因不是"来意变了"；修订通道改动了主判。

---

## 二、标准输出（完整解卦的默认形态）

按下面五段的顺序写。每段第一句就是这段的结论，读者跳着看也能拿到答案。

### 1. 简明卦盘
- 一行写卦与时间：`<主卦>之<变卦>（<宫>宫<世位类型>，世<n>应<m>）｜<年>年<月>月<日>日<时>时｜月建<支>·日辰<干支>｜旬空<两支>`。公历由脚本换算的，在后面注"（公历 2026-10-12 14:30 换算）"；起卦地不在东八区的，把时区一并写上（如"公历 2026-10-12 14:30 +01:00 换算"）。
- 六爻用一张小表，自上而下：爻位｜地支五行｜六亲｜六神｜世应｜动变（○/×→化出何支何亲）｜伏神。
- 一行写来意登记：谁测·测什么·问法类型；前卦有记录的写"前卦：<主判一句>，本卦与之同向/反向（原因）"，没有就不写。
- 有未确认字段，直接在表里写"未确认"，不补齐；影响主判的，第一段就说明并停在这里提问（`00` 第 0 步）。

### 2. 一句话主判
- 先答所问，给出明确倾向（成 / 难成 / 先难后成 / 成而有反复……），同一行写置信度等级（第七节）。
- 问题本身分层的（如婚恋卦），主判就是分层那几句：每层一句、各带倾向，不再另加一句合并的总吉凶（`00` 十三.5）；置信度给一个等级。

### 3. 关键依据与反证
- **依据** 2～5 条，每条一句卦理加一句现实话：`<卦理：谁对谁、什么关系、在什么状态>——<这在你的事里指什么>`。术语保留，出现处当场用半句话化开。
- **双镜一行**：`主流镜：<一句主判>；张德镜：<一句主判>；<同向 / 冲突→按某理由取某版>`。开了其他镜的同样各写一句（标门派）。这一行同时就是记录里的"各镜独立结论"，不能省。
- **反证**：触发了、但指向与主判相反的技法照写（`20` 五），说明为什么没有推翻主判。
- **备选**：只保留会实质改变结论的分支，写成"主判 X；若 <触发条件> 则 Y"。不会改变结论的分支不写。
- 结论只在一派规则下成立时，在该条依据后括注派别（`11` 二"标源要求"）。

### 4. 应期及条件
- 首句写单位依据：`单位取<年/月/日/时>，因为所测之事为<…>`。
- 列最近的 1～3 个候选，按"先遇先应"排序，每个写：时间｜卦理依据（机械关系）｜条件分支。写法规则见第八节。
- 落在用户时限外的，直说"时限内不定"。

### 5. 对应建议
- 只在问题涉及求测者自己要做的现实决定时给（乙类 `involves_decision`，或问法为"该不该"）。只问结果、只问时间、纯解释的，不给。
- 每条建议说清它针对的是第 3 段哪条依据（解的是哪个张力），讲一句机制；给建议就至少给一条排除项（不要做什么，为什么）。翻译与建议的写法见 `23`。
- 行动卡只在建议多于三条或带时间表时附在最后，内容全部压缩自正文，零新增信息（`23` 五）。
- 涉及健康、诉讼、重大财务时，末尾一句提示咨询相应专业人士。

## 三、详解展开（用户要求、重大分歧、复盘时）

在标准输出之后追加，或替换第 3、4 段为下列完整形态：

```
【完整卦盘】含纳干、伏神、变爻六亲、四值、盘面高亮（日月并冲合之爻、旬空、暗动、特殊卦象）
【来意预判】Jev 状态（ok / skipped / error / mock）；ok 时写主用神前两名及概率、歧义项及处理；其余写"未启用"或失败原因
【取用】用神<…> 原神<…> 忌神<…>；对应点<…>；张德镜：世应/卦意<…>
  同一人多用神时标边界（婚恋：应＝对方处境与立场；财/官＝感情对象与感情本身；父母＝条件/承诺/安排），每次提到对方标是哪一爻
【旺衰与关键作用】世/用/原/忌逐爻旺衰；暗动、墓空伏、生克冲合关键链；有争议规则括注派别
【卦理判词】域中立，只写爻位、六亲、生克冲合墓空、卦名；不含现实名词、关系词、心理词；逐条编号；每条标"两派同判 / 仅 X 派成立"
【落地翻译】每句回指判词编号；分层不取平均；分歧给主判＋备选＋触发条件
【门派对照】开过的镜逐一列结论与仲裁理由
【核对项】每条三个出口：对得上 / 对不上 / 想不出来（＝还没取到样，给取样办法）；每条配读偏条款（什么情况才算读偏、收回哪一句判词）。给不出读偏条款的象不写核对项
【应期表】首行单位依据；四列：时间｜卦理依据｜翻译（你去核）｜门派与分支
【记录】第十节字段全表
```

"卦理判词—落地翻译"两层在标准输出里也照样遵守（先推出判词再翻译，翻译不新增、不削弱、不反转），只是不显示编号。

## 四、简答（单点追问）

- 直接回答所问，1～3 句；后面跟一行依据（哪一爻、什么关系）。
- 沿用已登记的卦盘、用神与主判，不重复卦盘，不重出建议，除非答案改变了该做什么。
- 追问的答案改变了主判，先说"这一点改变了原判"，再按 `00` 十修订通道写修订说明，之后才可展开。
- 只问应期：给候选与依据（第八节），不复述吉凶全文。
- **沿用原置信度**，不为追问另起等级。追问带出的新不确定（如已过了某个应期而不知实际情况），写成条件分支或请用户补一句；它若会改变主判，走修订通道。
- 追问涉及没有开过的镜或门派：说明默认怎么看（`11` R 编号），不在追问里临时开镜。

## 五、复盘输出

### 1. 对照他人解读
1. 逐条引对方原文再评，不概括；批评对方"漏了什么"之前先核对原文确实没有。
2. 先列对方说对的；再把分歧分三类：规则错误（查 `references` 能定的）、门派差异（`11` 有分歧的，标两派）、取舍差异（下注与不下注）。三类不混。
3. 对方指出本方的错，逐条答"认 / 不认 / 部分认"；硬错（冲合方向、墓库主客、装卦）优先认，结论要不要动单独说。
4. 只重发被推翻的条目（主判、应期、置信度、记录），其余原样不动。

### 2. 事后对答案
1. 先列事前登记的内容（第十节记录），不凭印象复述。
2. 用事前写好的"可观察结果"逐条比对实际，判定：应验 / 部分应验 / 未应 / 无法判定（记录里没定义可观察结果的，只能判"无法判定"）。
3. 各镜分别判定，便于比较不同方法。
4. 事后才想到的镜和解释，标"事后解释"，单列，不计入判定，也不回填到原判断里。

### 3. 纠错
按 `00` 十修订通道输出"修订说明"：原→新、触发原因、受影响结论清单、未受影响结论。

## 六、资料解释输出

- 直接解释规则、术语或门派差异；说明当前默认是什么（引 `11` R 编号）和出处。
- 不启动解卦流程；用户没给卦就不起卦，也不把规则套到用户之前的卦上，除非用户要求。
- 解释旧资料里的越界断语（第九节第 5 条）可以原样介绍，标"原作者观点"，并说明当前版本怎么处理。

## 七、置信度（固定三级）

**含义**：置信度表示**本次判断的依据清晰度和所用规则的稳定性**，不表示"这件事会发生的概率"。

**五项检查**（只从这五项取理由）：
1. 输入齐：卦形与月建、日辰都已确认，没有影响主判的未确认字段；
2. 来意清：问法类型与主用神在看盘前已定，歧义已追问，或两个候选用神各断一遍结论一致；
3. 用神清：用神不真空、不乱，两现已判清，伏神出现路径清楚；
4. 两象定一象：主判有两处独立卦象支持；
5. 规则稳：主判所依关键规则"两派同判"，或属 `11` 默认且该条无分歧。

**等级**：
| 等级 | 条件 |
|---|---|
| 高 | 五项全满足，且没有降档项 |
| 中 | 缺一到两项；或五项满足但有一个降档项 |
| 低 | 缺三项及以上；或降档后低于"中" |

**降档项**（每个降一级，最低到"低"）：结论只在一派规则下成立；双镜冲突、仲裁不下；同一问题的两条用神线方向相反（如婚恋卦世应线与财官线，`00` 十三.6）；用户未答、按假定读法推进且该读法影响主判（`00` 0.2）；有指向相反的甲类触发、且不属于 `20` 五列的四种可排除理由（只能靠第 8 步仲裁定主判、另给备选）；看盘后改用神（只能作备选）；前卦主判反向且原因只能写"前判有误"；节气或子时边界两套干支结论不一致。

降档只认上面列出的项目；不在清单里的不确定（如"主应期已过、实际情况未知"），写成条件分支或请用户补充，不另造降档理由。

**分开表达，不混进等级**：
- **Jev 分类概率**：来意判读的把握（如"主用神 官鬼 0.82"），只在详解的【来意预判】里写；它通过第 2 项间接影响等级，不直接换算。
- **双镜是否一致**：在第二节第 3 段"双镜一行"里写；一致不升级，冲突按降档项处理。
- **现实会不会发生**：本包不给概率。"六爻约八成准"是未经本包数据验证的来源说法（`11` 六），不作理由。

写法：`置信度：中（来意清、用神清、两象定一象；结论依赖"静爻受生"一条，仅曲炜派成立，降一档）`。

## 八、应期写法

1. **单位**：首句写单位与理由；远断年月、近断日时，不越级求精确（`09` 四.4）。
2. **依据栏只写机械关系**：`甲冲乙`、`甲合乙`、`乙入甲之墓/库`、`乙值/临`、`乙出空`，写清方向与主客（丑冲未不是丑冲丑；开丑库要未，冲申要寅）。取象（变卦世位、卦名、六神）不进依据栏；六害不进依据栏（R09）。
3. **中性符号给双分支**：冲、合、入墓、三合等，写"若……则……；若……则……"，不写"必"。对照他人解读时遇到"必散""必成"这类说法，直接引本条指出。
4. **合墓**只作备选应期，写"合墓（`06` 四两说并存）"（R12）。
5. **数量**：月级最多六个、日级最多八个是上限，不是目标；依据不够就少列。标准输出只列最近 1～3 个。每个节点一句依据、一句翻译、一句分支，不写跨节点的连续剧情。
6. **六爻皆静**：不给日级剧本，只给冲、值、合三类日子的清单。
7. **时限**：理论应期落在用户时限外，直说"时限内不定"，不硬凑（`09` 四.5）。
8. **应期是结果日**：呈递、送礼、做局选定的行动日都只是中间节点，不当应期（`19` 六）。
9. 天数、窗口写出来源（先遇先应排出的区间）。

## 九、断语边界（当前版本允许写什么）

1. **卦只断事，不断心**。六爻能证的是某条线稳不稳、成不成、何时动、谁在压谁；不能证动机、人格、心理能力、真心与否。旬空＝虚而有气、有心无力，不是虚情假意；假空出空只说明"能兑现一段"，不说明"诚意"。断语不用"不是真心 / 假意 / 表态而已 / 没有能力 / 依赖型 / 内在支撑 / 走不出来 / 对方不实 / 虚诈"这类词，一律改回爻位状态（空、囚、入墓、被合、受克、待旺）。
2. **第三者象门槛**。"别人介入 / 另有其人 / 被人勾着"这类取象（财两现、官两现、财与兄合、临玄武勾陈、夹爻之鬼等）要同时满足四条才能写进主判：①两处独立卦象；②来意没有否定；③断前先问"对方身边有没有别的人或别的事"，不先断后问；④写成备选并配读偏条款。不满足就默认取"别的事、压力、处境"，不取"别的人"。同一个人在复筮里连续被读出第三者象，第二次起降为备选。
3. **健康**：可以写病势轻重的倾向、好转或加重的时点候选，并提示就医；不写病名诊断（如癌症）、不写死期、寿数。四土俱全俱动等警示信号只说"病象需重视、建议尽快检查"（R09）。
4. **法律与财务**：可以断"这件事成不成、何时有变"作参考，注明不构成专业意见；不推荐具体投资标的、不给仓位，股票代码法不用（`15` 二.6）。
5. **旧资料里的越界断语**：人格、真心、第三者、死期、"必分""必死"等判断，保留为原作者观点。当前版本只允许三种引用方式：①讲解资料时原样介绍并标"原作者观点"；②断卦时不把这类断语直接写成对求测者或当事人的结论，只转写成爻位状态（例：资料写"男测兄弟持世＝逢场作戏不想结婚"，断卦时只写"世持兄弟，兄弟克妻财：感情这条线在世这一方受分夺，财爻受制"，不写对方或求测者的心思）；③这类卦例不作模仿样本（`13` 适用标记）。
6. **危机**：遇明显心理危机或自伤倾向，先表达关心、引导寻求现实支持，不继续断卦。

## 十、复盘记录（字段的唯一定义）

记录用于事后对答案、比较方法、淘汰技法。字段：

| 字段 | 内容 | 何时写 |
|---|---|---|
| 记录编号 | 日期 + 序号 | 登记时 |
| 起卦时间 | 公历（含时区；时区是默认假定还是用户说明的）与四值干支；干支来源（用户给 / 脚本换算） | 登记时 |
| 起卦方式 | 铜钱 / 卦名动爻 / 截图 / 数字时间起卦（R24） | 登记时 |
| 问题与时限 | 来意摘要（不含卦盘）；问法类型；用户给的时限 | 登记时 |
| 输入版本 | 卦形来源、干支来源、修订次数（v1、v2…） | 每次修订更新 |
| 主用神 | 主用神 + 备选；看盘后新增的只能进备选 | 看盘前 |
| 规则版本与门派 | `r6.1`（登记时的当前版本；旧记录保留原版本号）；默认 / 盲派 / 其他（求测者事前指明） | 看盘前 |
| 各镜独立结论 | 主流镜、张德镜各一句主判；开过的其他镜（盲派、象法、五运六气、从象）各一句并标门派 | 第 8 步 |
| 最终主判 | 一句话；分层的按层各一句 | 第 8 步 |
| 备选与触发条件 | 只记会实质改变结论的 | 第 8 步 |
| 关键反证 | 触发但指向相反的技法 | 第 8 步 |
| 应期候选 | 最多三个，各带机械依据 | 第 9 步 |
| 置信度 | 等级 + 理由项（第七节） | 第 8 步 |
| 可观察结果 | 事前写：什么算应验、什么算未应；相近结果分开写（例："收到款项"与"对方口头答应付款"是两条）；时间窗口起止日期 | 登记时，最晚第 9 步后 |
| 修订记录 | 每次：时间、改了什么、触发原因、受影响结论 | 修订时追加，不覆盖原登记 |
| 事后结果 | 日期、实际发生了什么；按可观察结果判定（应验 / 部分应验 / 未应 / 无法判定）；各镜分别判定；事后解释单列 | 复盘时 |

纪律：
- **可观察结果先定义，再谈应验**。没有事前定义的，事后只能判"无法判定"。
- **时间窗口事前固定**，事后不放宽。
- **事后新增的解释不回填**到原判断，单列为"事后解释"。
- **修订不覆盖**：原登记保留，修订作为新条目追加；复盘时以结果发生前最后一次登记的主判为准，并注明原判。
- **跨会话复盘只依赖实际可读取的记录**（用户保存的文件、记忆里的条目、本会话可见内容），不假设模型记得以前的卦。
- **按需展示或导出**：标准输出不显示记录表；第二节第 1～4 段已含主判、双镜、应期、置信度，可据此补全记录。用户要存档、要复盘或要求详解时出全表；写文件用 `scripts/record.py`（`new` 出模板、`validate` 校验、`show` 导出一行或全表）。

## 十一、写法与输出自检

**写法**：先结论后依据；术语保留，出现处当场化开，落到能核对的具体表现；每段第一句是结论；不写心理咨询式安慰；不用"必""注定"；不造词，用资料里的术语或平常话；讲述口吻，少用反问。

**出口自检**（成文后逐项过）：
- [ ] 模式判对了吗？单点追问没有重出整套报告？资料解释没有强行起卦？
- [ ] 标准输出五段顺序对吗？每段第一句是结论吗？
- [ ] 未确认字段写成"未确认"、没有补齐？
- [ ] 双镜一行写了吗（各镜一句）？反证写了吗？备选只留会改结论的吗？
- [ ] 置信度是三级之一？理由只来自五项检查和降档项？Jev 概率、双镜一致性没混进等级？
- [ ] 应期：单位依据、机械关系、双分支、时限、数量没为凑数而填？
- [ ] 建议：该给才给？每条锚回依据？有排除项？纯解释追问没附行动卡？
- [ ] 断语边界：没有断心词？第三者象过了门槛？没有病名、死期、选股？
- [ ] 结论只在一派下成立的，标派别并降档了？
