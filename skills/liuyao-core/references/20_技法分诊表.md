# 20 · 技法分诊表（触发条件 · 检查顺序 · 反证记录）

> **为什么有这张表**：资料里各派技法杂糅，"这一卦用哪些技法"不能凭感觉挑——看完盘再决定用哪条规则，什么结论都凑得出来。本表把每条技法按"用不用由什么决定"分四类，并规定检查顺序和反证怎么记。
> 默认门派与开镜条件不在这里定义，见 `11` 第二、三节；本表只引用 R 编号。

---

## 〇、四类一览

| 类 | 用不用由什么决定 | 谁来做 | 例 |
|---|---|---|---|
| **甲 · 盘面触发** | 卦盘事实。门派默认定了之后，没有自由度 | `scripts/paipan.py` 算出触发清单，模型逐条判后果 | 旬空、月破日破、暗动、化进退、入墓、伏神、反吟伏吟 |
| **乙 · 来意判断** | 求测者说的话。闭集，**不看卦盘** | 看盘**之前**定（Jev 预判或模型逐题判），模型复核 | 问事类别、问法类型、动机、谁的事、主用神、应期单位 |
| **乙′ · 看盘的语义判断** | 卦盘 + 来意 | 模型（不交给 Jev） | 用神两现是否各司其职、哪个"病"是主要矛盾 |
| **丙 · 门派默认** | 同一问题各派互斥 | **事先定死**，见 `11` 二（R01–R29）；只能靠复盘证据改默认 | 旺衰法、土入墓、旬空反断、盲派切换 |
| **丁 · 取象成文** | 只影响"怎么说"，不影响吉凶 | 模型 | 六神象意、爻位象、卦名象、`17` 取象法、`23` 翻译 |

**三条纪律**

1. **乙类在看盘之前定。** 主用神（含备选）先按来意登记，再看盘。看完盘想换用神，只能写成备选并降一档，不替换主判——防"看盘挑用神"。用户侧带来新信息或发现排盘错误，走 `00` 十修订通道，不受此限。
2. **丙类不逐卦换。** 开镜、切门派只认 `11` 三的事前条件。
3. **甲类没触发的技法不写进断语。** 触发了、但指向和主判相反的，照写，记为反证（第五节）。

**脚本算到哪里**：`paipan.py` 的触发清单只算三类关系——各爻与月建、日辰；动爻与本位变爻；主卦六爻彼此之间的冲、两动相合、静爻逢动爻为墓。下面这些它不算，要模型自己过：变爻越位作用它爻（`03` 五）、暗动之爻再去冲合它爻、伏神与飞神之外的关系、从象与一气专旺、应期。清单里没有的不等于盘上没有。

**检查顺序**：第 1 步各项 → 第 3 步旺衰 → 第 4 步冲合 → 第 5 步动变 → 第 6 步四钥匙 → 第 9 步应期。同一步内，旬空、月破、日冲先于其余（"墓空为先"、"一看空二看冲"）。

## 二、乙类：来意判断（看盘之前定；Jev 预判题）

题目原文、选项定义、歧义阈值在 `21_Jev判断题.yaml`（题库 jq-v0.2）。这里只列用途。

| 题 | 问什么 | 选项 | 喂给哪一步 | 标了歧义怎么办 |
|---|---|---|---|---|
| `matter_category` | 问的是哪类事 | 求财、婚恋、事业、疾病、官司、失物、行人、出行、学业、天气、家宅、流年、比赛选举、其他 | 选 `10` 的对应节 | 追问"具体测什么事" |
| `wenfa_type` | 问法类型 | 能否成、走向好坏、该不该、只问时间、说不清 | 第 0 步登记；取用与喜忌；是否给建议 | 追问是问能不能成，还是成了之后怎样 |
| `single_matter` | 是否只问一件事 | 是 / 否 | 一事一断（R15） | 否 → 请求测者拆成几卦 |
| `motive` | 动机 | 想成、怕生变、已发生问结果、只问时间、说不清 | 取用与喜忌（`02` 用神转换、`19` 真念） | 追问动机 |
| `asker_role` | 谁的事 | 本人、替他人问、我和他人之间、说不清 | 世爻代谁（R02） | 追问是谁的事 |
| `yongshen_main` | 主用神 | 妻财、官鬼、父母、子孙、兄弟、世爻、应爻、生世之爻、说不清 | 第 2 步主流取用 | 追问来意；或两个用神各断一遍，一致才坐实 |
| `intent_clear` | 来意是否足以取用 | 是 / 否 | 第 0 步 | 否 → 追问 |
| `timescale` | 问的时间范围 | 当天内、一月内、一年内、一年以上、没说 | 第 9 步应期单位 | 有现实时限时追问；没有就按事体常理定 |
| `health_matter` | 是否涉及身体健康 | 是 / 否 | R03 五运六气镜、R09 四土警示的资格 | 不追问，按"否" |
| `involves_decision` | 是否涉及当事人要做的现实决定 | 是 / 否 | 输出层：是否给建议（`22` 二.5） | 按"是" |

**Jev 不可用时的人工判法**：按上表逐题从来意摘要判断；判不出的题按"标了歧义怎么办"一列处理。人工判断与 Jev 结果不一致时，以追问后求测者的说法为准。

**乙′（要看盘，不交给 Jev）**
- 用神两现是"各司其职"还是要取舍（`02` 三、R16）；
- 众多"病"里哪个是主要矛盾、应期取哪一爻（`09`）；
- 求测者不肯说来意时从卦断来意（`10` 十二）——本 skill 默认先问清，不练测来意。

## 五、反证记录

触发了、但指向与主判相反的甲类技法，是"反证"。反证不删，照下面记：

| 记什么 | 写法 |
|---|---|
| 哪条技法触发 | 例："应爻旬空（假空）" |
| 它指向什么 | 例："对方这条线暂未落实，指向迟滞" |
| 为什么没推翻主判 | 只能是以下之一：被更高层次的作用压过（写出哪一个）；只影响应期不影响成败；属取象不定吉凶；属少数派规则（写派别） |
| 会不会在某条件下翻转 | 有就写成备选的触发条件 |

标准输出里反证写进"关键依据与反证"段（`22` 二.3）；记录里进"关键反证"字段（`22` 十）。

## 六、复盘积累能比什么

记录字段见 `22` 十。攒够以后能比：
- 主流镜和张德镜分歧时，谁对得多（所以记录里两镜要各记一句）；
- 常触发的甲类技法（旬空、暗动、月破、化进退、入墓入库）指向与结果的一致率；
- 标了歧义、追问过的卦，和没标的卦，应验率差多少——这回答"问清来意值多少"；
- 婚恋卦第三者象的命中率。

现实一点：一年几十卦，只够比常触发的东西；反吟伏吟这类少见技法很难攒够样本。改 `11` 默认要有这类记录作证据，不凭单卦印象。
