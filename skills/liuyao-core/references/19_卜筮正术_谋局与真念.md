# 19 · 卜筮正术要义（谋局 · 真念 · 机变）

> 来源：《卜筮正术》（文始道门秘传卜筮法，函授课 001–049，扫描件 OCR）。该课**逐讲《增删卜易》**——其基础（用神旺衰空破墓、生克冲合）与本库高度重复（增删本就是库内纳甲主线之源），**不重复收录**。
> 本文件只提炼它**增删基础之外的独特增量**：谋略层的"相卦做局"、来意的"真念分型"、机变反宿命的卦术观、应期概念的澄清，以及对野鹤老人个别理论的修正。
> 据已 OCR 的 L003/L004/L025/L048 等代表课提炼（采"精提独特内容"策略，未逐页全收）。OCR 原件未随包分发。
> 本包怎么用这里的做局与再占：见 `11` R25（择日可作时机选项；择人随行、化贵入卦默认不用；再占只在情况实质变化后作新卦）。

## 一、起卦工具（补 `01` 起卦）
- **太极丸**：三颗、每颗六面，刻"二"与"三"两数且两两相对，摇之代蓍草成卦（简化大衍筮法的代法）。
- 简化大衍：49 根筹策、阴阳签随意两分→挂一→分签；"问卜人亲自分"代表其意念（"类似天子下命令"）。

## 二、断卦三步（本课招牌流程）
1. **探真念、定用神**——先问清求测者真实心念，据真念取用（见第三节）。
2. **断吉凶**——按纳甲生克定成败。
3. **言趋避**——给应期 + 做局调整（见第四节）。
> 与引擎 `00` 的"先问来意动机 → 取用 → … → 趋避"完全同构，可作其细化模板。

## 三、真念分型（来意取用的细化，实用增量）
**同一个问法，背后真念可有多种，取用与侧重随之不同。** 例（占"选期"=任命书何时下达）列四种真念：
1. 只想要个确定日期（不在乎成败）→ 只看异兆给应期，不分析得官与否；
2. 明问选期、实问能否得官 → 侧重能否得官，应期次要；
3. 位子肯定有、只问能否更好 → 比较官位高下；
4. 已许诺、怕生变 → 可能演变成**忧患卦**；此时**子孙持世未必是失官，可能是"包你满意"**——须具体分析。
- 心法："一个爻象可有多种解释，须结合卦主真念 + 现实情况综合定。"（与曲炜"用神转换"、张德"来意定用忌"同向、更细。）

## 四、相卦做局（谋局法，本课最大增量）★
**趋吉避凶不是认命，而是主动布局把"吉兆"落成现实、把"凶"调整掉。**
- **五层布局**："天地人神鬼"——天=日月(日令月令)、地=主卦变卦、人=世爻用神、神鬼各两重，综合应用。
- **依兆用象**：用卦中已有的关键字（合局的"扣结"字，如寅午戌局之**寅木**）来择日/择人做局——找到并应用它即"依兆用象"。细到所临天干/六神不同则择日不同（天干甲寅则选甲寅日最好）。
- **化贵入卦**：卦中各处都找不到关键字时，**从外部引入**代入成局——如选一个**年命属寅（虎）的人**随同前往，以补成合局。
- **用天时（择日做局）**：择日合成有利之局（如把官位午火合成寅午戌官鬼局，把世爻也绑进局内）；若时限不允许等关键日，可选合局里其他动/变出之符号（戌/子/午/申）择日。
- **反宿命·机变论**："卦吉只说明目前形势有利、非注定成功；卦凶只说明当前时空不利、**可换个时空再占**。" 成败在于把握过程中的"**机变**"，非命中注定（举刘邦项羽、袁绍谋士为喻）。**"卜术的价值在调整、不在教人认命。"**（本包处理：同一情况下反复摇不算新卦；现实情况实质变化后再占，按 `00` 0.5 登记前卦）
> 接入：择日合局可作 `23` 三.5 时机建议的一个选项；择人随行、化贵入卦默认不用，求测者明确要求做局时介绍并标"卜筮正术"（`11` R25）。

## 五、对《增删卜易》的修正
- **野鹤"两爻动一爻不动亦成三合局"——在吉凶判断层面是错的**：能成三合局者，三字须都动/暗动/变出；"虚一待用"（借月建补一字）**只能用于应期层面，不能当三合局判吉凶**。
- 卦兆论：野鹤后文亦有"卦凶可换时空再占"之意，本课据此发挥成"做局"体系。

## 六、应期概念澄清（纠常见错，重要）
- **应期 = 事情应验 / 出结果之日**（如求官＝任命书到手之日）。
- **呈递日 / 送礼日 / 测卦日 都只是"中间行动节点"，不是应期**——纠正"很多大师把行动日（如做局选定的寅日）当应期"的普遍错误。"一件事由无数中间小活动促成，那些行动点都不是应期。"
