# 02 · 取用神与对应点

> "取用决定全局对错。" 本文件统合三种取用范式：① 主流"按事取六亲"；② 曲炜"找对应点/用神转换"；③ 张德"废用神/顺卦意"。引擎要求**多角度取用、孤证不立**（`00` 第 2 步）。
> 当前默认：主流取用 + 曲炜对应点为骨，张德世应镜并跑（`11` R01）；代测、"我"是谁见 R02；用神两现见 R16。主用神在看盘前登记（`00` 0.7）。

## 一、主流：按所测之事取六亲为用神
- 求财→**妻财**；求官/官司/疾病(他人)→**官鬼**；文书/学业/房子/车/合同/父母长辈→**父母**；子嗣/医药/晴天/六畜/平安解忧→**子孙**；手足/竞争对手/劫财/合伙→**兄弟**。
- **以六亲取用，不以属相/五行取用**（曲炜铁律）：测雨取父母**不取**水爻；测六畜取子孙不取地支属相；测火/暖不取火爻。
- **配齐用神团队**：原神（生用神者＝事情的根/动力）、忌神（克用神者＝病）、仇神（生忌克原者）。**"用神是表面，原神才是根本；水要看源，木要寻根"**（邵伟中）——久远之事（身命、家宅、功名、坟墓）尤重原神是否被伤。

### 常见事项取用速查
| 测项 | 用神 | 要点 |
|---|---|---|
| 自测病/自测吉凶/自测财运/调动 | **世爻**（财占兼看财） | 克世为病、生世为医 |
| 测他人病/官司/凶祸 | **官鬼**（病/官方/凶），子孙为药 | 用神入墓随鬼入墓多凶 |
| 测父母病 | 父母为用、财爻为病、官鬼为医生 | 丁派四分法之一 |
| 求名/升学 | 父母(文星)+官鬼 | 艺术类偏重子孙(曲炜) |
| 婚姻 | 男看妻财、女看官鬼，兼世应 | 未婚重世应，已婚重财官 |
| 天气 | 子孙财=晴、父母=雨、官鬼=雷电雾、兄弟=风云 | →[10] |
| 失物/盗 | 财(物)，测盗取官鬼、抢劫取兄弟 | 用神不上卦找伏神 |
| 行人归期 | 代表该人之六亲，五爻为道路、兄弟为阻 | →[10] |

## 二、曲炜：取用 = 找对应点（多角度，最推荐并用）
- **核心定理**："取用神实质就是找对应点……找出所有与求测人事物有关的爻，一一对应所测之事的方方面面。对应点越准越多，断得越全。"
- **示例（开饭店）**：世=求测者、应=店面/求财环境、财=财利、子孙=财源/顾客、父母=房屋/房租/费用、官鬼=各种收费。
- **用神转换原理（关键）**：同一物，因**求测角度不同**，用神随之变：
  - 雨伞——经销商测营销取**子孙**(财源)；店里伞丢失取**妻财**(财物)；顾客测伞质量取**父母**(防雨功能)。
  - 牛——买牛测优劣取子孙；卖牛测何时卖取财；丢牛取子孙看生死、取财看能否找回。
  - → **所以第〇步必须问清动机**：同一"找工作"，为糊口取"生世之爻"、为名利前途取"官爻"（曲炜反对"父母=工作"教条）。
- **真假六亲（测有血缘的亲属/生死大关时才用）**：本宫内卦出现者为内亲之"真"、外卦出现者为外亲之"真"，否则取内卦伏神、再否则以世为基点按实际关系推。**真六亲受克=人有灾；假六亲受克=事/能力有问题**（如破财，而非妻有难）。

## 三、用神两现 / 用神伏藏
### 用神两现
- 别急着取一舍一（刘昌明/刘虹言"**各司其职**"）：先判两爻是否代表**不同的人/不同的面**（如正缘 vs 第三者；现在的官 vs 想求的官——内卦官=现在、外卦官=欲求）。
- **定应期时**：专取"**有病那一爻**"（一空一不空，看旺衰定有无，以空爻定应期）。
- **古法取舍**（备用）：舍闲爻取持世、舍无权取临月日、舍安静取发动、舍不空取旬空。

### 用神不上卦（伏神）
- **伏神出现（得用）只有四法**（曲炜）：**值、临、冲伏、冲飞**。合伏神/合飞神都出不来。
- **飞伏生克**：飞神生伏神=飞泄气、利伏神（吉）；伏生飞=伏神泄气（不利）。
- 伏神照论旺衰、月破日破、入墓（入飞神/月日之墓）。旺相有气之伏神在出空、冲伏/冲飞时有用；衰伏被飞克则凶。
- 口诀："**伏无提挈终徒尔，飞不冲开亦枉然**""**冲飞露伏**"。
- **卦中无某六亲**=信息：无官鬼可揭示离婚/无夫；无财非测婚必无妻（须兼看应、伏财）。

## 四、张德：废用神 / 顺从卦意（第二镜，并跑校验）
- **立场**："单凭取用神断卦，是只见树木不见树林、瞎子摸象。顺从卦意才是真正客观的取用神。"
- **替代操作**：抓**世应重心**——持世之爻=第一基本点（我在此事所持态度/方法），临应之爻=第二基本点（我面对的对方/目的），动变=动态明显信息。
- **喜忌怎么定**：不靠格局，依**六亲性质 + 测项客观喜好厌恶**（想象现实里这事希望什么、厌恶什么）。
- **克的现实化**（极实用）：克=找、追求、控制、把握、得到。→ "占财财爻克世必得；占病子孙克世即愈；官鬼克世=麻烦找上门；父母克世=条框约束、自由受限；兄弟克世=口舌/讨钱找上门。"
- **代测**：测他人事≈他人亲自摇得，**世=他人**；反对把卦中某六亲硬当成被测之人（代测晚辈病把子孙当晚辈、代测父事以父母爻当父亲——"往往歪打正着、实则大错"）。（张德观点；本包默认按关系取六亲，张德层作对照，`11` R02）

## 五、袁炜明：先天/后天六亲、代占以世代六亲（少数派镜头）
- **代占**：来者为六亲预测，**以世爻代表所占之六亲**（受全息论启发）；占六亲生死另看天干六亲。
- **先天/后天六亲**：先天=按卦宫五行排（表面/命中有的）；后天=以世爻为中心重排（真实本质）。例：财持世+兄为忌，用后天看"兄=世的官鬼=麻烦伤害"。
- **天干三遁定六亲**："天干三遁定六亲；六亲吉凶地支判"——解决一卦多断时一个偏财既是情人又是父亲又是外财的信息重复（惜遁法原书未公开）。
- ⚠️ 这些是袁氏自洽体系内的规定，**整套用或不用，不要单条摘出套别派盘**。
