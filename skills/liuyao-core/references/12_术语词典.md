# 12 · 术语词典

> 按主题分组的速查表。详解见对应专题文件 `→[0X]`。
> 编号提醒：→[0X] 指 `references/0X` 文件；"资料01–06""墓书"指原始资料（名册见 `11` 一），二者不是一回事；R01–R26 指 `11` 第二节默认规则。

## 一、排盘 / 结构
- **纳甲（纳支）**：把天干地支配到六爻上的规则（京房法）。天干用于查旬空、排六神；断卦重在地支。→[01]
- **卦宫 / 本宫**：八宫之一，决定卦的五行（乾兑金·震巽木·坎水·离火·艮坤土）。六亲以卦宫五行为"我"排定。→[01]
- **六亲**：父母·兄弟·官鬼·妻财·子孙。生我父母、我生子孙、克我官鬼、我克妻财、比和兄弟。→[01]
- **世 / 应**：世＝求测者/我方，应＝对方/环境/目的地。→[01]
- **持世**：某六亲落在世爻位置。张德辨："持世＝世持（态度/方法），持世之爻≠世爻"。→[02]/[11]
- **间爻**：世应之间两爻（三四爻），主中间人/媒介/证人/选民。
- **飞神 / 伏神**：用神不上卦时藏于某爻（飞神）之下者为伏神。→[07]
- **变爻 / 变卦**：动爻变出之爻/卦；变卦为事之终、结局。→[05]
- **互卦**：取二三四、三四五爻组成，主事情中间过程。
- **游魂 / 归魂**：八宫第七、第八卦；归魂主"想改难改终归原状"，游魂主"变/动"。→[01]
- **卦身（月卦身/命卦身）**：辅断之"事之主"，各派用法不一（曲少用、张德否定）。→[01]

## 二、时间 / 四建
- **太岁 / 月建（月令）/ 日建（日辰）/ 时辰**：年月日时四个干支。日建＝六爻主宰（始终有权），月建＝万卦提纲（只司月内）。→[01]/[03]
- **旬空（空亡）**：本旬中无天干配的两地支。真空（休囚）vs 假空（有气）。→[07]
- **应期**：事情应验的时间点；"找病治病"。→[09]
- **进行时**：起卦后时间的流转（流年/流月/流日）；定应期用，**不用来定吉凶**。→[00]/[03]

## 三、旺衰 / 状态
- **旺相休囚死**：爻的能量等级（以月令为主）。→[03]
- **长生十二宫**：五行寄生十二宫（长生·沐浴·冠带·临官·帝旺·衰·病·死·墓·绝·胎·养）。→[03]
- **月破 / 日破**：被月/日冲的（休囚）爻，无用。→[03]/[04]
- **值 / 临**（曲炜）：值＝与日月同支（寅日见寅爻）；临＝与日月同五行而不同支（寅日见卯爻）。古书和邵伟中行文里的"临日建""临月建"多指同支，读原文时按上下文分辨。→[03] 六
- **暗动**：旺相静爻被日辰冲而获生克权。→[03]
- **临界态**（曲炜）：介于暗动与日破之间的中间状态。→[03]
- **同功同权**：日月对某爻一生一克时，可抛开日月只看卦中旺衰。→[03]
- **生克权 / 力量≠权力**（曲炜）：力量＝力度（旺衰定）；权力＝能否行使生克（层次/状态定）。→[03]
- **爻的四个层次**（曲炜）：日月＞变爻＞动爻/暗动＞静爻/伏爻。→[03]
- **原象 / 原象不易性**（张德）：起卦那一刻的盘面（四值+卦+六神）；旺衰不会因进行时旺月翻盘。→[03]
- **从象 / 一气专旺**（墓书）：弱极顺从/旺极专旺的反常格局。→[03]
- **五运六气**（袁炜明）：以中运/司天/在泉断世爻旺衰的医易体系。→[03]
- **助旺 vs 生旺**（张德）：爆发无后劲 vs 渐强可持续。→[03]

## 四、作用关系
- **生 / 克 / 泄 / 耗**：相生、相克、我生者泄我、我克者耗我。
- **冲（六冲）**：相对地支相冲；四态＝冲起(暗动)/冲破(日月破)/冲实/冲散。→[04]
- **合（六合 / 三合）**：合化（变性增减力）vs 合绊（失生克权）。→[04]
- **刑 / 害**：多数派以生克论；丑未戌三刑、四土俱全为专题加权信号。→[04]
- **十六字诀**："先生后克，先动后静，无生则克，无克则生。"→[04]
- **通关 / 贪生忘克**：连续相生使两端不相克。→[04]
- **回头生 / 回头克**：变爻反过来生/克本位动爻。→[05]
- **化进神 / 化退神**：同五行前进（增力）/后退（减力）。→[05]
- **反吟 / 伏吟**：爻变冲克（反复动荡）/爻变同支（呻吟不顺）。→[05]
- **独发 / 独静**：卦中唯一动爻/唯一静爻。→[05]
- **暗动**：见上"旺衰"。
- **虚化**（张德）：明动导致它爻被动变化。→[05]

## 五、墓 / 库
- **四墓库（辰戌丑未）**：辰水库·戌火库·丑金库·未木库。→[06]
- **入墓 vs 入库**：衰爻入墓（死墓，凶）vs 旺爻入库（保护待用，吉）。→[06]
- **临库 vs 入库**：临库＝什么库（库里放什么）；入库＝谁的库。→[06]
- **随鬼入墓**：用神/世随官鬼入墓（多凶）。→[06]
- **冲墓 / 合墓 / 填实**：解墓三法 + 墓空填实。→[06]
- **四墓全**："四墓全则土动"，忌神冲脱吉、原用冲脱凶。→[06]

## 六、取用
- **用神 / 原神 / 忌神 / 仇神**：所测之六亲/生用神者/克用神者/生忌克原者。→[02]
- **对应点**（曲炜）：与所测事相关的所有爻；取用＝找对应点。→[02]
- **用神转换**（曲炜）：同物因求测角度不同，用神变化。→[02]
- **用神两现 / 各司其职**：两个同神代表不同人/面。→[02]
- **真假六亲**：本宫内外卦定真假；真＝人身、假＝事/能力。→[02]/[07]
- **先天/后天六亲**（袁）：卦宫排（表面）vs 以世重排（本质）。→[02]
- **废用神 / 顺卦意**（张德）：不锁用神，抓世应卦意。→[02]/[11]

## 七、六神 / 神煞
- **六神（六兽）**：青龙·朱雀·勾陈·腾蛇·白虎·玄武。只取象、不定吉凶。→[08]
- **桃花（咸池）/ 沐浴煞**：感情、作风。→[08]
- **驿马 / 马星**：车、走动、变动。→[08]
- **真假神煞**：配旺衰辨真假（休囚旬空者不应）。→[08]

## 八、方法论
- **内因 / 外因**（曲炜）：主变卦各爻＝内因（定吉凶）；年月日时＝外因（定应期/引发）。→[00]/[03]
- **信息定向锁定**（曲炜）："测什么照什么"；一卦可多断、不可兼断。→[00]/[11]
- **两象定一象**（曲炜）：两处信息互证才坐实结论。→[00]
- **一事一断 vs 一卦多断**：单项事一事一断、宽主题可多角度（`11` R15）。
- **断应期＝治病**（曲/黎）：病处寻药。→[09]
- **测此应彼**（刘虹言）：卦显示的是关联的另一件事。→[11]
- **太极裂变**（王虎应）：以爻位为太极点演新卦。→[11]

## 九、流程与记录（v6.x 用语）
- **四种模式**：完整解卦 / 单点追问 / 对照与复盘 / 资料解释。→`00` 〇、`22` 一
- **问法类型**：能否成 / 走向好坏 / 该不该 / 只问时间；取用与喜忌随之不同。→`00` 0.3
- **来意摘要**：交给 Jev 的来意文字，只含谁测、测什么、关心哪一面、动机、时限，不含任何卦盘信息。→`00` 0.6
- **事前登记**：看盘之前定下问法类型、主用神（含备选）、应期单位、门派。→`00` 0.7
- **修订通道**：用户纠正问题、补关键事实或发现排盘错误时，重定主用神与主判并记录原因与受影响结论。→`00` 十
- **降级**：缺日期、边界未确认、截图不清、Jev 失败时，做能做的部分并标出暂不能成立的判断。→`00` 十一
- **未确认字段**：读不清或有两种可能的输入字段；照写"未确认"，不补齐。→`00` 1.1
- **规则版本 r6.1 / R 编号**：`11` 第二节默认规则表的版本与条目号；记录里写明所用版本。
- **标源 / 两派同判**：结论依赖有分歧的规则时括注派别；两派规则下都成立写"两派同判"。→`11` 二
- **反证**：触发了但指向与主判相反的甲类技法，照写不删。→`20` 五
- **各镜独立结论**：主流镜、张德镜（及开过的其他镜）各自得出的一句主判，分别记录。→`22` 二.3、十
- **可观察结果**：事前写好的"什么算应验、什么算未应"与时间窗口。→`22` 十
- **事后解释**：看到结果后才想到的解释，单列，不计入判定，不回填原判断。→`22` 五.2
- **置信度三级**：高 / 中 / 低，表示依据清晰度与规则稳定性，不表示发生概率。→`22` 七
